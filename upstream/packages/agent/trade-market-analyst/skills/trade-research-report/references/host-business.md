# 公开获客与AI背调七项

使用 task.type=host_business，intent 对应 profile_customers / similar_customers / type_customers / image_companies / sales_diligence / negative_diligence / opportunity_diligence。必填占位必须替换真实业务输入，完整可见提示保留，缺省目标20/10/20，图片全部标识不设凑数目标；背调贸易、趋势、事件近12个日历月，登记财年保留实际年份。S49复用已有真实我方产品与优势，缺失时只列通用待验证机会。

先确认请求，再通过宿主公开发现/图片解读，记下完整链接、检索范围、精确摘录与检查时间。宿主对网页/文本的解读标为尚未核实；页面里原样的结构化片段（如 JSON-LD）可按同一记录绑定主体、值、日期及口径。资料日期未知必须写未知，检查日不当资料日。反证、撤回、限定、未查到、未访问、失败与不可用各别保留。

执行与续做按 SKILL.md 第 3 步写查询记录。先确认完整原请求；图片任务绑定实际附件及宿主解读的全部标识；公开来源记下实际链接。外部宿主（公开检索、图片解读）费用拿得到就照记并写明已确认上限，拿不到按下面的“未知”披露，只能有限部分交付；易查云调用费用未知或已发出未记结果时，先告诉用户再继续。示例为合成证据，不授予真实检索或预算。company_lookup/trade_lookup缺省关闭，启用后仍须本次两钱包授权；贸易先describe_market，再按实际角色、市场和时间核验；不继承联系人授权。

公开发现与企业核验分列，登记不证明采购。相似度逐维业务、渠道、产品和规模，保留差异，不评分。经营地、总部、注册地、店铺分开。图片品牌、权利人、集团与法律实体分开；未知不猜。营收、可见进口采购与出口销售各别。S48指控不当定罪，更新与撤回一直保留；分五类查（产品召回与安全事故、电商平台差评、诉讼与监管、财务健康、媒体负面报道），每类标风险高 / 中 / 低，没查到标低并写明检索范围；按用户2026-10-31决定在网页报告和聊天摘要最前面给明确总体结论：存在重大负面，不建议合作 / 负面较多，需谨慎 / 有轻微负面，可正常合作 / 未发现负面事件 / 主体未确认，补X即可判断；跟一句理由、一句建议和最关键的3个事件。结论主要由已确认事件决定，推断和待核实只能上推一档，同名公司事件不计入；“未发现负面事件”附本次检索范围；结论不录成证据字段。S49建议与证据分开，不自动发送消息。扩张、欺诈等级、概率与评分规则仍待讨论（S48总体结论除外）。

## 外部宿主费用拿不到时

仅适用于公开检索、图像等外部宿主费用，不是 MCP 费用例外，也不授权追加来源。宿主响应没有费用信息时，聊天、Word、Excel 摘要和独立费用披露表都写 UNKNOWN（未知），不写零，不并入 MCP 两钱包，金额、币种、上限保持空，并引用宿主响应里说明没有费用信息的原句作依据。它是操作者披露，不是 provider 费用收据、签名证明或结清证明。部分交付仍执行所有来源、主体关联、图片清单、资格与格式检查，不表示业务完成；provider 摘录仍不能冒发布者原件。

## 原目标未确认时的观察与部分交付

仅 S02/S47/S49 可把检索中观察到的名称、完整网站、国家和来源列示角色记为“未核实观察”；原请求及公司输入原字保持，不补写用户域名或别名。根操作者的记录不当用户确认；观察不属于目标事实、核验候选、身份、资格或机会建议，也不授权任何查询。观察要引用来源原文中的原样锚点（最多160字），主体关联一律未核实，未知资料日期不以检查日补填；提供方文本不成为发布者原件或登记证明。

只有观察时不能正式交付。确需有限交付时，写明原因、未解决的目标、缺哪些证据（非空清单）和下一步；交付后观察清单不再改，新材料另批。交付时目标主表与目标事实为空、取得及合格计数为0、业务完成为否；原目标待核实及下一步在全部格式保留，不能跳过待确认的身份。这不豁免其他待确认条件、失败来源、未知费用或格式规范；外部宿主费用仍单列 UNKNOWN。没有明确选择这种交付的旧任务保持原身份门禁。观察主体不能进入企业搜索、画像、贸易核验或针对性提案；不必为取得有限报告增加查询。

S02 初版只允许参考企业（reference）的观察，不允许发现或相似候选。原输入仍标为参考企业并保留原字；部分交付单列业务、产品、渠道、规模四维待核实。目标名单、事实、取得及合格候选计数均为0，原目标数和全部缺口保持，未知不补零、不评分。没有明确的观察交付决定时仍按原门禁执行。
