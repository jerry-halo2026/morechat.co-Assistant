# 04 TikTok 直播教程（从开通到复盘）

## 1. 直播权限开通条件

- **基础直播**：年满 18 岁 + 粉丝 ≥ 1000（多数市场口径，以后台「Go LIVE」按钮是否点亮为准）。
- **打赏（LIVE Gifts）**：18 岁以上 + 账号状态健康。
- **电商直播（挂车带货）**：需绑定 TikTok Shop（达人挂联盟商品或自有店铺），
  部分市场要求实名认证 + 无违规记录。
- 新号快速过 1000 粉：按 01/02 分册起号，常规 2–6 周；不要买粉（门槛审核会清退）。

## 2. 设备与场景清单（三档预算）

| 档位 | 预算 | 配置 |
|---|---|---|
| 起步档 | ≤¥500 | 手机（近 3 年机型）+ 手机三脚架 + 环形补光灯（18 寸）+ 安静房间 + 干净背景 |
| 进阶档 | ¥1000–3000 | 起步档 + 领夹麦（无线双通道）+ 副灯（打亮产品）+ 背景布/货架 + 提词器 App |
| 专业店播档 | ¥1 万+ | 相机（索尼 ZV 系列）+ 采集卡 + 双灯布光 + 声卡麦克风 + 实景直播间 + 中控电脑 |

**三条底线**：画面不抖、人脸不黑、声音清晰。满足这三条比昂贵设备更重要。

## 3. 开播 SOP（标准作业流程）

**播前（T-24h → T-0）**
1. 选品排品：本场 5–10 个 SKU，确定 1 个引流款（低价冲人气）、2-3 个利润款、1 个形象款。
2. 写直播脚本：过款顺序 + 每款卖点话术 + 憋单节点（见第 4 节框架）。
3. 发 2–3 条预热短视频（直播前 24h / 3h / 30min 各一条，口播预告时间+福利）。
4. 设置直播间：标题带品类关键词+利益点（「Kitchen gadgets 50% off LIVE」）、
   封面、挂好商品、公告写清规则。
5. 设备测试：画面、收音、网络（上行 ≥ 10Mbps）、商品链接点击测试。

**播中节奏（以 2 小时场为例）**

| 时间 | 环节 | 动作 |
|---|---|---|
| 0–10min | 开场留人 | 欢迎话术滚动 + 预告本场福利 + 引导关注/分享，不上硬货 |
| 10–30min | 引流款冲量 | 低价款密集过，拉在线峰值和互动 |
| 30–80min | 利润款主场 | 每款 8–12 分钟：痛点→演示→比价→逼单→答疑 |
| 80–100min | 憋单返场 | 「最后 X 单」「下播前最低价」集中释放 |
| 100–120min | 收尾 | 感谢 + 下场预告 + 引导关注，下播前挂回放 |

**播后（T+0 → T+24h）**
1. 当场数据截图存档，填复盘表（见第 5 节）。
2. 剪 3–5 条直播高光切片发布（直播回放是免费素材库）。
3. 处理售后与私信；标记高意向用户。

## 4. 话术框架（填空模板）

**开场话术**：「Welcome in! 今天直播间只有一件事——【品类】全场【利益点】，
刚进来的宝宝先点关注，【整点/X 分钟后】我们抽【福利】。」

**留人话术**（每 5–10 分钟一轮）：「现在在线的 X 位，扣个【关键词】让我看到你，
扣完我马上演示【下一个卖点】。」

**过款话术四步**：痛点场景（「是不是每次……都很烦？」）→ 产品演示（现场用给你看）
→ 价格锚点（「亚马逊卖 $X，今天直播间 $Y，就这一波」）→ 逼单指令
（「小黄车 1 号链接，库存只有 X 件，拍完记得回来扣已拍」）。

**逼单话术**：制造稀缺（库存/时限）+ 降低决策成本（「不合适可退」）+ 即时反馈
（「刚扣已拍的 3 位，备注加赠【赠品】」）。

**互动救场**（在线人数下滑时）：抛争议问题 / 上 1 元秒杀款 / 发起投票，
绝不在镜头前冷场超过 30 秒。

## 5. 直播数据复盘指标

| 指标 | 含义 | 健康线（经验） | 低了怎么改 |
|---|---|---|---|
| 进房率 | 刷到直播→进入的比例 | ≥3% | 改封面/标题/预热视频 |
| 平均停留 | 人均观看时长 | ≥60 秒 | 开场节奏、留人话术密度 |
| 互动率 | 评论/进房 | ≥5% | 每 5 分钟一次互动指令 |
| 商品点击率 | 点击商品/进房 | ≥5% | 话术指向小车 + 弹卡片频率 |
| 点击成交率 | 成交/商品点击 | ≥10% | 价格力、逼单话术、评价信任 |
| GPM | 千次观看成交额 | 类目差异大，环比自己 | 综合上面几项 |
| UV 价值 | GMV/进房人数 | 环比提升即健康 | 排品结构 |

复盘铁律：每场只改 1–2 个变量（如只换开场话术），下周同时间段对比，否则不知道什么起了作用。

## 6. 直播间流量从哪来

1. **短视频引流**（占比通常最高）：播前预热视频 + 播中发切片，视频右下会出现 LIVE 呼吸灯入口。
2. **推荐页直播卡**：直播间实时互动数据好 → 被推进更大的直播流量池。
3. **关注页/粉丝通知**：粉丝量决定底盘。
4. **付费投流**（LIVE Shopping Ads / Promote）：直播间自然流数据跑通后再投，先验证转化模型。
