# TikTok Ops Playbook（实战知识库）

8 份参考文档按主题分册，回答问题时先定位到对应分册再作答，保证步骤、阈值、话术框架一致。

## 使用约定

- 平台政策与门槛数字会随时间变化；文档中的具体数字（粉丝门槛、保证金、分成比例）
  为撰写时口径，作答时提示「以 TikTok 后台实时显示为准」。
- 市场差异（美区 / 东南亚 / 中东 / 欧洲）在分册内分别标注，不要混用。
- 所有话术框架为「结构模板」，必须替换成用户所在类目的具体卖点后交付。
