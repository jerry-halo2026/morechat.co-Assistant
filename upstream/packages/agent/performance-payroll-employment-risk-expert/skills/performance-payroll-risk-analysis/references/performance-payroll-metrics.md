# 绩效薪酬指标与边界

| 指标 | 口径/限制 |
|---|---|
| 评价完成率 | 同主题下有结果且完成必要确认的人数 / 绩效计划考核对象人数 |
| 评分分布 | 使用绩效总分核定与绩效等级，按同一主题/量表统计人数与比例 |
| 自评差异 | 直接上级评分合计 - 自评分合计，仅作为校准线索 |
| 部门差异 | 同周期同量表比较，并报告样本量 |
| 薪酬复核 | 按员工+归属年月去重，拆分基本、绩效、补贴、税前加减、个税与实发 |
| 绩效薪资链 | 当月绩效薪资与绩效薪资×绩效系数的差异；仅验证模板可见公式 |
| 同岗差异 | 同岗位/职级/地区/工时口径下的复核线索 |
| 合同到期 | 到期日距分析日的天数，阈值由用户确认 |

输出中隐藏无关身份信息。个人清单只提供给明确授权角色，并用“需复核”而非“违规/不公平”表述。
