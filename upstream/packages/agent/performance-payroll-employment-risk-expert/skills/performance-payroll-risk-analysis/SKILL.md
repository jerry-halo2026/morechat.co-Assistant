# 绩效薪酬风险分析

## 必读参考

- 模板与连接门禁：@references/hrm-template-map.md
- 指标与高敏边界：@references/performance-payroll-metrics.md

## 执行流程

1. 确认周期、量表、规则版本、薪酬期间、币种、同岗口径和适用地区。
2. 真实数据任务静默完成应用、表单、字段映射；唯一候选继续，多个同名/同指纹应用请用户选择，再读取最小必要字段。
3. 用绩效计划定义应评价集合、绩效结果定义结果集合；检查必要确认、重复工资、异动生效日和合同日期。
4. 分析绩效总分/等级、自评与上级评分差异、薪资结构与工资计算链、同岗差异、合同到期和流程完成率。
5. 只生成复核线索，不自动得出不公平、低绩效、调薪或解除结论。
6. 输出异常规则、记录范围、证据、复核人、截止时间和建议动作。

## 写入能力门禁（执行前必检）

- 连接器已连接时仍需单独确认 `member_data_create` 是否存在；「新增数据」是需审核能力，不能因查询成功就假设可写。
- 工具缺失时进入**已连接—只读连接模式**，继续查询和生成复核项/提醒记录预览，并说明申请、管理员审核、断开并重新连接步骤。
- 工具存在但返回权限不足时，区分 MCP 新增能力和目标表单新增权限；停止重试，不虚构成功。
- 只有工具可用、目标表单允许新增且用户针对本次预览二次确认后才可写入。

## 安全边界

- 默认匿名化和群组汇总；小群体合并以降低反识别。
- 不使用受保护属性或代理变量作决定。
- 不凭模型常识生成市场薪酬分位。
- 任何新增记录先检查能力，再完整预览并二次确认；不支持的修改、删除或审批转人工处理。
- 劳动法、个税和薪酬合规由当地 HR/法务/财税复核。

## 稳定数据与时间口径

- 预制问题、示例问法和模板演示不依赖会随自然时间推移而失效的相对时间窗口；可使用当前可访问数据、完整数据覆盖期、明确业务状态或记录中的具体日期。
- 先逐表展示数据覆盖起止日期和样本量；不同模块覆盖不一致时分别报告，不能硬凑同一周期。
- 用户未指定截止日时，账龄、停滞、合同到期、招聘超期等时间差指标使用相关源表中最晚有效业务日期作为分析截止日，并明确写出该日期。
- 只有存在可比时间段且样本完整时才输出趋势；否则展示全量分布、排序、状态和数据缺口。
