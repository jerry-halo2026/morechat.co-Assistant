# WorkBuddy 产品经理专家 Agent 导入指南

## 导入步骤

### 方法 1：本地导入

1. 解压本 zip 包，将解压出的目录复制到 `~/.workbuddy/plugins/marketplaces/my-experts/plugins/product-pm-expert/` 下（目录名保持 `product-pm-expert`）
2. 运行注册命令使其可见：

```bash
python3 ~/.workbuddy/plugins/marketplaces/workbuddy-builtin/skills/expert-manager/scripts/register_expert.py <expert-dir>
```

3. 重启 WorkBuddy
4. 在专家列表中找到「产品经理专家」即可使用

### 方法 2：通过 expert-manager 技能安装

在 WorkBuddy 聊天框发送：
```
安装专家 [zip 包路径]
```

### 方法 3：手动创建

1. 在 WorkBuddy 中进入 Craft 模式
2. 按 plugin.json 中的配置手动创建专家
3. 将 agents/product-pm-expert.md 内容粘贴为专家提示词
