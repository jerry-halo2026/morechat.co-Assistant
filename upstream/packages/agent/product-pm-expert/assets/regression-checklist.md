# 产品经理专家发布前回归检查清单

> 配套资产：与 agent.md「能力 8：演练与回归验证」保持一致（单一事实源）。
> 用途：每次版本升级后逐项核对；自动化项由 `package_and_validate.py` 执行，人工项由发布者核对。

## 一、自动化回归项（校验脚本执行）

| # | 检查项 | 判定标准 |
|---|--------|----------|
| 1 | 版本号三处同步 | plugin.json / README 版本历史 / 校验脚本 VERSION 一致 |
| 2 | 演练标准与模板区一致 | 能力 8 演练标准条目在 PRD 模板区均有对应（无漂移） |
| 3 | SKILL.md 与 agent.md 同步 | 结构（15 段/专项/依赖）、触发词、Troubleshooting 覆盖一致 |
| 4 | 触发词覆盖新增能力 | 新增能力的关键词均命中 read_when |
| 5 | 自建断言全 PASS | package_and_validate.py 全部断言通过，无 FAIL |
| 6 | zip 结构完整 | 根目录含 .codebuddy-plugin / agents / assets / skills + README；avatar 与回归清单资产存在 |
| 7 | 官方校验通过 | validate_expert.py 输出 ✅ Expert package is valid! |

## 二、人工回归项（发布者核对）

| # | 检查项 | 判定标准 |
|---|--------|----------|
| 8 | 真实场景演练 | 至少 1 个场景演练覆盖本次变更点，演练报告留档 |
| 9 | 演练产物归档 | 演练 PRD / 报告存入 _deep_test 并在演练案例集登记 |
| 10 | 数据保质保量 | 演练与交付数据逐项核验，假设数据标注口径 |
| 11 | 合规复检 | 新增内容不抄袭、不侵权、不踩红线；引用注明来源 |

## 三、演练标准速查（PRD 出稿自检）

- [ ] 15 段结构齐全
- [ ] 功能需求逐条编号 + Given/When/Then 验收
- [ ] 方案对比给出推荐结论 + 演进路径（本期 → 后续 + 触发条件）
- [ ] 依赖三档分级（阻塞/并行/可绕过）+ 最晚就绪时限
- [ ] 资金类：交易/资损专项 8 项 + 底线三件套不可砍
- [ ] 涉及迁移：存量迁移方案模板
- [ ] 变更请求：需求变更评估表
- [ ] 每版本最小数据能力（至少 1 个核心指标看板）
- [ ] 交付前需求评审检查清单 8 项
- [ ] 附录含 RTM 与合规声明

## 四、演练场景库（选型参考）

| 场景 | 演练重点 |
|------|----------|
| 电商交易 | 幂等、金额精度、对账、资损监控、退款口径、风控联动 |
| B 端权限 | 角色模型、数据隔离、权限变更审计、存量迁移 |
| SaaS 配额 | 配额模型、超额策略、依赖就绪度、用量口径 |
| 内容社区 | 内容审核、分级处置、申诉闭环、未成年人保护、合规红线 |
| 工具多端 | 同步冲突策略、离线队列、存量迁移、回滚 |
| 信息流 | 推荐策略对比、冷启动、指标口径、A/B 实验、隐私合规 |
| 订阅资金 | 订阅幂等、续费重试、对账、资损告警、取消退款、演进路径 |
| 开放平台 API | 接口契约、认证鉴权、限流配额、计量计费、版本兼容、沙箱文档 |
| 数据合规 | 数据分类分级、PII 处理、用户权利、告知同意、留存清理、审计 |
| 国际化 | i18n 资源规范、区域配置、货币精度、法规适配、区域灰度 |
| 企业服务 | 工单 SLA 分级计时、续约漏斗、升级链路、服务度量口径 |
| 硬件 IoT | 设备接入认证、物模型、OTA 灰度回滚、离线处理、容量、存量迁移 |
| 金融 | 资金三件套、强监管合规、风控联动、利率年化口径、存管对账、审计留痕 |
| 教育 | 课程资金三件套（报名幂等/课时对账/退费口径）、督学留痕、版权合规 |
| 医疗健康 | 处方合规、健康隐私（PII 脱敏）、紧急处理链路、资质核验、广告红线 |
| 游戏 | 防沉迷强制（实名/时长/宵禁）、内购幂等与退款、版号与内容合规 |
| 本地生活 | 储值资金三件套、商户资质核验、核销防重、履约异常补偿 |
| 出行 | 退改签资金三件套、行程安全与承运资质、计价争议、保险责任边界 |
| 文创 | 版权与授权链、原创与不侵权、侵权投诉与 48h 下架、虚拟商品资金三件套 |
