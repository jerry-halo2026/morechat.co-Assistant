# 第四批场景模板反哺重检（Backfeed Check）

> 配套资产：第四批业务场景模板（企业服务/硬件 IoT/金融，v1.12.0 新增）反哺旧场景演练 PRD 的合规重检规范（v1.14.0）；v1.19.6 扩展：评审语料库 RC-39~41（本地生活/出行专项）反哺 PRD-17 v1.1 / PRD-18 v1.1 重检（3.4/3.5 节）。与 agent.md 能力 8 模板反哺小节、SKILL.md「## 模板反哺重检」章节保持一致（单一事实源），改其一必同步其余。
> 用途：用新模板的 8 项专项检查清单重检同域旧演练 PRD，逐项核实「已覆盖/待补强/不适用」，对缺口补强到旧 PRD 本体（文件名不变），重检记录沉淀为本资产并纳入回归。
> 机制名：模板反哺重检机制（语料库 RC-35 引用，措辞必须一致）。

## 一、反哺原则

1. **新模板反哺旧产物**：第四批模板的专项检查清单（金融资金三件套/强监管合规、IoT 安全容量、企业服务 SLA 度量）向同域旧演练 PRD 反哺，逐项重检
2. **如实记录**：每项重检标注「已覆盖（引用 PRD 实际章节）/ 待补强（缺口描述与补强落点）/ 不适用（注明原因）」，不静默忽略、不夸大覆盖
3. **补强落回本体**：缺口项直接修订旧 PRD（文件名不变，内容增强），文档信息表版本行追加反哺重检记录
4. **回归断言**：`_verify_backfeed.py` 断言重检记录与 PRD 实际措辞一致（已覆盖项必须真实存在于 PRD，待补强项补强后转为已覆盖）
5. **不破坏既有回归**：补强只增不删，保持 15 段结构与既有断言锚点（语料库/口径库/出稿自检）不失效
