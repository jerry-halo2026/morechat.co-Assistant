### 新增的实际产品能力

- **五形态**：图鉴、白皮书、数据报告、人群专题、方法论。自然语言选择/推荐，共用基础层与共用块组合，各自叙事骨架、页型、语气、视觉配置与静态替代；形态与赛道分离，只递增组合修订。五份母版、形态目录、样式与版式资产随包闭合，不再只是开发目录中的引用。
- **数据限制进入成果**：期间与实际覆盖、单位换算并保留原值、分母/样本、缺失与真零分开、多选不归一、缺基准不算 TGI、模拟不计真人、单对象不虚构 TOP10、概念公式不数值化、撤销素材合法降级。均提供小型确定性守卫，可复算。
- **平台无关的局改写入器**：以解析后的路径关系替代字符串前缀判断，正确覆盖 Windows 反斜杠路径；写前对选定源码/原件/用户手改重新读取完整字节并比对，变化即拒绝；原子排他新建、碰撞拒绝、写后读回、写入回执；同号只读查询零写、不换号、不重放。这是新实现，不声称与旧冻结执行等价。
- **便携接续卡**：意图/证据/组合/稿件修订分开，材料覆盖三层、承重主张、成果清单、写入回执、保护项与待同步项、失败/未知、唯一下一步；新会话只从项目文件恢复，不依赖云记忆、本地记忆或后台状态。
- **闭合 0200 客户端**：`paper.intent.v2` 闭合 wire + 精确 `2026.11.0200` + 同号只读 receipt 查询。先排他保存规范字节/UUID/摘要并读回；一次 resolve；两层校验（外层七闭合字段、内层 v2 语义）；恢复不刷新寿命、不等于重做工作；反馈独立且默认关闭；远端默认关闭；服务 lane 已由控制者部署 paper-20261105-0200-r3 并公网读回通过，但客户端实际线上消费不因此宣称通过，仍待独立验收。
- **有界 HTTPS 运输与显式反馈入口**：运输的单调总截止在连接、响应头与正文全程生效（单次原读循环、慢速滴入正文在截止点被切断而非读完后才检查）；严格 JSON 拒绝重复键、非有限常量与指数溢出（如 1e999）；已知 HTTP 状态按原号保留为 unknown（不自动重发、不推断业务落库、不外泄异常正文/URL/凭据）。既有 v2 反馈保留显式正向入口：默认关闭，须完整 payload、明确同意、真实可观测指标与本进程已验证的 selected 决定，先持久化发送开始事件再单次真实发送，仅真实 2xx 对象回执才报确认；未知保持未知，重启后回执不恢复反馈资格；v3 反馈未启用。
