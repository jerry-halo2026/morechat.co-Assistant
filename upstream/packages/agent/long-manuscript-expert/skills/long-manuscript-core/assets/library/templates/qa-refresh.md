## 视觉表达选择
- 决策读者先用决策卡；承重主张进入证据矩阵。
- 有同口径数据时使用 `update` 布局及配套视觉块；无有效数据时保留“未知/未读/待复核”面板。
- 每幅图附图题、指标定义、单位、期间、样本/分母、来源锚点、变换和限制。严禁从图形面积或高分补出缺失事实。
- 自动组合只调整已授权问题的表达；改变研究方向、读者、数据访问、花费或写入范围时保留为待采纳提案。
