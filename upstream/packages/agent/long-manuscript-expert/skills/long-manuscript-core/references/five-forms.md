# 五形态：选择、组合、叙事与降级

本文件是 2026.11.5 的产品方法正文，不是开发台账。五份母版、形态目录、样式与静态版式随包闭合，路径均相对本包，不指向任何开发目录或历史快照。

## 一、三层分离

研究问题回答"要作出什么判断"，行业适配回答"哪些证据与方法适用"，成品形态回答"如何组织与呈现"。不能把图鉴塞进赛道，也不能把智能硬件当页面样式。

- 形态选择只递增**组合修订（composition_revision）**，不改有效意图（intent_revision）或证据（evidence_revision）。
- 用户用自然语言选择或描述读者与用途由专家推荐；不要求填内部 JSON、块 ID 或技术字段。
- 主模板决定阅读节奏；章节可组合其他形态的页型，但须保留组合理由、作者结构、来源及写入范围。
- 撤销一个形态资产（图片、原声、关系边、底表）时，结论按实际剩余证据降级，不静默保留旧结论。

## 二、共用基础层

- 默认 A4 竖版；横向数据附页和图鉴对页明确指定。对页采用单页源序列 + 对页呈现映射，拆成单页时读序和脚注不丢失。
- 内容边距 18mm、12 列网格、列沟 5mm、8pt 间距节奏；H1 26—32pt、H2 17—21pt、正文 10.5—12pt、图注与脚注不低于 8.5pt。密表优先分页或附录，不靠持续缩字适配。
- 中文字体随宿主确认可用与授权；定义中文、拉丁数字与缺字回退。标注、负号、小数点和上下标必须可辨。
- 颜色按语义映射：主对象、基准、观察、假设、风险、未知各有稳定规则；正负方向与"好/坏"分开，未知不使用零值条。关键信息同时用文本或符号表达，不仅靠颜色。
- 每张图保留标题、读法、单位、期间、样本/分母、来源与限制；页眉显示章节，页脚有页码和必要来源。每页明确一个论证任务，建议 1 个主判断、1—2 组主证据；数据页最多 4 个主图面板。

`assets/five-forms.css` 提供五套可覆盖的语义变量；`assets/layout/T0*-layout.svg` 是宿主不支持交互图时的静态替代，SVG 文件存在不等于宿主已显示。

## 三、形态差异与硬限制

### T01 图鉴
- **叙事**：范围与旅程 → 趋势证据 → 两种场景 → 画像与原声 → 案例拆解 → 行动回顾。先写观察再解释，不能先设人物故事后编证据。
- **视觉**：浅暖底、有限章节色；一张主图 + 两个观察卡，或 55:45 图文对页；图片与留白约 45%—65%。
- **必需物料**：授权视觉或可替代图、场景事实、原声定位、趋势观察、案例证据、时间范围。
- **反例**：撤销授权图片或原声后，保留"未知/未获取"并改用文字场景卡与明确占位；不生成虚构受访者或实拍图。装饰不计入证据；去掉装饰仍能读出依据；对页拆分后来源和读序保持。

### T02 白皮书
- **叙事**：执行摘要 → 问题/范围 → 证据与趋势 → 术语/定义 → 核心论点 → 参考架构 → 替代方案与权衡 → 案例 → 实施条件/限制 → 参考资料。段落遵循"主张—依据—机制—适用条件—小结"。
- **视觉**：克制底色、清晰层级；正文单/双栏切换，全页架构图与长文交替；宽图跨栏时图题与来源不拆到下页。
- **必需物料**：原始文献、术语表、论点支持与反证、结构关系、系统边界、案例来源。
- **反例**：切换厂商不改通用概念定义；概念公式无参数不自动计算；厂商自述与独立测量分层；撤销一条架构边后，图与授权范围内正文同步提示影响；流程箭头不被写成已验证因果。

### T03 数据报告
- **叙事**：范围与数据说明 → 关键结论/KPI → 总体基准 → 核心对象 → 维度拆解 → 时间变化 → 异常与机会 → 行动清单 → 底表。数值先行，每条解释交代比较对象和期间。
- **视觉**：白底、细网格、稳定数字排版；高亮仅用于主对象与异常；每图下面保留原值、出处与限制。单页数据不足时自动减图，不填充假图。
- **必需物料**：类型化底表、指标字典、地域与对象层级、实际覆盖与完整性、单位、分母、基准、统计/预测标记与计算记录。
- **反例**：1—8 月实际覆盖不写成全年事实标题，目标范围与观测覆盖显式分开，缺月不补 0；辆/万辆、万人/人数、百分比/百分点显式换算并保留原值；缺人口不计算每千人量；只有 1 个可用对象时只显示该对象与覆盖说明，不虚构 TOP10；主对象未入榜单列"补充对照"而不篡改排名；静态导出不依赖悬停提示，关键值进入静态标签或底表；本期与基期长度不同、预测与实际混排分别标注。

### T04 人群专题
- **叙事**：研究问题 → 样本与方法 → 分群维度 → 总体分布 → 群体画像 → 场景/行为/原声 → 群间差异 → 机会与验证计划。以研究范围限定表达，画像以群体描述呈现，不用绝对标签替代个体差异。
- **视觉**：重复画像卡与固定图位支持群间比较；总体 N 与子样本 n 紧邻图；重叠分群用矩阵或条形，不强制饼图；每群固定人群、场所、触发、期待、时段、品类等字段，按任务删减。
- **必需物料**：抽样/配额与调查时间、总体及子样本、题目/选项、多选标记、权重状态、分群规则、原声、来源家族及 TGI 参照总体。无抽样设计时保留探索性范围。
- **反例**：多选合计超过 100% 可表示重叠，不强凑 100%、不用互斥饼图；N 与 n 分别显示，子样本不替换总体；缺同源同口径参照总体时 TGI 为 unknown，不造基准；访谈、行为数据与模拟反馈不得相加为真人样本；零、null、缺行、零分母分开；群体不等同具体个体。

### T05 方法论
- **叙事**：要解决的问题 → 方法定义/适用边界 → 总体模型 → 步骤详解 → 工具/检查表 → 案例及反例 → 实施路线图 → 检验与迭代。讲清怎么做、为什么做、何时不做。
- **视觉**：长文与简图交替；统一步骤编号、阶段色和角色标识；路线图按目标/动作/角色/产物/门槛排列，跨页重复表头；没有实测不画效果增长曲线。
- **必需物料**：问题证据、前置条件、步骤、角色、输入输出、案例过程、基准/结果、失败/退出条件。实施周期来自任务约束，不照抄参考的 90 天。
- **反例**：每个步骤可定位输入和输出与完成门槛；删除前置资源触发受限方案或明确退出；观点公式标记为概念模型，未实测效果用待验证假设表达；模拟消费者结论、案例自报与独立测量分层显示，不作实测效果证明。

## 四、稳定降级

| 缺项 | 可交付 | 不允许 |
| --- | --- | --- |
| 没有合法图片 | 文字场景卡、原创概念图、明确占位 | 把生成照片称为真实用户/产品实拍 |
| 没有定量数据 | 定性观察、证据表、补数清单 | 用假数、零值、空轴制作"效果图" |
| 只有厂商自述 | 带归属的方案介绍与待核条件 | 写成独立研究已确认的收益 |
| 缺总体/分母/基准 | 保留原值、说明不可计算 | 计算市场份额、TGI、改善率 |
| 字符映射错误或扫描页 | 渲染复核、已读范围、待 OCR 清单 | 字符数不为零即认定已读全文 |
| 宿主无法显示 SVG 或导出 | 可读文字表 + 实际支持的静态图 | 把存在的 SVG 文件当宿主已显示 |

## 五、交付与首轮上限

每类首轮样稿最多 6 页、五类共最多 30 页；这是初轮验收上限，不是正式报告页数限制。五形态应使用**一个一致研究主题**验证输出结构与数据限制，按缺口补有价值的反例，不为样例数堆栈。

六层质量（结构、算术、来源、语义、作者保护、视觉及交付）分别给 PASS / FAIL / UNKNOWN / NOT_APPLICABLE 及证据来源；不存在综合高分覆盖关键失败的通过机制。实际生成、读回、渲染/目视、宿主显示分别记录；未查看页不能写已目视通过。
