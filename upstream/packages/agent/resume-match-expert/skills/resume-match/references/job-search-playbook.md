# 求职全流程行动手册

从「诊断简历」升级到「全周期求职」：诊断 → 定制 → 投递 → 面试 → offer。本手册覆盖除深度面试练习外的所有环节；面试问题库与模拟练习见 `interview-prep.md`（本技能另一份参考文件）。

所有比例数字均为**经验参考区间**，因行业、地区、个人情况而异，非官方统计。把它当方向感，不当 KPI。

## 1. 求职漏斗与节奏

求职是一个漏斗，每一层都会漏掉一部分人，这是正常现象，不是针对你：

```
投递 → 笔试 → 面试 → offer
```

| 阶段 | 含义 | 常见卡点 |
|------|------|---------|
| 投递 | 简历被 HR/系统看到 | 简历与 JD 不匹配、被 ATS 过滤 |
| 笔试 | 在线测评 / 技术笔试 | 题型不熟、时间不够 |
| 面试 | 一面/二面/终面 | 表达不清、项目讲不透 |
| offer | 谈薪、接/拒 | 对比不清、谈薪失误 |

**经验参考区间**（非官方统计，仅作节奏参考）：从投递到 offer 通常需要 4~8 周；每投 10 份简历大约能换来 1~3 次笔试或面试机会。回复率低不代表你不行，可能只是渠道或简历表达问题。

**每周投递节奏建议**：

- **全职求职者**：每周 15~25 份，其中至少一半是「匹配档」（见第 2 节），宁缺毋滥；
- **在职骑驴找马**：每周 5~10 份，集中在周末批量投，工作日只处理回复；
- **应届生**：跟着校招批次走，提前 1~2 个月开始，每周 10~15 份；
- 投递不是目的，**回复和面试才是**。如果连续两周投出去毫无回音，先停下来改简历和换渠道，而不是加量硬投。

## 2. 分层投递策略

不要把所有岗位一视同仁地投。按「匹配度」把目标岗位分成三档，分配不同精力：

| 档位 | 定义 | 投递配比（经验参考） | 精力投入 |
|------|------|---------------------|---------|
| 冲刺档 | 匹配度 60~80%，公司或岗位比你现在高半级，跳一跳够得着 | 约 20% | 简历精修 + 全力准备面试 |
| 匹配档 | 匹配度 > 80%，岗位要求你基本都满足，最可能成 | 约 50% | 标准定制 + 稳定推进 |
| 保底档 | 匹配度 60% 上下，要求略低于你，用来保心态和保 offer | 约 30% | 快速投递，不花太多心思 |

**怎么算匹配度**：对照 JD 逐条打分。硬性要求（学历、年限、核心技术栈）全中 = 高匹配；缺 1~2 项硬性要求但能用经验弥补 = 中匹配；缺一半以上 = 低匹配。也可以直接跑本技能的 `analyze_resume.py` 脚本拿客观匹配度。

**分层原则**：

- 冲刺档别投太多，投多了会持续消耗你的信心；
- 保底档的 offer 是「心态保险」，不是「将就」，拿到后照样可以继续面冲刺档；
- 每周三档都要有，别只投一档。

## 3. 按 JD 定制简历：5 分钟清单

每投一个岗位，投之前花 5 分钟按这份清单过一遍简历。**不要用同一份简历海投**。

### 5 分钟定制清单

1. **标题与摘要对齐岗位**：简历顶部的一句话简介，把岗位关键词放进去。JD 写「高级 Java 工程师」，摘要就写「5 年 Java 后端经验，专注高并发服务」；
2. **技能排序对齐 JD**：把 JD 里最看重的技能排到技能列表最前面，JD 没提的技能往后放或删掉；
3. **经历要点嵌入 JD 关键词原词**：JD 写「Redis 缓存」，简历就写「Redis 缓存」，不要写「内存数据库」这种近义词（ATS 匹配以原词最稳，部分系统支持近义词，但别赌）；
4. **删除无关噪音**：和这个岗位无关的项目、技能、奖项，删。一页纸放不下的时候，删噪音比压缩文字更有效。

### 每投必调的 3 个地方

- **摘要**（30 秒改完）：对齐岗位方向；
- **技能列表顺序**（1 分钟）：按 JD 优先级重排；
- **第一条工作/项目经历**（3 分钟）：把和 JD 最相关的经历提到最前，并嵌入 JD 关键词。

### 常见错误

- 一份简历投所有岗位（匹配度被稀释，回复率最低）；
- 只改公司名不改内容（HR 一眼看穿，等于没定制）；
- 关键词用近义词替代（ATS 匹配不上）；
- 为了凑关键词硬塞不会的技能（面试一问就穿帮，比不写更糟）。

### 内推：比海投高效得多的渠道

中国求职渠道的效率排序：内推 > 官网/招聘页直投 > 猎头/垂直招聘平台 > 海投平台。内推的简历通常直达用人团队，回复率远高于海投——有条件就优先走内推。

**怎么找内推**：

- 校友：校招群、学长学姐、校友会；
- 前同事、前同学、朋友的朋友；
- 脉脉 / 领英上目标公司的员工：找不到熟人时，礼貌私信同岗位或同部门的员工，一两句话说明来意 + 一个最匹配的亮点 + 附简历；
- 垂直行业社群、公司官方内推码。

**内推寄语模板**（请对方转给 HR 用，控制在 3~4 行）：

```
您好，我是 [名字]，[一句话背景，如：3 年后端开发，目前在 XX 公司]。
看到贵司 [岗位名] 在招，我的 [一个最匹配的亮点，如：高并发系统经验] 和岗位要求比较契合。
方便帮我内推一下吗？简历见附件，麻烦您了，感谢！
```

**内推后**：把内推人记入求职看板「备注」列，3~5 天后礼貌同步一次进度，不反复催。

**注意**：内推只是「让简历被看到」，不等于内定；别群发同一家公司的多个员工；对方没回不要追问。

## 4. 投递后跟进

### 跟进时机与频率

| 场景 | 建议 |
|------|------|
| 投递后无回复 | 7~10 天后跟进一次，之后最多再跟一次，不纠缠 |
| 笔试/面试后 | 3~5 天后跟进，问结果 + 表达意愿 |
| 对方明确说「等通知」 | 尊重节奏，1~2 周后再问一次 |
| 已读不回 / 石沉大海 | 默认没戏，继续投下一家，不内耗 |

### 跟进邮件模板（中文）

```
主题：关于 [岗位名] 面试结果的跟进（[你的名字]）

[HR 姓名] 您好：

我是 [日期] 参加 [岗位名] [笔试/一面/二面] 的 [你的名字]。
想跟进一下后续进展，也再次表达我对这个岗位的兴趣。

如果还需要补充材料或安排下一轮，请随时告诉我。
无论结果如何，都感谢您的时间。

[你的名字]
[电话] / [邮箱]
```

### 英文简版

```
Subject: Follow-up on [Position] interview - [Your Name]

Hi [Name],

I interviewed for the [Position] role on [Date] and wanted to
follow up on the status. I remain very interested in the position.

Happy to provide any additional information. Thank you for your time.

Best regards,
[Your Name]
```

### 石沉大海怎么办

- 默认没戏，不追问第三次，不质问对方；
- 复盘这一家的简历和渠道：是匹配度问题，还是渠道问题（内推 > 官网 > 海投平台）？
- 把「没回复」当成漏斗的正常损耗，继续投下一家。**回复率是概率问题，不是人品问题。**

## 5. 面试邀约与安排

多线并行是求职常态，但排期要留余地：

- **同一周最多排 2~3 场面试**，每场之间至少隔 1 天，留出准备和复盘时间；
- **避免撞车**：收到邀约先确认时间，撞了优先保「匹配档」和「冲刺档」；
- **留出准备时间**：技术面至少提前 2~3 天准备，行为面至少提前 1 天；
- **主动约时间**：HR 给的时间不合适，直接提「这个时间我有安排，X 时间可以吗」，正常公司都接受调整；
- **面试前 10 分钟**：确认会议链接/地址、设备、简历和 JD 打印或开好；
- 面试准备的具体方法（自我介绍、项目深挖、反问环节）见 `interview-prep.md`。

## 6. Offer 阶段

### Offer 多维度对比框架

拿到多个 offer 时，别只看月薪。按下面的维度打分（1~5 分），乘权重求和：

| 维度 | 参考权重 | 看什么 |
|------|---------|--------|
| 薪资构成 | 25% | 月薪、年终、股票/期权、五险一金基数、补贴，算**年包**而不是月薪 |
| 成长空间 | 20% | 业务是否在增长、技术栈是否主流、晋升通道是否清晰 |
| 团队与业务 | 15% | 直属领导风格、团队规模、业务是否核心 |
| 稳定性 | 15% | 公司现金流、裁员传闻、行业周期 |
| 通勤 | 10% | 单程通勤时间，超过 1.5 小时会持续消耗你 |
| 加班文化 | 15% | 实际作息、大小周、on-call 频率，问清楚再决定 |

权重可按你的优先级调整（比如你特别在意通勤，就把通勤权重调高）。**把「钱」和「生活」分开算，别让月薪一票否决其他维度。**

**年包怎么算（中国职场特有，务必算清楚）**：

- 年包 = 月薪 × 12 + 年终奖（常见 1~6 个月，问清是否写入合同、是否保底）+ 股票/期权（按可兑现部分摊薄到年）+ 各类补贴；
- **公积金与社保缴纳基数单独问清**：不少公司按最低基数或打折基数缴纳，长期差异很大（影响每月到手和买房贷款额度）；
- 口头承诺不算数，写进 offer 邮件才作数。

### 谈薪原则与话术

- **基于事实，不虚报**：报期望薪资用「当前薪资 + 市场行情 + 岗位价值」支撑，不编造现有薪资；
- **锚定区间**：给区间而不是单点，比如「期望 25~30k」，区间下限是你真正能接受的底线；
- **书面确认**：口头承诺不算数，所有薪资构成（月薪、年终、期权、试用期）要求发正式 offer 邮件确认；
- **不急着亮底牌**：先问对方预算范围，再报自己的期望。

**薪资参考从哪来**（没有内置薪资数据库）：三源合成——① 你真实的当前薪资（最重要，来自你自己）；② 你的期望和可接受底线；③ 市场行情用 WebSearch 现查（如「[城市] [岗位] 薪资」），引用公开来源、标注时效，仅作参考区间。**绝不编造「某城市平均薪资」之类的数字**；给建议时说明依据来源。

话术示例：

```
「我目前薪资是 X，结合这个岗位的职责和市场上同级别的水平，
我的期望是 25~30k。如果年终和期权结构合适，区间内都可以谈。」
```

### 接 / 拒 offer 的礼貌处理

- **接**：确认收到 offer，问清入职时间、需要准备的材料，书面回复确认；
- **拒**：尽快回复，不拖到入职前才说。给一句真实但简短的理由（「经过综合考虑，我选择了另一个更匹配的方向」），不贬低对方公司；
- **接了又反悔**：尽量避免，会烧掉你的信誉。实在要反悔，越早越好，诚恳道歉；
- **用 offer 催另一家**：可以礼貌地告诉对方「我这边有一个 offer 在等回复，想确认一下贵司的进度」，但别威胁式逼单。

### 降薪 / 平薪跳槽怎么讲

如果新岗位薪资低于或持平当前，面试时把话题落在「主动选择」上（赛道、平台、成长空间、稳定性、通勤），给一个可信的主动理由，不暴露「被迫离职 / 急着找工作」。同时想清楚底线：低于底线就坦诚谈，不要勉强接受——接了又后悔，代价比婉拒大得多。

## 7. 周复盘模板

每周固定 30 分钟，打开求职看板（见 `templates/job-tracker.md`）做一次复盘：

**第 1 周没有数据也要做**：记下目标方向、目标城市、核心技能盘点和本周投递目标——先把基线建立起来，后面几周对比才有意义。

### 数据回顾

| 指标 | 本周 | 累计 |
|------|------|------|
| 投递数 | | |
| 回复数 | | |
| 笔试数 | | |
| 面试数 | | |
| offer 数 | | |

### 卡点诊断

- **投了没回复** → 问题在简历和渠道：简历匹配度够吗？是不是该换内推/官网渠道？
- **有笔试没过** → 题型不熟：刷题量够吗？是不是该补基础？
- **有面试没过** → 表达问题：项目讲透了吗？自我介绍顺吗？去 `interview-prep.md` 练；
- **有 offer 但不想去** → 投递策略问题：是不是保底档投太多、冲刺档投太少？

### 下周计划（写入看板「复盘区」的下周行动列）

- 下周投递目标（数量 + 三档配比）；
- 要改的简历（哪几份、改哪里）；
- 要练的面试环节（具体到哪个问题）；
- 要跟进的岗位（哪几家、哪天跟）。

## 8. 心态管理

求职是持久战，心态崩了比能力不够更致命。

- **建立节奏感**：固定作息，投递、准备、复盘都排进日程，别让求职变成全天候焦虑；
- **拒绝脱敏**：被拒是漏斗的正常损耗。把「被拒」当成数据点记进看板，而不是自我评价。每被拒一次，就离匹配的岗位近一步；
- **把面试当练习**：每一场面试都是免费的实战演练，面完立刻复盘「哪里没讲好」，下一场改。面挂了不等于你不行，只是这场没匹配上；
- **保底档保心态**：手里有一个保底 offer 时，面冲刺档的心态会完全不同；
- **给自己放假**：每周至少留半天完全不碰求职，求职是马拉松，不是冲刺；
- **求助不丢人**：卡住两周没进展，回来找专家复盘数据、改简历、调策略，别一个人硬扛。
