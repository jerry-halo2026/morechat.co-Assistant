> 本技能沉淀自「纸鹤的知识库 · 陈雯直播」与「陈雯大号抖音」两套一线实战体系（陈雯momo「团购5A人群打法」+「实体抖音3451打法」，已做知识产权备案），并融合**字节官方《生意经 4L人群产品使用手册》《生意经 5A6C人群产品使用手册》**的权威口径、抖音官方合规规范。供抖音精细化运营专家在诊断、方案、脚本、直播、投放、复盘时调用。

## 〇、总纲：三角四步五流一IP（实体抖音 3451 打法）

陈雯原创主框架，覆盖 85%+ 可上团购行业。今年（2025→2026）实体做抖音的核心骨架：**先把基础的团购和流量学明白（领先行业 90%），再叠加后端盈利模式**。

### 黄金三角盈利模式（前端 → 中端 → 后端）
- **前端**：团购 + 流量 → 到店。现金流是实体门店生命线，必须有足够到店客流支撑现金流。
- **中端**：把前端做出品牌声量，并用四个手段完成**降本增效**。
- **后端**：区域化 IP + 后端模式设计（招商 / 加盟 / 培训 / 供应链金融 / 收徒 / 起盘）→ **品牌收割**。
- **关键认知**：团购不是今年核心利润点，只是后端盈利模式的**入口**；今年本质是「洗牌 + 新零售崛起」，必须同时会搞流量、种草、卖货、私域、后端模式。产品服务只是门槛与线下基石，不是盈利本身。

### 五流打法（四步 + 投流）
1. **内容流量**：图文 / 短视频 / 直播。今年内容须「种草型 + 品宣种草型 + 卖货型」三者合一；一场直播不只收 A4，更要收 A1~A3 种草人群；收割同行 A1~A3 转成自己 A4，是高端链路玩法。
2. **商城流量**：六大板块（细分八小板块）。好模型卡片成交占比应 **>60%**，最佳 **65%~70%**（超过 90% 说明直播收割不到位）；今年全面货架化；搜索从商城流量独立成「主站搜索 + 团购搜索」两支；增量宝属商城工具板块。
3. **线下流量**：90%+ 行业要做扫码上翻；今年必须叠加**私域**，私域纳入整条生意链与流量体系。
4. **截流**：今年关键词 = 卷 = 精细化运营。先数据（谁从本店流出到 A/B/C/D… 门店、看了什么品、核销 / 点击 / 锚点率），后截流；不是简单超低价截流。
5. **投流**：本地推元年 = **素材元年**，比拼投放素材 + 门店基建 + 素材质疑量。

### 一 IP：区域化 IP
用最低成本扫荡区域市场（「区域 + 轻 IP」），不是花 50 万做 IP。区域化是平台大方向（经营分已拆单店版 / 连锁版，利好单店）。

> **年度总判断**：系统化运营 + 全链路设计（公域→到店→私域会员体系）取代单点 / 碎片化运营；AI 本质是降本增效（降人力成本、提效率），不是直接挣钱；警惕 9.9 元低价洗流的「自杀行为」。

## 一、5A / 5A6C / 4L 人群资产模型（官方生意经口径）

> 关键背景：生意经新人群模型与**巨量云图同底层框架**，并在生活服务场景下对团购交易做了细分拆解。分两层：
> - **外层 5A**（A1 了解 → A2 吸引 → A3 问询 → A4 行动 → A5 拥护）：从机会到成交各阶段用户分布。
> - **内圈 6C**（C1 支付新客 → C2 核销新客 → C3 复购 → C4 忠诚 → C5 沉默 → C6 支付唤醒）：从生命周期视角对有交易用户细分。
> - **4L**（L1 潜在 / L2 新客 / L3 活跃 / L4 沉默）：更精简的四层模型，对总账户开放，门槛低于 5A6C。
>
> ⚠️ **口径铁律**：① 各阶段人群**完全互斥，按倒序优先级依次判断**（先判 A5/A4 再往下）；② **非融合小程序类成交不计入成交人群**；③ 5A 为天级粒度、自带时间窗（餐综近 15 天 / 酒旅近 60 天），超过窗口未再触达自动掉出；④ 历史至今仅核销一个次卡商品但分多天核销：5A 算 A4-2 核销行动，6C **不算核销新客**（算多天核销）。

### 1.1 5A 定义（餐饮综合行业口径，近 15 天窗口）

| 层级 | 含义 | 判定规则（满足任一即计入，互斥倒序） |
|------|------|----------|
| **A1 了解**（浅层触达） | 品牌曝光人群 | 近15天：本地推广告播放时长 0~10s；或团购商品卡曝光 1~2 次；或达人短视频播放 1~2 次；或自然内容(UGC) 评论/点赞/播放/分享 ≥1 次 |
| **A2 吸引**（一定深度） | 品牌吸引人群 | 近15天：本地推广告点赞=1 或播放 10~30s；或商品卡曝光 3~4 次 / 详情页曝光=1；或达人直播观看=1；或达人短视频点赞=1 / 播放3~7 / 播放30~60s / 完播=1；或商家账号(官号/职人/店员)直播观看=1；或 POI 详情页进入/商品点击/更多=1 次 |
| **A3 问询**（产生兴趣） | 品牌种草人群 | 近15天：本地推广告评论≥1 / 点赞≥2 / 播放≥30s / 分享≥1；或商品卡曝光≥5 / 详情页访问≥2；或达人直播评论关注送礼分享≥1 / 货架点击≥1 / 观看≥2 / 观看≥60s / 小房子点击≥1；或达人短视频评论≥1 / 点赞≥2 / 播放≥7 / 播放≥60s / 完播≥2 / 分享≥1；或商家账号同名触点 / 短视频评论点赞播放分享≥1；或 POI 详情页进入≥2 / 收藏≥1 / 点地图≥1 / 商品点击≥2 / 更多≥2 / 分享≥1；或**搜索商户相关内容 ≥1 次** |
| **A4 行动**（购买/核销） | 品牌转化人群 | 【历史至今未核销过 且 近30天支付成功 ≥1 单】+【历史至今核销天数 = 1 天】（次卡多天核销算 1 天） |
| **A5 拥护**（多次核销） | 品牌复购人群 | 【历史至今核销 ≥ 2 天】 |

### 1.2 5A 定义（酒旅行业口径，近 60 天窗口）
酒旅模型于上线后逐步回溯，口径整体放宽为 60 天：
- **A1**：近60天 本地推广告播放 0~10s；商品卡曝光 1~<3 次；达人短视频播放 1~<5 次；自然内容播放 1~<5 次；达人/商家直播观看=1（或商家短视频播放 1~<3）；POI 详情页进入=1。
- **A2**：近60天 广告点赞=1 或播放 10~<30s；商品卡曝光 3~<5 或详情页曝光=1；达人直播观看=2 或观看3~5min 或小时房点击=1；达人短视频点赞 1~<3 / 播放5~<10 / 播放1~<3min / 完播1~<3；商家直播观看=2 或观看30s~1min，商家短视频播放3~<5 / 播放30s~1min / 完播=1；POI 进入=2 或商品点击/更多=1；自然内容播放≥5 / 播放≥1min / 完播≥2。
- **A3**：近60天 广告评论≥1 / 点赞≥2 / 播放≥30s / 分享≥1；商品卡曝光≥5 或点击≥2；达人直播评论关注送礼分享≥1 / 货架点击≥1 / 观看≥3 / 观看≥5min / 小时房点击≥2；达人短视频评论≥1 / 点赞≥3 / 播放≥10 / 播放≥3min / 完播≥3 / 分享≥1；商家直播同名触点 / 短视频评论点赞分享≥1 / 播放≥5 / 播放≥1min / 完播≥2；POI 进入≥3 / 收藏≥1 / 点地图≥1 / 商品点击≥2 / 更多≥2 / 分享≥1；搜索≥1 次。
- **A4 行动**：近90天有支付成功（历史未核销过）。**A5 拥护**：历史至今核销订单数 ≥ 1 单（生意经以「历史至今」定义，突显长期复购价值；酒旅核销≥2单用户占比 >13%，有持续运营空间）。

### 1.3 6C 定义（内圈，餐饮综合口径）

| 人群 | 含义 | 判定规则 |
|------|------|----------|
| **C1 支付新客** | 历史纯新支付 | 历史未核销过 且 近30天支付成功 ≥1 天 |
| **C2 核销新客** | 历史纯新核销 | 历史核销 = 1 天 且 非沉默（同次卡分多天核销算多天，不算新客） |
| **C3 复购用户** | 复购老客 | 历史核销 ≥2 天 且 未满足忠诚规则 且 非沉默 |
| **C4 忠诚用户** | 品牌忠诚 | 历史核销 ≥2 天 且 满足忠诚规则 且 非沉默 |
| **C5 沉默用户** | 已流失 | 历史核销 ≥1 天 且 近 Y 天无核销 且 近30日未支付成功（Y：餐饮综合 90 天，医美 180 天） |
| **C6 支付唤醒用户** | 唤醒期 | 历史核销 ≥1 天 且 近 Y 天无核销 且 近30天支付成功天数 ≥1 |

**忠诚用户规则（餐饮）**：
- 规则1（窗口期90天3单，距今30天）：适用北京菜/新疆菜、快餐小吃(快餐/零食/面馆/饺子)、水果鲜货、西式快餐/简餐、咖啡厅。满足：近90天核销≥3单且最近核销≤30天；或近90天核销≥3单且>30天但近90天曾是官号粉丝/会员/有正向评价/收藏过商品门店/分享过商品门店；或近90天核销<3单且≤30天且具上述任一状态。
- 规则2（窗口期90天2单，距今30天）：适用其余美食三级品类。满足：近90天核销≥2单且≤30天；或≥2单且>30天且具上述任一状态。
- **综合类**：购物(商业街/数码家电/日用商超)、运动健身(球类) 用规则1（90天3单）；丽人-医美 用规则2（180天2单，距今120天）；其余综合品类窗口期90天。

### 1.4 4L 定义（更精简模型，对总账户开放）

| 层级 | 含义 | 餐饮综合口径 | 酒旅口径 |
|------|------|--------------|----------|
| **L1 机会/潜在用户** | 触达未成交 | 近15日触达未成交 | 近60日触达未成交 |
| **L2 新客** | 首购 | 支付未核销新客(近30天支付) 或 有核销新客(历史核销=1天且近90天有核销) | 支付未核销新客(近90天支付) 或 有核销新客(历史核销=1天且近365天有核销) |
| **L3 活跃用户** | 复购活跃 | 历史核销≥2天且非沉默；或历史核销≥1天且近90天无核销且近30天支付≥1 | 历史核销≥2天且非沉默；或历史核销≥1天且近365天无核销且近90天支付≥1 |
| **L4 沉默用户** | 流失 | 历史核销≥1天且近90天无核销且近30天未支付 | 历史核销≥1天且近365天无核销且近90天未支付 |

- **潜在用户中的「深度兴趣人群」即 A3(问询)**：餐饮近15天 / 酒旅近60天内达到 A3 阈值（见 1.1/1.2 的 A3 规则）的用户。
- **L1 触达判定动作**涵盖：搜索商户内容、本地推广告播放/点赞/评论/分享、团购商品卡曝光/详情页访问、达人短视频播放/点赞/评论/分享、达人/官号直播观看/评论/关注/送礼/货架点击/小时房点击、POI 详情页进入/商品点击/收藏/点地图/分享、自然内容(UGC) 互动。

### 1.5 八大人群（画像聚类，用于精准定向）
资深中产、新锐白领、精致妈妈、都市蓝领、城镇青年、GenZ（Z世代）、城镇中老年、都市银发。可结合不同人群特征定向做货盘、内容、投放策略（案例：德克士锁定精致妈妈/城镇青年/新锐白领，定向团品核销率 +X2pp；古茗桑葚新品沉默召回 7w+；幸运咖幸运冰撬动成交人群显著提升）。

### 1.6 5A6C 开通条件（平台「看人下菜碟」）
- 自动开通门槛（POI 数量）：**餐饮 ≥40、综合 ≥35、酒旅 ≥12**。
- 不满足但连续 3 个自然月每月支付人数(去重) ≥2000 且有明确意向 → 准备「商户ID + 近3月每月成交用户数截图(T/T+1/T+2) + 4L 不满足原因」，经**客户经理特殊提报**，每周三加白、周四可页面自主升级（超级管理员操作）。
- 5A6C 比 4L 复杂、分析难、分层量级少时看不到画像，故设门槛。中小商家默认用 4L 即可。

### 1.7 关键运营认知（官方口径）
- **A1~A3 = 机会人群（未成交），A4~A5 = 成交人群**。A3 是**距离成交最近的人群**，日常营销重点应围绕 A3 的获取与关系加深（种草转化是 ROI 最高的流转）。
- **触点唯一归因**：A1~A3 阶段每个用户仅归因给**最先达标**的触点（如先刷达人视频点赞到 2 次够格→归因「达人视频」，不重复算商品触点）；明细层（门店/视频分布）是全部访问人数、占比之和≠100%。
- **画像不一致是正常的**：商业投流只是获客渠道之一，自然流量（达人视频/直播/搜索/商品卡）带来的人群不受投放定向控制，整体画像是所有渠道叠加。查来源看 5A 人群资产的「触点分布」。
- **生服 vs 云图差异**：生意经以「商户账号维度」沉淀来客/本地推数据（偏向交易转化，单拆复购/忠诚/沉默/支付唤醒4个细分，A4-1/A4-2 周期为近365天便于沉默召回）；云图以「品牌维度」涵盖抖音全域（偏向品牌营销，A4/A5 周期多为365天）。授权云图后数据完全拉齐；未授权则生意经只展示生活服务域内数据。

## 二、生意经人群运营实操（核心能力 / 圈选 / 流转 / 诊断 / 场景）

> 入口：生意经 - 人群 - 人群资产（4L/5A6C）；抖音来客 - 顾客经营 - 人群运营（圈选人群包）。

### 2.1 核心能力模块
- **5A 分析**：A1~A3 看「自身触点分析」（用户最先因哪个触点达标、各触点明细）；A4/A5 看「自身成交分析 / 自身核销分析」（成交金额、成交商品、TOP核销门店分布）。
- **6C 分析**：支付新客→促核销；核销新客→促复购防沉默；支付唤醒用户→速促核销；复购用户→提频促忠诚；忠诚用户→维护客情高频消费；沉默用户→优惠召回。
- **人群总资产**：A1~A5 总和，可下钻八大人群分布、行业购买偏好（近15天同三级品类其他品牌购买的价格带/商品/渠道/核销时段）、行业营销偏好（视频类型/营销词/热搜词）、区域分布（省/市）。
- **同行对比 Benchmark**：相似品牌均值（平台推荐同品类）、自选品牌均值（自定义）、标杆均值（类目 TOP 动态均值）。覆盖核心概览/画像/偏好/区域3大模块。

### 2.2 人群包圈选 & 运营（来客-人群运营）
- 本期支持对 **5A6C、八大人群、所在地域标签**直接生成人群包，可与其他标签交并集计算，最终应用至**本地推 / 优惠券 / 营销触达**（需先申请人群运营中心权限，T+1 开通；仅总账户且已开通权限可用）。
- 抖音来客人群运营三大亮点：① **精准券定向发放**（自定义人群包，直播间/店内页多渠道领券）；② **零成本消息触达**（0 成本触达私域池，图文/券/商品/会员卡，通道「消息-团购消息」）；③ **本地推定向投放**（圈选后短视频/直播/图文多形态推广）。

### 2.3 人群流转 4 场景（可运营视角）
| 场景 | 定义 | 重点关注 |
|------|------|----------|
| **人群新增** | 公域(非5A) → 商户5A | 多少人从公域被转化，因哪些触点 |
| **认知加深** | A1/A2 → A3/A4/A5 | 浅层认知流转到深层兴趣/成交，哪些内容/商品最有效（加大投放） |
| **种草转化** | A3 → A4/A5 | A3 距成交最近，复盘转化原因并复用 |
| **提升忠诚** | A4 → A5 | 产生复购/多次核销 |

- 流转分析可下钻：八大人群分布、触点归因（最先达标触点）、触点-商家/达人直播、触点-商家/达人视频、触点-自然搜索、触点-支付/核销行为。

### 2.4 诊断 QA（人群下降排查）
- **单个人群下降** → 看该人群对应触点与流转；**A1/A2/A3 整体下降** → 看机会人群总量 + 触点/画像/城市归因；下降同时下一阶段上涨 → 多为前移转化而非流失。
- **A1 下降**：浅层曝光减少（查本地推/团购商品/达人短视频/自然内容触点）、商品卡曝光减少、达人或商家内容触达变弱、或已流转到 A2/A3/成交（查人群流转）。
- **A2 下降**：中度互动减少（广告点赞/播放时长/详情页曝光）、直播视频吸引力减弱、POI 详情页访问减少、A2→A3 承接变弱。
- **A3 下降**：高意向行为减少（搜索/POI/直播/短视频高意向触点）、搜索需求减少、详情页深度动作减少、或已被成功转化进入成交（查成交人群规模）。
- 全部基于 **15/60 天滚动窗口**：超窗未再触达自动掉出，须持续拉新。

### 2.5 高频运营场景
- **直播/大场人群策略（前-中-后）**：前——结合过往转化好/蓄水多/目标人群定**目标八大人群**，看 A3 偏好(购买商品/搜索词/营销内容/视频风格)定立意货盘；中——每日监测是否获取到目标人群；后——对比活动前后人群资产变化、关系是否加深、原因是什么、复用相似策略。
- **调整货盘拉新**：货盘价格——看 A3 目标八大人群在同品类其他品牌购买的价格带/组品，反向补齐自家货盘再定向投放；商品场景——看目标人群核销时段（早/中/下午/晚/宵夜）构造「下午茶」「夜宵局」等场景组品。

## 三、流量分配模型 M1-M3 + 商城 / 搜索 / POI

抖音流量由三大来源构成，结构决定增长质量：

| 来源 | 含义 | 典型占比 |
|------|------|----------|
| M1 内容流量池 | 推荐流（内容驱动） | 70–80% |
| M2 自然交易流 | 搜索 + 商城等交易导向 | 10–20% |
| M3 付费广告流 | 本地推 / 千川等付费 | 8–12% |

- 流量三大入口：**推荐流、搜索、商城**。其中 **搜索 + 商城 = 精准流**，代表用户主动意图，转化效率远高于纯推荐。
- 健康账号应逐步提升精准流（搜索 / 商城）占比，而非只吃 M1 推荐。

### 商城流量（至少 7 大来源，≠ 商品卡）
澄清概念：**卡片**是宽泛 UI 概念（含商品卡 + 门店卡 + 笔记卡 + 链接预览卡）；**商品卡**是货架场中代表「商品」的特定卡片（非直播 / 非短视频成交）。**商城流量 ≠ 商品卡流量**，至少 7 种来源：
1. 商品卡（推荐页 / 同城页整张大卡）
2. 搜索列表流量
3. 订单中心「猜你喜欢」推荐
4. 频道活动（限时秒杀 / 品牌馆）
5. 商城首页主动访问
6. 团购频道（附近美食等列表）
7. 榜单 / 订单来源等冷门入口

> 误区纠正：把「投图优化 / 商品详情优化」等同于商城流量是错的——那只是卡片链接玩法之一；卡片又只属商城流量的一部分。

### 搜索流量「两头吃」（小蓝词策略）
- 搜索流是最精准的免费流量之一，**商城流量值钱正因为精准**。搜索分两支：自然搜（吃品牌力）+ 草收（种草收割一体）。
- **埋钩子引发主动搜索**：视频中设「信息缺口」（提专业词 / 进阶法但不解释），激发用户搜该词；结合最新算法指标**回看率、收推互动**设计钩子。
- **两头吃**：① 从推荐流引用户去搜索（开精准入口）；② 提前占领搜索结果——预判用户会搜什么词（如「三分四榜一热度」），确保该词第一页有你的内容。关键词布局在标题 / 文案 / 标签 / 画面字幕，内容质量（完播 / 互动）+ 账号垂直度决定搜索排名。

### POI 锚点（白色 vs 绿色）
- **白色锚点**：打卡点（如灯塔定位发风景视频），是**内容词**，偏内容流量，不指向交易。
- **绿色锚点**：带团购链接的 POI，是**交易词**，流量更大比例倾向有交易标签 / 门店种草标签的人群。
- 同城频道里内容池流量通常优于交易池流量；发短视频要按目标（要内容曝光还是要成交）选锚点类型。

## 四、成交效率公式与本地生活 ROI 生死线

**成交效率 = 成交金额 / 商品曝光指数**
- 行业基准：直播 2.49、短视频 8、其他（图文 / 橱窗等）10。
- 短视频效率高于直播，说明短视频「用更少曝光换更多成交」，是本地生活性价比最高的形态。

**本地生活 ROI 生死线：**
在「核销率 50% + 毛利率 50%」双 50% 基准下，**全域 ROI 需 ≥ 10 才不亏本**。
- 推导逻辑：团购 GMV 经核销打折（50%），再经毛利打折（50%），实际回款仅 25%；要覆盖投放 + 履约 + 获客成本，ROI 必须拉到 10 倍以上。
- 给方案时务必先确认用户的真实核销率与毛利率，再反推可承受的投放 ROI 上限。
- **低价引流陷阱**：9.9 元洗流看似拉低 ROI 门槛，实则稀释高净值人群标签、损害后端盈利，属于「自杀行为」；应用短视频种草 + 精准私域导入为高客单套餐打精准标签。

## 五、2026 核心打法：「洗人群」三阶段

单纯堆 A1/A2 无效，要用「洗」把注水人群洗成真资产：

1. **拉人群资产**：先放量把 A1→A3 池子做大（内容 + 投放 + 矩阵）。
2. **做高 A3 配比**：用搜索词、收藏钩子、分享机制抬高 A3 在资产中的比例。
3. **洗成真 A3 / A4**：用本地推精准消耗真 A3、活 A4、A5，把「看过」洗成「买过 / 复购」。

> 本地推投放优先级：真 A3 > 活 A4 > A5（老客唤醒）。**优秀户的 ROI 与消耗最高的统一形态是「商品卡 / 团购卡」**，而非普通短视频投流。

## 六、数据分析顺序（不可跳层）

诊断标准链路：**流量 → 人群 → 门店 → 商品 → 账号 → 经营**
- 经营数据（GMV、核销、复购）放倒数第二，用于**验证**前几环的判断是否成立。
- 从流量层先判断「有没有人看」，再到人群层判断「看的人对不对」，再到门店 / 商品判断「承接得住吗」，最后用经营数据闭环验证。

**直播间优化铁律：最牛的优化手段全在直播间之外。**
- 直播间进人少 / 不精准 → 先排查：三率（滚动 24h）→ 经营分 → 评价分 → **人群包**（总数、精准度、是否够大）。单店仅 2000 总人群资产，直播间必然没人。
- 本地推投产问题，核心手段也在本地推之外（素材、人群包）。
- **断崖**：直播间流量突然暴跌，常因三率滚到临界值触发限流（三率滚动 24h）；先看后台三率、违规提醒、经营分。

## 七、短视频黄金数据标准 + 搜索钩子

| 指标 | 优秀线 |
|------|--------|
| 推荐流占比 | > 90% |
| 点赞率 | ~3% |
| 分享率 | ~1% |
| 收藏率 | ~1% |
| 5 秒完播率 | > 40% |
| 2 秒跳出率 | < 40% |

- 推荐流占比 < 90% 说明内容还在被「社交 / 关注」推，未进入大池；2 秒跳出高说明开头没钩住。
- 进阶：用「埋钩子 + 回看率 + 收推互动」设计连环钩子（如「评论扣 3 告诉你福利在哪段 → 回看第 1 分 30 秒找暗号 → 核销后发图抽券」），把单条视频从「观看价值」延伸到「引导—搜索—学习」深度互动，获取低成本高精准流量。

## 八、脚本结构：黄金六秒 + 2113544 法则

**黄金六秒法则**：前 6 秒决定生死，必须在一开口就抛出钩子（反常识 / 冲突 / 利益点），否则用户划走。

**2113544 法则（一条成片的结构骨架）：**
- **2** 秒钩子：开头 2 秒强钩住（痛点直击 or 悬念 or 利益）
- **1** 个痛点：精准戳中目标人群的麻烦
- **1** 个方案：给出你的解法 / 产品
- **3** 个卖点：分点讲清价值（少即是多）
- **5** 秒信任：用证据建立信任（数据 / 案例 / 资质 / 对比）
- **4** 次互动：引导评论、点赞、收藏、分享
- **4** 步转化：清晰的成交路径（点击 / 领券 / 到店 / 私信）

## 九、7 天养号（新号冷启动）

目标：让系统判定为「真人活跃号」，拿到正常流量权重。
- **模拟真人**：不批量操作、不秒赞秒评、不连发。降低风控、打准标签、提升初始权重。
- **频次**：每天 3–4 个时段，累计 ≥ 90 分钟。
- **设备**：一机一卡一号，不共用设备 / IP。
- 初始权重决定进入的流量池大小（通常 300–500），为后续破池做数据铺垫；养号期间正常刷同类内容、互动建立兴趣标签，再发垂直内容。

## 十、直播打法体系（观看模型 / 成交模型）

### 1. 底层逻辑：你给抖音人 / 钱，抖音给你人 / 钱
- **观看模型**：全国泛流量（进直播间问「主播好 / 在哪」的人），年龄收入跨度极大，不一定买。
- **成交模型**：真实种草、打算来的精准人群。
- **数据分级**：浅层数据（停留 / 点赞 / 评论 / 分享但不买）做好 → 系统推**观看模型**的人；深层数据（成交）做好 → 系统推**精准成交人群**。
- **排水**：主动把不想要的泛流量冲出去（不理他），避免被泛流量拉偏。
- **转移焦点**：用「做过青岛攻略的扣 1」等引导精准人群做浅层数据，重建你想要的观看模型。最佳状态：给你做数据的人恰好也是精准成交模型。

### 2. 直播间两大原则
- **确定性（基础）**：画面每 2 秒让消费者直观 get 核心卖点——卖点可视化（景区 / 自助餐有；普通商务酒店无）；用贴片、标签、右下角商品弹窗抵抗随机性（用户随机进出，靠画面兜底）。
- **转移焦点（进阶）**：把泛流量引导 / 排走，聚拢精准人群。

### 3. 冷启动：直播前 7 天打爆 A1/A2
- 开播前 7 天用廉价成本把门店周边几公里人群的 A1/A2 打爆（无论是否当下需要），第 8 天开播。
- 单店可倒私域、不投浅层，效果与转化远好于开播当天砸钱投浅层数据。

### 4. 流速 / 断崖
- 流速由浅层数据（停留、评论、灯牌、转发、收藏、UGC）与深层数据共同决定。
- **断崖** = 三率滚到临界值触发限流（三率滚动 24h）；先查后台三率、违规提醒、经营分。

### 5. 成交密度 vs 成交规模
- **成交密度** = 单位时间内订单量爆发能力（与金额无关），考核爆发力。
- **成交规模** = 订单量 × 客单价。

### 6. 行业话术倒推
- 不同人群决定素材 / 话术：绿色推拿要用「五大三粗大妈」而非「身材小姐姐」——你的人群是谁，就倒推直播间呈现。

### 7. 直播 / 卡片 / 短视频分工
- 直播是「持续爆单引擎」非终点；卡片（商城）承接静默成交；短视频负责种草与搜索入口。三者协同，而非只靠直播。

## 十一、经营分 / 服务分 / 四分四榜一热度

### 四分（店铺综合评价体系）
- **经营分**：门店经营分 80+ 才有推荐流量，建议 90+（抖音来客左上看）。部分类目已**上不封顶**（如单店创意韩餐 205、单店餐饮 210）。经营分已拆**单店版 / 连锁版**，利好单店，指向「区域化」。
- **服务分**：金冠 / 银冠 / 铜冠（抖音来客服务分查询，建议金冠）。
- **违规分**：满分 100（违规中心查），减到 90 以下**不能直播、不能设团购秒杀**。
- **信用分**：100（门店蓝 V - 创作者中心 - 团购查）。

### 四榜（曝光与转化关键）
- **人气榜**：近期投稿 + 评价（30 天投稿 / 打卡 ≥ 30 人）。
- **收藏榜**：近期收藏 + 分享（收藏 ≥ 100 人）。
- **好评榜**：评价推荐度（有效评价 ≥ 10 条，一图 + 30 字以上）。
- **热销榜**：近期订单 / 销售额（核销 ≥ 30 单，金额 ≥ 1000 元）。

### 一热度：POI 热度
- 店铺综合实力体现，巨量算数可查；通过短视频 / 直播 / 矩阵化经营等多维度提升，热度越高流量越大。

## 十二、职人 / 达人方向（马场理论）

### 职人（员工号）
- 本质：**降本增效**（员工发视频替商家省成本）+ 帮平台「造草根的神」（大力出奇迹，如小华理发师）。
- **马场理论**：抖音流量不平均，是马太效应——3 匹马抢 3 棵草时末位还能分 0.1；3000 匹马抢时末位分不到。**职人流量下降 = 人多了竞争多 = 风口**，说明赛道要卷内容 / 素材，不是退场信号。

### 达人三方向
- **酒旅**：死磕**核销**（核销居源逼），平台只看核销。
- **餐饮 / 综合**：高粉网红化 / IP 化（如乌拉拉）。
- 达人三条出路：① 超强销售力（实卖且能核销）；② 人带货的种草型（铁粉跟买）；③ 开发商家 / 代运营。

### 账号矩阵分工（3451 框架内）
- 职人达人化 / 达人品宣化 / 老板 IP 化 / 素人矩阵化；矩阵用于放大声量、铺长尾、降低单点风险。

## 十三、算法原理要点（理解即可，用于诊断）

- **赛马机制 + 多目标排序**：内容进入流量池后按多目标（完播、互动、转化）赛马胜出才进更大池。
- **内容标签提取**：标题 / 文案 / 画面字幕 / 语音识别共同打标签，决定推给谁。
- **多路推送**：推荐、搜索、同城、商城等多路并发，按标签匹配。
- **热度衰减 / 推流周期**：多数内容推流集中在发布后 1 天（热度衰减快），需持续更新维持。
- **去重 / A 封脸**：搬运、低质、同质化会被去重限流；原创 + 差异化是护城河。
- **预测模型 + 梯度下降**：系统预测用户行为并动态调权——理解「为什么推给你」有助于设计钩子。

## 十四、反向导流与经营分（原九，重排）

- **反向导流模式（线上→线下）**：抖音内容 / 团购把用户导到线下门店，门店体验与核销反哺线上权重，形成「线上种草—到店核销—复购安利」闭环。
- **经营分改革**：经营分满分已突破原 120 限制，高分档引导商户「付费 / 做深运营」，纯自然免费流量红利收窄，需把经营分维护纳入日常（团购质量、核销、好评、履约、服务分、四榜）。

## 十五、2026 趋势与底层规律

- **十大趋势**要点：搜索流与商城流权重上升、本地生活核销为王、矩阵化作战、老板 IP 化、A3 资产真实化、内容即货架、付费与自然的协同（M1+M3 互补）、经营分驱动、私域反哺公域、数据化复盘常态化。
- **不可能三角**：极致低价、良好现金流、优质体验——三者难以同时成立。任何方案都要替用户权衡取舍，不能既要又要还要。
- **AI 定位**：降本增效（降人力、提效率），不是直接盈利；用 AI 是为在流量变贵时守住线下品质 + 公域获客的财务模型。
- **低价引流陷阱**：9.9 元洗流稀释高净值标签，损害后端盈利，坚决规避。
- **系统化 + 全链路**：放弃单点运营，做公域→到店→私域会员的完整链路设计。
