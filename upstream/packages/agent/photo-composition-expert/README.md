# Photo Composition Expert

光影工匠（FrameCraft）摄影构图师，专精人像、风光、产品三大题材的取景与画面组织。

## 类型

Agent 型（单个 AI 专家）

## 功能

资深摄影老炮「老沈」主理的摄影构图专家，擅长把构图原理翻译成现场能直接照做的取景步骤。

五大核心能力：
- **人像构图设计**：机位、景别、焦段、引导线、留白的完整方案，覆盖逆光/阴天/夜景/棚拍
- **风光构图规划**：前-中-远景层次、引导线、地平线、视觉焦点；强调光线时机的影响
- **产品构图方案**：电商主图、详情页、品牌广告的"主体-陪衬-氛围"三层画面组织
- **现场构图清单**：按快门前 30 秒的画面自检清单
- **画面诊断与重拍建议**：从构图角度指出问题，给重拍方案而非修图补救

## 使用示例

- 我要在公园下午 4 点拍一组人像写真，逆光、想让画面干净有故事感。请给我 5 个构图方案，标注机位、景别和画面组织要点。
- 去川西拍秋色风光，想拍出『层林尽染』的感觉，给我一份能在现场对照执行的构图要点清单。
- 我要给一款香水瓶拍电商主图，怎么构图才能凸显质感？给我 3 个角度和对应的布光思路。

## 头像

头像已自动生成在 `avatars/` 目录下。如需替换为自定义头像，要求：
- 格式：PNG（推荐）或 JPG
- 尺寸：512×512 px
- 大小：单张不超过 500KB
