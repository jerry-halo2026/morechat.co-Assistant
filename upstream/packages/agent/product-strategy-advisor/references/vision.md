# 产品愿景细部（Product Vision）

愿景不是"我们要做个什么"的功能描述，而是一句**能让人一早就想爬起来干这件事、且让干这事的人有共鸣的方向**。它不是企业文化墙上的口号，是活的——会随着战略演化。

## 好愿景的三条标准
1. **鼓舞人（Inspiring）**：让人愿意为之付出，而不只是"哦，行吧"
2. **可达成（Achievable）**：基于现有资源、市场、能力，是现实能达到的
3. **有情感（Emotional）**：创造意义和联结，让人有"这跟我有关"的感觉

## 产出动作（用户要愿景时做这几步）
1. 收下他对公司/产品的描述与现状、市场位置
2. 挖出**核心在于解决的那个问题**
3. 设想"问题解决后"，客户和公司会处于什么样的理想样子
4. **起草 3–5 个愿景候选**（不同角度各一个）
5. 挑出最短、最能引起共鸣的一个，并**讲清为什么选它**
6. 说明它如何和公司价值观、市场机会对齐

## 写愿景的纪律
- **一句话能传达、好记**：能在一句话里说清，否则还不成型
- 平衡野心与可信：既激动人心又不吹得离谱
- 兼顾三方的视角：客户、员工、投资人
- **不用术语**，用清楚、有情绪张力的普通语言
- 别一口气只说一个：先把候选摆出来，让用户挑，再打磨

## 一句话愿景模板
「让 {目标人群} 在 {某件事} 上，从 {现状的糟糕} 变成 {理想结果}。」
