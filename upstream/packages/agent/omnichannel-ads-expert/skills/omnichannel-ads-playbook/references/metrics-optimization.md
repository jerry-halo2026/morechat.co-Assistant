# 指标口径与优化决策手册

## 一、核心指标口径与公式

| 指标 | 公式 | 看什么 | 常见误区 |
|------|------|--------|----------|
| CPM | 消耗 / 曝光 × 1000 | 流量竞争度与素材 eCPM 竞争力 | 只看 CPM 低就高兴，忽略人群质量 |
| CTR | 点击 / 曝光 | 素材吸引力与人群匹配度 | 用标题党刷 CTR，CVR 反而崩 |
| CPC | 消耗 / 点击 | 单点击成本 | 与 CVR 割裂看，低 CPC 高 CPA 常见 |
| CVR | 转化 / 点击 | 落地页与承接质量 | 忽略转化事件埋点错误导致的假性下降 |
| CPA | 消耗 / 转化 | 核心考核成本 | 只看整体 CPA，不看分人群分素材 |
| ROI / ROAS | 收入 / 消耗 | 回收能力 | 归因窗口不一致导致数据不可比 |
| 频次 | 曝光 / 触达人数 | 素材疲劳度 | 频次高但无新素材补充，必然衰退 |
| 素材 eCPM | CTR × CVR × 出价 × 1000 | 平台排序的隐形核心 | 不知道这是决定跑量的关键变量 |

**关键认知**：信息流平台按 eCPM 排序，你的出价再高，素材差也拿不到量；素材好但出价过低，同样跑不动。两者是乘法关系。

## 二、漏斗排查法（先定位层级，再给动作）

```
曝光量 → 点击率 CTR → 转化率 CVR → 客单价/复购/退款 → ROI
  ↓          ↓            ↓                ↓
 CPM/出价   素材钩子      落地页/链路      人群质量/产品力
 定向宽度   人群匹配      埋点正确性       归因口径
 计划数量   素材疲劳      加载速度         客单价与退款率
```

**铁律：一次只改一层。** 同时改出价、定向、素材，出问题后无法归因。

### 分层排查动作表

| 问题层级 | 诊断信号 | 优先动作 |
|----------|----------|----------|
| 曝光不足 | 计划花不出去钱、CPM 明显低于同行业 | 放宽定向、提高出价 10-20%、增加计划数、换素材提升 eCPM |
| CTR 偏低 | 有曝光但点击率低于行业基准 | 换首帧钩子、换封面、检查人群是否匹配、检查版位与时段 |
| CVR 偏低 | 点击不少但转化少 | 查埋点是否正确触发、落地页首屏是否与素材一致、加载速度、转化路径步数 |
| CPA 达标但 ROI 差 | 成本可控但回收不行 | 查人群质量、客单价、退款率、归因窗口，必要时回调前端激进素材 |
| 成本突然飙升 | 同等设置下 CPA 单日上涨 > 30% | 先查素材是否衰退、是否有异常流量/刷量、再看出价与竞争环境变化 |

## 三、诊断决策树

```
成本超标？
├─ 曝光够吗？
│  ├─ 不够 → 定向太窄/出价太低/素材 eCPM 差 → 放宽定向 → 提价 10-20% → 补新素材
│  └─ 够
│     ├─ CTR 低于基准？ → 换钩子/换封面/换人群
│     └─ CTR 正常，CVR 低？ → 查埋点 → 对齐落地页 → 压缩转化路径
│
跑不起量？
├─ 计划数够吗？（冷启动期建议多计划并行）
├─ 出价有竞争力吗？（参考后台建议出价区间）
├─ 素材数量够吗？（单计划下多创意赛马）
└─ 账户/主体是否处于冷启动或受限状态
│
成本达标但不放量？
├─ 提价幅度过小 → 每次 10-20%，观察 24h
├─ 定向过窄 → 逐步放开年龄/地域/兴趣
├─ 预算限制 → 单计划预算是否限制了模型探索
└─ 素材供给不足 → 增加新素材进入赛马
```

## 四、冷启动规则

| 平台 | 冷启动判断 | 不达标时的动作顺序 |
|------|------------|--------------------|
| 巨量引擎 | 计划 3 天内累计转化 ≥ 20 个视为基本跑通 | 先查出价与定向宽度 → 再补素材 → 最后才考虑重建计划 |
| 腾讯广告 | 广告 3 天内累计转化 ≥ 20 个 | 同左，优先调出价与版位，不建议频繁关停重建 |
| Meta Ads | Ad Set 一周 50 个转化退出学习期 | 减少编辑次数、合并受众、提高预算而非频繁调整 |
| Google Ads | 智能出价需足够转化样本 | 转化少时先用最大化点击积累数据，再切 tCPA/tROAS |

**通用禁忌**：冷启动期频繁关停重建、单次调价超过 20%、一天内多次改动同一计划——都会让模型反复重置。

## 五、出价与放量策略

### 出价调整规则
- 提价/压价单次幅度控制在 **10%-20%**，调整后至少观察 **24 小时**
- 目标成本下调要更保守：先 10%，跑稳后再继续
- 放量期提价与补素材同步进行，避免只提价导致成本失控

### 放量节奏（三阶段）

| 阶段 | 目标 | 预算策略 | 关注指标 |
|------|------|----------|----------|
| 测试期（1-7 天） | 找到能跑通的方向 | 小预算多计划多素材并行 | 转化数、CTR、CVR |
| 放量期（7-21 天） | 把跑通的方向放大 | 集中预算给 Top 20% 的计划与素材 | CPA 稳定性、成本波动幅度 |
| 稳定期（21 天+） | 控成本、延生命周期 | 保留主力计划 + 持续补充新素材 | ROI、素材衰退速度、复购 |

### 止损规则（写进方案里）
- 单计划 3 天累计消耗 > 3 倍目标 CPA 且 0 转化 → 关停
- 单条素材 3 天 CTR 连续下滑 > 30% → 下架并启用备份素材
- 单平台连续 7 天 CPA > 1.5 倍目标且无改善 → 暂停该平台，把预算挪到已跑通的平台

## 六、归因与数据口径注意事项

1. **先对齐口径再谈优化**：不同平台的归因窗口（点击后 1 天 / 7 天 / 30 天）和归因模型（末次点击 / 数据驱动）不同，跨平台横向比 CPA 前必须统一口径。
2. **后端数据才是真相**：前端 CPA 达标但后端 ROI 差，通常说明素材过度承诺或人群质量有问题，此时应回调前端，而不是继续放量。
3. **埋点优先排查**：CVR 异常下跌时，先确认转化事件是否正常上报，再怀疑素材和落地页。
4. **iOS 与隐私政策影响**：海外投放注意 SKAN 回传延迟与数据缺失，不要用实时数据做短周期判断。
