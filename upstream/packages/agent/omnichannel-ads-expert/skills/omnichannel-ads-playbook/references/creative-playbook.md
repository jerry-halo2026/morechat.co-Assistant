# 投放素材创意手册

> 素材是信息流投放里最大的变量。一条好素材的价值远高于把出价调高一档。

## 一、创意矩阵（先搭矩阵，再写脚本）

先穷举组合，再挑优先级最高的 5-8 个方向批量生产：

```
创意方向 = 目标人群 × 核心痛点 × 使用场景 × 产品卖点 × 钩子类型
```

| 人群切片 | 核心痛点 | 典型场景 | 主推卖点 |
|----------|----------|----------|----------|
| 价格敏感型 | 怕买贵、怕踩坑 | 比价、等大促、看测评 | 性价比、保价、无理由退换 |
| 效率导向型 | 时间成本高、流程繁琐 | 通勤、加班、带娃 | 省时、一步到位、自动化 |
| 品质导向型 | 怕廉价、怕不安全 | 送礼、自用升级 | 材质、认证、口碑 |
| 从众型 | 不知道选哪个 | 刷内容、看榜单 | 销量、评分、达人同款 |
| 焦虑型 | 怕错过、怕落后 | 抢名额、限时 | 稀缺、限时、专属 |

每个切片至少配 2 个不同的钩子类型，避免素材同质化互相抢量。

## 二、钩子库（前 3 秒定生死）

| 钩子类型 | 句式模板 | 适用产品 |
|----------|----------|----------|
| 痛点直击 | 「还在为 X 发愁？90% 的人都踩过这个坑」 | 通用，尤其工具/服务 |
| 反常识 | 「别再买 X 了，真正好用的是这个」 | 消费品、3C |
| 权威背书 | 「做了 8 年 X 的师傅说，选它就看这三点」 | 高决策成本产品 |
| 价格锚点 | 「专柜 899，今天这个渠道不到 300」 | 电商、本地生活 |
| 场景代入 | 「每天通勤两小时的人，一定要看这个」 | App、出行、效率工具 |
| 对比测评 | 「我买了三款 X，只有这款留下来了」 | 消费品、美妆 |
| 结果前置 | 「用了一个月，我的 X 从 A 变成了 B」 | 教育、健康、健身、SaaS |
| 悬念留白 | 「这一步做错，后面全白费」 | 通用 |

规则：同一个计划下的多条创意，**首帧钩子必须不同**，否则视为同一素材重复投放。

## 三、视频口播脚本结构（15-40 秒）

| 段落 | 时长 | 作用 | 写法要点 |
|------|------|------|----------|
| 钩子 | 0-3s | 留住人 | 一句话点出痛点或反常识，画面同步出现最强视觉冲击 |
| 共情/放大 | 3-8s | 建立关联 | 把痛点场景化，让用户觉得「说的就是我」 |
| 方案出现 | 8-18s | 引出产品 | 产品自然出场，讲清「凭什么是它」 |
| 信任证明 | 18-28s | 消除疑虑 | 实测画面、数据、资质、真实用户反馈 |
| 行动号召 | 28-35s | 促转化 | 明确指令 + 利益点，CTA 与落地页首屏话术一致 |

### 脚本交付格式

```
【创意方向】价格敏感型 × 痛点直击
【时长】30s
【首帧】画面 + 大字标题
【口播】逐句台词，标注时间码
【字幕/花字】关键信息的视觉强化点
【BGM 与节奏】
【CTA】
【对应落地页首屏话术】
```

## 四、标题与文案

### 标题产出的 5 个角度
1. 痛点型：「还在手动整理表格？这三步自动搞定」
2. 利益型：「新用户立减 200，仅限今天」
3. 好奇型：「为什么老用户都不买 A 而选 B」
4. 数据型：「30 天复购率 68%，它做对了什么」
5. 人群型：「给每天加班到十点的你」

每次交付至少给 5 组标题，覆盖不同角度，并标注各组对应的测试假设。

### CTA 写法
- 弱 CTA（适合冷流量）：了解详情 / 看看别人怎么用 / 免费试用
- 中 CTA：立即领取 / 预约体验 / 0 元试用 7 天
- 强 CTA（适合热流量/再营销）：立即下单 / 限时抢 / 今日特惠

CTA 必须与落地页按钮和首屏承诺一致，不一致会显著拉低 CVR。

## 五、素材衰退的判断与应对

### 衰退信号
- 同一条素材连续 3 天 CTR 下滑 > 30%
- 同等曝光量级下转化成本上涨 > 20%
- 频次明显上升而转化数持平

### 迭代顺序（不要一上来就重做）
1. **换首帧**（3 秒钩子 + 封面图）— 成本最低，优先试
2. **换脚本结构**（改叙事顺序、换口播人、换场景）
3. **换创意方向**（回到创意矩阵换一个切片重来）

### 预防机制
- 建立素材周更节奏：每周至少补充 5-10 条新素材进入赛马
- 每个跑量方向保留 2-3 条备份素材，避免主力素材突然衰退断量
- 跑量素材做衍生版本（横竖版、不同时长、不同口播），延长生命周期

## 六、素材与落地页一致性检查清单

| 检查项 | 说明 |
|--------|------|
| 首屏承诺一致 | 素材主打的利益点必须在落地页首屏直接兑现 |
| 价格/优惠一致 | 素材说的优惠在落地页必须能找到，且无隐藏门槛 |
| 视觉风格一致 | 素材色调、产品外观与落地页不要割裂 |
| CTA 一致 | 素材 CTA 与落地页按钮文案一致 |
| 加载速度 | 首屏 3 秒内可交互，否则 CVR 明显受损 |
| 转化路径步数 | 每多一步流失一档，尽量压缩到 2 步以内 |
