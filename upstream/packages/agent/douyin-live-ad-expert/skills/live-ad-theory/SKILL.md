# 抖音直播间投流 · 基本理论（判断规则库）

本技能是投流诊断的推理底座，规则卡全文在 `references/core-theory.md`。

## 何时必须加载

以下任一情况出现，**先加载本技能再下判断**，不许凭感觉：

1. 需要判定问题落在哪一层（人群 / 素材 / 画面 / 机制 / 时段）
2. 需要区分两个表象相似但处置相反的故障（如素材衰退 vs 人群失效）
3. 需要判断是否收窄人群、收窄到什么程度
4. 需要判定画面该不该改、改什么
5. 需要判定某品类的用户决策因子
6. 数据拿不到，需要决定降级口径

## 使用原则

**先判层，再判点。** 层判错了，后面所有优化都是白花钱。

**规则卡格式**：现象 → 判因 → 动作。找不到完全匹配的规则时，取最接近的一条并说明偏差，不要跳过规则直接给结论。

## 规则卡索引

### 一、对用户理论：对的人看到对的产品

| 编号 | 规则 | 一句话判据 |
|---|---|---|
| T1 | 人货错配优先判定 | 曝光够但 CTR 低于赛道均值 → 判人货不匹配，不是素材差 |
| T2 | 高曝光低停留的归属 | 停留短 → 先查人群错位，再查画面承接 |
| T3 | CTR 与 GPM 背离 | CTR 达标但 GPM 低 → 泛流量，收窄人群 |

**职责边界（铁律）**：只对曝光、点击、CTR、进入率、流量成本负责 —— 即「进来的人准不准」。停留、转化、复购、退货由客户运营团队与主播承接。对用户说透这条，但它是**分工事实，不是免责话术**。

### 二、抖音算法逻辑

| 编号 | 规则 | 一句话判据 |
|---|---|---|
| A1 | 标签收敛 | 新号/换品前期人群发散 → 窄而准打成交，收敛后再放宽 |
| A2 | 流量池与赛马 | 在线卡量级 → 预算买不到层级跃迁，跃迁靠单位效率 |
| A3 | 素材衰退 vs 人群失效 | 换素材后 GPM 恢不恢复，一刀切开两种故障 |
| A4 | 极速 vs 专业推广的选择逻辑 | 测素材/测人群用极速，跑长期主力用专业 |
| A5 | 出价与预算调整节奏 | 单计划单日调整 ≤1-2 次，单次出价调整 ≤10-15% |

**A3 判别表（实操最易判错、最烧钱的一处）**：

| 判别点 | 素材衰退 | 人群失效 |
|---|---|---|
| 换素材后 CTR | 明显恢复 | 不明显 |
| 换素材后 GPM | 同步恢复 | 不恢复 |
| 投放时长特征 | 同一素材跑了多天 | 换素材也无效 |

### 三、画面逻辑

**核心立场**：画面影响的是「进入率」和「前 3 秒停留」，这两个数据在投放后台可直接读到 —— 所以画面问题**可以做数据归因，不是玄学**。

| 编号 | 规则 | 一句话判据 |
|---|---|---|
| V1 | 进入率异常 | CTR 正常但进入率低 → 素材承诺与落地场景不符 |
| V2 | 高在线低成交 | 画面留住了人但没交易感 → 缺价格锚、缺机制提示 |
| V3 | 人群-画面对齐检查 | 不花钱就能改，优先级高于加预算 |

### 四、用户需求与决策因子

| 编号 | 规则 | 一句话判据 |
|---|---|---|
| U1 | 决策因子四类归类 | 价格敏感 / 功效导向 / 颜值认同 / 信任依赖 |
| U2 | 因子-画面-人群三线对齐 | 三条线各打各的 → 转化平平的真正原因 |
| U3 | 邻赛道借人 | 判据是决策因子同层，不是品类标签相近 |

### 五、数据缺失时的估算口径

| 缺失项 | 降级路径 | 标注 |
|---|---|---|
| 赛道 GMV 水位 | 锚点公式取估算值 | `[估算] 锚点公式` |
| 成交人群画像 | 邻赛道画像 + 决策因子推导 | `[估算] 邻赛道推导` |
| 对手账号数据 | 该层级公开可见表现做定性判断 | `[估算] 定性推断` |
| 用户自身数据 | **必须索取，不可估算** | 无 |

**硬性要求**：`[估算]` 值必须在同句或紧邻处写明依据；下游引用时**继承** `[估算]` 标记，不得被写成事实。
