| 通路 | 准入 | 关键规则 | 标注 |

**累计扣满 10 分永久关闭带货、蒲公英、投流全部商业化功能。**【行业整理，需回后台核对】

## 三、抖音（2026 年有两次结构性调价，必读）

### 3.1 佣金结构（商家设的是两笔独立费率，不是从一个池子里切）

```
商家设置：达人推广佣金率  +  团长服务费率
              ↓                  ↓
      达人交平台技术服务费   团长交平台技术服务费（= 团长服务费 × 10%）
```

| 计划类型 | 佣金可设区间 | 调整限制 |
|---|---|---|
| 普通计划 | 1%–50% | **设置后 7 天内仅能下调 1 次，每次幅度 ≤5%** |
| 定向计划 | 0%–80% | — |
| 专属计划 | 0%–50% | — |

> **「7 天内仅能下调 1 次且幅度 ≤5%」是个隐形陷阱**：大促前把佣金拉高冲量，
> 大促后想降回来会被卡住（30% 降回 15% 需要至少 3 次调整、跨 21 天）。
> **佣金策略必须提前 3 周规划。**【行业惯例】

### 3.2 【重大变更一】佣金率下限提到 5%

| 项 | 内容 |
|---|---|
| 变更 | 精选联盟商品佣金率下限**从 0%–1% 提高至 5%** |
| 节奏 | **2026-04-01** 首批五类目（休闲食品、医疗器械及保健用品、水饮冲调、母婴用品、书籍杂志报）；**2026-04-15** 扩至全品类 |
| 豁免 | 黄金足金、二手奢侈品、二手 3C 等少量类目 |
| 标注 | 【公开报道】建议以精选联盟后台实际可设区间复核 |

> 🔴 **对 KOC 运营的含义**：**"0 佣挂车做口碑"这条路基本被堵死。**
> 低毛利标品的 KOC 铺量成本结构性上升至少 5 个点，**必须重算盈亏平衡**。

### 3.3 【重大变更二】达人技术服务费从统一 10% 改为五档分级（2026-07-08 全网生效）

| 等级 | 基础扣费 | 返还 | **实际费率** |
|---|---|---|---|
| A | 10% | 全额返还 | **0%** |
| B+ | 10% | 返还 3%–5% | **5%–7%** |
| B | 10% | 无 | **10%** |
| C | 上调至 20% | 无 | **20%** |
| D | 上调至 40% | 无 | **40%** |

- **更新节奏**：每月 8 日更新上一自然月评级；当月 9 日至次月 8 日的订单执行当期费率；
- **评级五维**：合规经营 / 结算健康度 / 稳定经营 / 内容创作能力 / 带货综合能力；
- **稳定经营的量化门槛**：视频达人**每月新增 ≥6 条有效挂车视频**；直播达人每月 ≥3 场有效挂车开播；
- 触发 D 级的典型情形：批量搬运、AI 生成虚假对比图、售假、单月售后退货率远超类目均值三倍以上。

标注：【官方·转述】两来源交叉一致；**分级结果以达人后台「服务费等级」实际显示为准**。

> 🔴 **三个可落地动作**：
> 1. **招募 KOC 时必须问对方当前服务费等级**。同样 20% 佣金，A 级到手 20%、D 级只到手 12%
>    —— 对 D 级达人来说，同样的佣金吸引力打了 4 折，这不是话术能解决的；
> 2. **"每月 ≥6 条有效挂车视频"是官方给出的活跃度及格线**，直接拿来当筛选阈值：
>    近 30 天挂车视频 <6 条的账号，大概率不是在认真做带货。这是免费借用平台已做过的筛查；
> 3. **退货率被写进评级** → 如果你的品退货率高于类目均值，招募难度会系统性上升。

### 3.4 其他费率与时效

| 项 | 规则 | 标注 |
|---|---|---|
| 小黄车技术服务费 | 订单**固定 6%**，从实际支付金额中扣除，**不参与后续佣金计算** | 【官方·转述】 |
| 精选联盟推广者技术服务费 | 推广费 × 10%（**已改为按合规与经营表现分层，见 3.3**） | 【官方·转述】 |
| 结算基数 | 2025-06 起由「实付 − 运费」调整为「**实付 + 主播券 + 平台券 + 支付通道补贴 − 运费**」 | 【官方·转述】 |
| 星图平台服务费 | 客户侧：指派/共创/招募任务 5%，投稿任务 10%；达人侧：自然人 5%、MCN 3% | 【官方规则】 |
| 星图自审时限 | **客户须在达人上传视频后 3 天内确认或要求修改，超时自动确认** | 【官方规则】 |
| 星图 CPM / CPE 口径 | `CPM = 任务金额 ÷ 播放量 × 1000`；`CPE = 任务金额 ÷ (点赞+评论+分享)` | 【官方规则】 |

> ⚠️ **CPE 口径陷阱**：星图 CPE 的分母**只算点赞+评论+分享**，**不含完播、不含收藏**；
> 分子用的是**任务金额**（含平台服务费的下单金额），不是达人到手金额。
> 内部报表若把收藏或完播算进互动，跟星图后台必然对不上。
> 另外星图投后数据**只追踪 45 个自然日**，复盘请统一取"发布后第 45 天"快照。

### 3.5 团长（要铺量找招商团长，要内容找服务商）

| 维度 | 招商团长（官方角色） | "服务团长"（行业口语，非官方术语） |
|---|---|---|
| 收入来源 | 团长服务费（走平台结算） | 服务费/月费/坑位分成（多为线下合同） |
| 核心职责 | 双向撮合：帮商家找达人、帮达人选品 | 达人履约管理、内容把控、排期、复盘 |
| 平台约束 | 保证金、等级考核、技术服务费 | 无平台约束（也无平台保障） |
| 适用 | **铺量** | **做内容** |

**谈团长时问这三个官方字段**（比听他自述池子大小有用得多）：
1. 你现在什么等级（V1–V5）？
2. 近 30 天**动销达人数**是多少？（挂在池子里 ≠ 动销，动销数才进平台考核）
3. **跃迁达人数**？（能不能把达人做起来，而不只是薅现成的）

团长入驻要求：保证金 **2 万元**；权限保留考核为近 90 天结算订单量 ≥100 单且 GMV ≥1 万元，
三次不达标永久收回权限。【官方·转述 / 经验值，需后台核对】

## 四、微信小店（私域 KOC 分销的官方口子）

### 4.1 推客带货的三方结构

```
商家 ──设置「机构服务费」──▶ 推客带货机构 ──自行拆分──▶ 推客（KOC）
```

【官方规则】"商家只需设置**机构服务费**，推客佣金由机构自行分配设置，从机构服务费中扣除"；
佣金推广比例区间 **0–90%**。

**三种模式**：
| 模式 | 路径 | 适用 |
|---|---|---|
| 一 | 商家入驻优选联盟 → 设普通/定向推广 → 机构 API 取商品 → 上架自有小程序 → 推客分享 | 大多数商家 |
| 二 | 商家授权自营内容（直播/短视频/文章）→ 机构取内容 → 推客分享 | 有内容资产的品牌 |
| **三** | **商家自注册成为联盟带货机构** → 开通推客功能 → 自研推客小程序 → 自己招募推客 | **自建 KOC 分销体系的合规路径** |

> **模式三是"自建 KOC 军团"的正解**：相比在小程序里私搭一套分销，走这条路有平台身份背书。

### 4.2 染色时效（归因）——私域分销的核心杠杆

| 场景 | 窗口 |
|---|---|
| 推客分享商品链接，用户从**非内容场景**购买 | **30 天** |
| **内容场景**（短视频/直播/公众号/服务号）分享 | **3 天** |
| **3 天内首次下单** | **延长至 30 天** |

> 🔑 **这条规则决定了私域 KOC 的打法**：推客首触后的**前 72 小时是唯一的机会窗口**。
> 只要 72 小时内撬动任意一笔下单（哪怕 9.9 元引流品），这个用户后续 30 天的复购都算这个推客的。
> **落地动作**：① 首触话术必须绑一个低价钩子品；
> ② KPI 里单独考核「**72 小时内首单转化率**」，不要只看 GMV。

### 4.3 帮卖机构（微信生态的"团长"）

【官方规则】供货带货机构（出货）↔ 帮卖带货机构（推广）：
**帮卖机构服务费不得超过供货机构服务费的 90%**；费率**调高立即生效、调低次日 0 点生效**；
每机构支持 2,000 个合作机构。

> **注意**：微信生态里"团长/招商"官方对应的是**帮卖带货机构（机构主体）**，不是自然人。
> 个人招商团长通常需挂靠或注册机构主体 —— 这与抖音招商团长可个人开通不同。

### 4.4 分销层级红线

微信侧对多级分销的处置最严（封禁分享/支付能力直至封号），
且**官方规则从未成文写出"允许两级"**——"两级以内"是行业解读，不是平台承诺。
详见 `koc-compliance-guard/references/platform-rules.md`。

## 五、素材银行：把 KOC 内容变成可反复消耗的素材

### 5.1 抖音侧三条链路

| 链路 | 计费 | 关键参数 | 标注 |
|---|---|---|---|
| **A 素材集市**（无需重新建联） | 授权费 = **素材投流消耗 × X%** | **单素材封顶 ￥20,000**；28 天计费周期 T+7，第 30 天扣款；建议账户余额 ≥1 万；**达人拒绝授权后无法再次申请** | 【官方规则】 |
| **B 一口价授权**（下单时就买） | 固定金额 | **≥20 元且 ≤任务金额的 50%**；授权范围含二创；多平台不重复收费；**达人授权长期有效**；授权费部分同样计 5% 平台服务费；推送完成后不支持退款 | 【官方规则】 |
| **C 视频推送至投放平台** | 无额外授权费（需达人同意） | **默认授权投放时长 30 天**（原为"不限-3650 天"），**最长 365 天**；推送账户 ID 上限 500 个；千川/本地推要求 **4s ≤ 时长 ≤ 300s**（巨量营销可到 60min）；招募任务超 90 天无法推送 | 【官方规则】 |

**两条选择规则：**
```
一口价成本 = F（20 元 ≤ F ≤ 任务金额 × 50%）
分成成本   = 预计投流消耗 S × X%
→ F < S × X% 时选一口价；反之选素材集市
→ 素材集市单素材封顶 2 万，所以超大消耗素材反而分成链路更划算
```

**三个必须写进 SOP 的坑：**
1. **默认授权只有 30 天** —— 按老习惯以为"永久可投"的团队，素材会在第 31 天集体失效。台账里"授权到期日"要设提醒；
2. **千川/本地推限 300 秒** —— KOC 常见的 5–8 分钟长测评直接不合规，入库时按时长分流；
3. **先内容后投流** —— 已投放过商业素材的内容不可再做内容营销投放，顺序反了素材就废了。

### 5.2 小红书侧

蒲公英报备笔记 / 合作码 / 合作广场 三条通路（见第二节）。
**大前提：没有报备或授权的"私下笔记"不能用聚光投流。**

### 5.3 授权六维（最容易翻车的地方）

合同里必须逐项写清，**默认不能想当然归品牌方使用**：

| 字段 | 必须写清 | 常见坑 |
|---|---|---|
| 授权平台 | 具体到「巨量广告/千川/本地推/DOU+/聚光/朋友圈」逐个勾选 | 只写"用于广告投放"，投朋友圈时被主张越权 |
| 授权期限 | 起止日期（不要只写"长期"） | 写了"长期"但没写平台字段，跨平台失效 |
| 授权地域 | 中国大陆 / 全球 | 出海复用时无授权 |
| 授权用途 | 付费投放 / 自然分发 / 落地页 / 线下物料 / 电商详情页 | 只授"投流"，结果用到详情页 |
| 剪辑权限 | 是否允许二创、到什么程度（换字幕/配音/封面/重剪） | 星图一口价明确含二创，其他链路不一定 |
| 转授权 | 是否可授权给经销商/代理商/服务商账户 | 分销体系铺开时全部要重签 |

### 5.4 收益结构（背公式，不背结论）

```
单条内容入库总成本 = 商单报价 + 素材授权费 + 平台服务费
内容复用率        = 被二次投流的内容条数 ÷ 当月 KOC 产出内容总条数   ← 建议月度 KPI，红线 <10%
素材边际成本      = 累计授权费 ÷ 该素材带来的投流消耗
复用摊薄后单篇成本 = 单篇有效内容成本 ÷ (1 + 复用深度)
```

**素材银行的收益来自三处**（缺一不可）：① 省下的素材生产费；② 复用原视频互动数据带来的冷启动加速；
③ 自然流量 + 营销流量双触达带来的额外自然曝光。
