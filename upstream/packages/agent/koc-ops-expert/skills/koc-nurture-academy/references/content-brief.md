# 内容 Brief 八板块 + 选题库 + 爆文拆解

> Brief 是**前置约束**工具，不是事后挑刺的清单。Brief 字段越全，审稿轮次越少。
> 审稿超过 1 轮的项目，问题在 Brief，不在 KOC。

---

## 一、Brief 八大板块字段清单

| 板块 | 字段 | 必填 | 写法要求 |
|---|---|---|---|
| **A 项目信息** | 项目名 / 期次 | ✅ | |
| | 内容窗口期（起止日期，**精确到日不到小时**） | ✅ | 精确到小时会伤自主感 |
| | 对接人 + 响应时效 | ✅ | 写清"几点前回复" |
| **B 目标与受众** | 本期目标：认知 / 搜索承接 / 转化，**三选一** | ✅ | 一次只给一个目标，给两个等于没给 |
| | 目标受众画像（1–2 句，写人不写标签） | ✅ | "刚生完二胎、家里有洗烘一体机的妈妈"＞"25-35 女性" |
| | 对应用户旅程的哪一环（建议 A3 主动搜索） | 建议 | 决定选题从"用户会搜什么"倒推 |
| **C 产品信息** | 产品名 / SKU / 规格 / 价格 | ✅ | |
| | **核心卖点 ≤3 条** | ✅ | 多于 3 条必然稀释 |
| | 使用方法与注意事项 | ✅ | |
| | 竞品对比口径：可说什么 / 不可说什么 | ✅ | 防贬低竞品的法律风险 |
| **D 内容要求** | 形式（图文/短视频）与数量 | ✅ | |
| | 最低规格：图片张数下限 / 视频时长区间 / 正文字数下限 | ✅ | 用**下限**不用精确值 |
| | 必须出现的元素：产品正面露出、包装、**具体使用场景** | ✅ | 场景比卖点重要 |
| | **可选选题 3–5 个（供自选）** | ✅ | 选单不派单，成本为零但显著影响持续产出 |
| | 参考样例 2–3 篇，**逐篇标注"参考它的什么"** | ✅ | 只给链接不标注等于没给 |
| | 禁止事项：禁用词、绝对化用语、竞品名、医疗功效表述 | ✅ | 合规刚需 |
| | 话题标签 / @账号 / 定位要求 | ✅ | |
| **E 合规** | **是否需标注「广告」及标注方式** | ✅ | 判据见下方 |
| | 是否走平台官方报备/合作工具 | ✅ | 以平台最新规则为准 |
| | 未成年人 / 特殊人群出镜限制 | ✅ | |
| **F 授权（最常被漏）** | 二次使用范围：品牌自有渠道 / 付费投放 / 线下物料 / 电商详情页 | ✅ | 漏了它，之后想拿去投流要重新一个个谈 |
| | 授权期限、是否可修改剪辑、是否署名 | ✅ | |
| | 肖像使用范围 | ✅ | |
| **G 流程** | 是否需审稿、**审稿轮次上限（建议 1 轮）**、审稿时效 | ✅ | |
| | 发布后回执方式（链接提交表单） | ✅ | |
| | 数据回收时点（T+7 / T+30） | ✅ | 决定复盘节奏 |
| **H 对价** | 报酬形式、发放条件、发放时点 | ✅ | 用「达标即得」而非「按名次分档」 |
| | 违约与返还条款（删稿、提前下架、未按期发布） | ✅ | |

### 「要不要标广告」的判据

《互联网广告管理办法》（市场监管总局令第 72 号，2023-05-01 施行）**第九条**：
除法律、行政法规禁止的情形外，**通过知识介绍、体验分享、消费测评等形式推销商品或者服务，
并附加购物链接等购买方式的，广告发布者应当显著标明「广告」。**

落到动作上：

| 内容形态 | 是否附购物链接/购买方式 | 处理 |
|---|---|---|
| 纯体验分享，无链接、无购买引导 | 否 | 一般不强制标注，但仍受《广告法》对虚假宣传的约束 |
| 体验分享 + 挂商品链接 / 团购码 / 小黄车 | **是** | **必须显著标明「广告」** |
| 平台官方合作工具下单的商单 | 是 | 走平台报备，平台会加合作标识；仍需按平台规则确认标注是否充分 |

> 细则与平台侧要求见 `koc-compliance-guard` 技能，那里有完整的红线清单与发布前自检表。

## 二、可直接复制的 Brief 模板

```markdown
# {品牌} × KOC 内容 Brief｜{项目名} 第 {N} 期

## A 项目信息
- 内容窗口期：{开始日} ~ {结束日}（当天 24:00 前发布即可）
- 对接人：{姓名}（微信 {号}），工作日 12 小时内回复
- 提交回执：发布后把链接填到 {表单链接}

## B 本期目标与受众
- 目标（本期只有一个）：{认知 / 搜索承接 / 转化}
- 目标读者：{一句人话描述，写具体的人和处境}
- 我们希望读者看完后：{一句话，写行为不写感受}

## C 产品
- 产品：{名称} / {规格} / {到手价}
- 核心卖点（只讲这 3 条，其他都不用讲）：
  1. {卖点 1 —— 用用户的话说，不用参数说}
  2. {卖点 2}
  3. {卖点 3}
- 使用方法：{步骤}
- 注意事项：{禁忌 / 适用人群}
- 关于竞品：可以说 {…}；不要说 {…}（不要点名贬低任何品牌）

## D 内容要求
- 形式：{图文 ≥6 图 + 正文 ≥300 字 / 视频 30~60 秒}
- 必须出现：产品正面露出 ≥2 处；{具体使用场景}；{包装/细节}
- 可选选题（挑 1~2 个，也可以自己提，提前跟我说一声）：
  1. {选题 1}｜适合：{什么样的你}
  2. {选题 2}
  3. {选题 3}
  4. {选题 4}
  5. {选题 5}
- 参考样例：
  - {链接 1} —— 参考它的**开头 3 秒怎么把问题摆出来**
  - {链接 2} —— 参考它的**对比图排版**
- 标签：{#话题1 #话题2}；@{品牌号}；定位：{可选}
- 禁止：
  - 绝对化用语（最/第一/国家级/100%/永久）
  - 医疗功效表述（治疗/根治/替代药物/无副作用）
  - 点名贬低竞品
  - 未经验证的效果承诺（"7 天瘦 10 斤"这类）

## E 合规
- 本次内容 {需要 / 不需要} 标注「广告」：{说明理由，见判据}
- 走 {平台官方合作工具 / 自然发布}
- {未成年人出镜要求}

## F 授权
- 你的内容我们希望能用于：{品牌自有账号转发 / 电商详情页 / 付费投放}
- 授权期限：{12 个月}；{可以 / 不可以} 二次剪辑；{署名方式}
- 肖像使用范围：{同上范围内}
- 如果你不同意其中某一项，告诉我，我们按你同意的范围来。

## G 流程
- 审稿：{需要 / 不需要}；如需，**只审 1 轮**，我们 24 小时内给完整意见
- 数据回收：发布后 T+7 与 T+30 各回收一次

## H 对价
- {样品 {价值}，无需退还}
- {发布并通过验收后 {N} 个工作日内发放 {金额} 后置稿费}
- {带货佣金 {X}%，平台结算}
- 未按期发布或删稿：{返还样品或不结算稿费}
```

## 三、选题库怎么生成（从"用户会搜什么"倒推，不从卖点倒推）

**方法：A3 搜索词倒推法。** 用户在主动搜索时看到的"同类人真实体验"，是硬广覆盖不了的，
这是 KOC 内容唯一不可替代的战场。所以选题不能从"我想说什么"出发。

### 四步生成

1. **列搜索词**：把用户可能搜的词穷举成四类
   - 品类词：`{品类} 推荐`、`{品类} 怎么选`
   - 痛点词：`{症状/困扰} 怎么办`
   - 比较词：`{A} 和 {B} 哪个好`、`{品牌} 值得买吗`
   - 场景词：`{人群}{场景} 用什么`
2. **看搜索结果页缺什么**：搜一遍，看现有内容没回答的问题（这是最容易出爆文的位置）
3. **一个搜索词对一个选题**，标题里必须自然带上这个词
4. **按人群切面复制**：同一选题换 2–3 类人群再各出一条

### 选题模板库（10 类，可直接套）

| # | 选题类型 | 标题公式 | 适合谁写 | 对应搜索意图 |
|---|---|---|---|---|
| 1 | 痛点解决 | 「{痛点场景}，我是这么解决的」 | 有真实困扰的用户 | 痛点词 |
| 2 | 使用前后对比 | 「用了 {N} 天，{可视化变化}」 | 效果可拍的品类 | 品类词 |
| 3 | 选购避坑 | 「买 {品类} 前一定要看的 {N} 点」 | 做过功课的人 | 怎么选 |
| 4 | 横向对比 | 「{A} vs {B}，到底差在哪」 | 手上有多个产品的 | 比较词 |
| 5 | 场景清单 | 「{场景} 我的 {N} 件必备」 | 生活方式类账号 | 场景词 |
| 6 | 翻车与纠正 | 「我踩过的坑：{错误用法}」 | 老用户 | 长尾问题 |
| 7 | 人群定制 | 「{特定人群} 怎么用 {产品}」 | 属于该人群的人 | 人群 + 品类 |
| 8 | 极简教程 | 「{N} 步搞定 {任务}」 | 表达清晰的人 | how to |
| 9 | 数据实测 | 「实测 {N} 天，记录了这些数字」 | 愿意做记录的人 | 值得买吗 |
| 10 | 回答型 | 「有人问我 {问题}，统一回答」 | 有粉丝互动的账号 | 具体疑问 |

> 给 KOC 的时候，**一次给 3–5 个，让他挑**。给 10 个等于没给。

## 四、爆文拆解四问（用来做样例讲解，也用来复盘）

对每一篇跑出来的内容，只问四个问题，写成 4 行：

1. **它替谁说了话？** —— 读者在评论区说"这就是我"的那一句是什么？
2. **前 3 秒/前 1 屏给了什么？** —— 是问题、是结果、还是反常识？
3. **它可信在哪？** —— 哪个细节让人相信这是真用过的？（时间、翻车、具体数字、不完美的地方）
4. **它把人带去哪？** —— 收藏、搜索、还是直接下单？动作有没有被明确引导？

**拆完必须转成可复制的东西**：一句可套用的标题公式 + 一个可复制的结构 + 一个可复用的镜头/图位。
只夸"这篇写得好"是无效复盘。

## 五、半成品素材包（提高出稿率最有效的单点动作）

面对空白页是出稿率最大的敌人。给素材包不是替 KOC 写内容，而是**降低起步门槛**：

| 素材 | 说明 |
|---|---|
| 产品高清图 / 免抠图 / 场景图 | 让不会拍摄的人也能出图文 |
| 3 个标题模板（带空格填空） | 「{场景}，我用 {产品} 解决了 {问题}」 |
| 正文结构骨架 | 开头 2 句 → 使用过程 3 点 → 我的感受 → 一句提醒 |
| 数据/成分说明卡 | 防止 KOC 自己编参数（合规风险最高的地方） |
| 禁用词表 | 直接给一份可搜索的清单 |
| BGM / 转场模板（视频） | 降低剪辑门槛 |

> **注意边界**：素材包提供的是"结构和素材"，**不是替 KOC 写好体验**。
> 体验必须是他自己的——一是合规（虚假宣传风险），二是真实感是 KOC 内容唯一的护城河，替他写就把这个护城河填了。
