# FIT-6 六维评分卡 · 评分锚点与反刷量

> 分数不是算出来的，是判断出来的。脚本只做换算与排序，**每一维必须给理由**。
> 阈值除标注来源者外均为【经验值/待校准】。

---

## 一、六维与权重

| 维度 | 权重 | 判断什么 |
|---|---|---|
| **F** 人货匹配 Fit | 25 | 内容领域与品类的相关度 × 粉丝画像与目标人群的重合度 |
| **I** 内容力 Ideation | 20 | 近 30 天更新稳定性、表达与审美、批次内的爆款能力 |
| **T** 粉丝质量 Trust | 15 | 数据真实度（互动结构）、粉丝画像与目标人群的一致性 |
| **C** 转化力 Conversion | 20 | 历史带货/挂链表现、评论区求购信号、内容形态是否易转化 |
| **O** 配合度 Ops | 10 | 响应速度、改稿意愿、历史履约记录 |
| **$** 成本效率 Cost | 10 | 寄样 + 稿费 + 佣金的综合成本 vs 预期产出 |

**分层线**：≥80 直通带货位（L2/L3）｜65–79 主力内容位（L1）｜50–64 体验官观察（L0）｜<50 不建议合作。

## 二、逐维评分锚点

### F 人货匹配（25 分）

| 分段 | 锚点 |
|---|---|
| 21–25 | 内容就在该品类里，且粉丝画像与目标人群重合度高（性别/年龄/城市线级都对得上） |
| 15–20 | 相邻品类（如母婴 → 家清），画像大致匹配，内容可自然带入 |
| 8–14 | 泛生活/泛娱乐账号，靠"场景植入"才能勉强关联 |
| 0–7 | 完全不相关，或粉丝画像与目标人群**匹配度 < 30%** → 直接淘汰 |

> 人货不匹配是最贵的错误，**靠 Brief 补不回来**。宁可空着档期也不要用不匹配的人。

### I 内容力（20 分）

| 分段 | 锚点 |
|---|---|
| 17–20 | 近 30 天更新 ≥8 篇且稳定，有过批次内 P95 内容，排版/表达明显高于同粉丝量级 |
| 12–16 | 近 30 天更新 ≥4 篇，表达清楚，图文/视频完成度达标 |
| 7–11 | 更新不稳定（月 1–3 篇），内容能看但没亮点 |
| 0–6 | 近 30 天几乎不更新，或内容明显搬运/模板化 |

### T 粉丝质量（15 分）

按互动结构判断，**先跑一遍 `audit` 子命令**：

| 分段 | 锚点 |
|---|---|
| 13–15 | 评论/点赞 0.02–0.10，收藏/点赞达品类线，评论内容与主题相关、评论者主页有真实内容 |
| 9–12 | 结构基本正常，个别指标偏低 |
| 4–8 | 有一项异常（评论极低 / 收藏极低 / 涨粉曲线陡增） |
| 0–3 | 多项异常 → **命中 V1 一票否决** |

### C 转化力（20 分）

| 分段 | 锚点 |
|---|---|
| 17–20 | 有挂链带货记录且出过单，评论区常有求链接/问价 |
| 12–16 | 有挂链记录但单量不明，或评论区有明确购买意向信号 |
| 7–11 | 没带过货，但内容形态适合转化（测评、对比、清单类） |
| 0–6 | 纯图美/情绪类内容，无转化动作，也没有购买意向信号 |

> 转化力弱但种草强的人**不要淘汰**，放在内容位，不背 GMV 指标 —— 别用出单率去考核他。

### O 配合度（10 分）

| 分段 | 锚点 |
|---|---|
| 9–10 | 私信 2 小时内回复，明确接受改稿与报备，有良好履约历史 |
| 6–8 | 回复在 24 小时内，配合度正常 |
| 3–5 | 回复慢或对流程反复确认，需要多次跟进 |
| 0–2 | 拒绝报备/标注、拒签履约条款 → **命中 V4/V5 一票否决** |

### $ 成本效率（10 分）

| 分段 | 锚点 |
|---|---|
| 9–10 | 纯佣可谈或只需寄样，综合成本低于同层均值 |
| 6–8 | 小额后置稿费可谈，成本合理 |
| 3–5 | 报价偏高但内容力能撑住 |
| 0–2 | 报价明显偏离，或要求高额前置买断 |

## 三、五条一票否决（命中即拒，不看总分）

| # | 否决项 | 判断依据 |
|---|---|---|
| **V1** | **数据异常** | 互动结构不合常理、粉丝画像失真（见第四节阈值） |
| **V2** | **人设风险** | 有争议言论、违规记录、负面舆情历史；账号有平台风险标 |
| **V3** | **竞品绑定** | 近 90 天接过直接竞品商单且无排他约定 |
| **V4** | **拒绝合规** | 不接受平台报备，或不愿按规则标注「广告」 |
| **V5** | **结算风险** | 要求高额前置买断且拒签履约条款 |

## 四、反刷量信号阈值（做成审号 checklist）

| # | 信号 | 判定阈值 | 严重度 |
|---|---|---|---|
| 1 | **互动率异常高** | **高于行业均值 2–3 倍 → 进人工复核**（不要因为"数据好"直接录用） | 高 |
| 2 | 评论用户 ID 重复 | 重复率 **>40%** → 淘汰 | 高 |
| 3 | 粉丝画像错位 | 与目标人群匹配度 **<30%** → 淘汰 | 高 |
| 4 | 评论/点赞比 | **<0.01** 高度疑似刷赞；>0.30 疑似互刷或引战 | 高 |
| 5 | 收藏/点赞比 | **<0.03** 异常；功能性品类建议 ≥0.15，情绪性品类 ≥0.08 | 中 |
| 6 | 粉赞比倒挂 | 正常账号"总赞藏数"一般应 > 粉丝量 | 中 |
| 7 | 涨粉曲线陡增 | 短期急剧攀升且无爆款内容支撑 → 淘汰 | 高 |
| 8 | 评论者主页空白 | 随机点 10 个评论者，**≥4 个主页空白/无原创 → 淘汰** | 中 |
| 9 | 评论时间集中爆发 | 评论集中在某个时间段大量出现 | 中 |
| 10 | 评论内容模板化 | 与内容无关、高度同质 | 中 |

**真实评论的三个特征**：内容与主题相关、时间分布均匀、评论者主页有真实内容。

### 投前 15 分钟审号 SOP

| 步 | 动作 | 淘汰线 |
|---|---|---|
| 1 | 看平台侧是否有风险提示/违规标 | 有 → 淘汰 |
| 2 | 拉近 30 天内容列表，看有无孤立高峰 | 单条 > 中位数 10 倍且无内容合理性 → 复核 |
| 3 | 点开最近 3 条内容评论区，随机点 10 个评论者主页 | ≥4 个空白 → 淘汰 |
| 4 | 评论文本查重 | ID 重复率 >40% → 淘汰 |
| 5 | 对粉丝画像与目标人群 | 匹配度 <30% → 淘汰 |
| 6 | 看涨粉曲线 | 短期陡增无爆款支撑 → 淘汰 |
| 7 | 看互动率 | 低于大盘及格线 → 淘汰；**高于均值 2–3 倍 → 标黄进深审** |

### 投后 72 小时验真（刷量最藏不住的窗口）

| 时点 | 检查 | 判定 |
|---|---|---|
| T+2h | 互动增长曲线形态 | 真实内容是"前快后慢的衰减曲线"；刷量常见"阶梯式跳变" |
| T+24h | 评论文本相似度 + 评论者 ID 唯一性 | 触发任一信号 → 启动扣款条款 |
| T+72h | 挂链存活 + 数据截图回传 | 挂链 ≥72 小时；截图按合同时限提交 |
| T+7d | UTM / 专属码归因 | 区分真实种草与自然流量 |

## 五、数据从哪里取（不要编）

| 平台 | 工具 | 让用户取这些字段 |
|---|---|---|
| 小红书 | 蒲公英后台 / 千瓜 / 新红 | 粉丝量、近 30 天笔记数、近 10 篇平均互动、粉丝画像（性别/年龄/城市）、商单占比、笔记阅读单价 |
| 抖音 | 星图后台 / 蝉妈妈 / 飞瓜 | 粉丝量、近 30 天作品数、CPM/CPE、粉丝画像、带货口碑分、历史带货类目 |
| 微信 | 小店优选联盟后台 | 带货者层级、历史带货类目、成交来源 |
| 自有 | CRM / 企微 SCRM | 复购次数、评价字数、社群发言频次、是否有公开社交账号 |

> **三方工具的局限（必须对用户说清楚）**：千瓜官方说明其粉丝活跃度计算的抽样比例为
> **10%–70%**，传播指数"**不排除误差较大的情况出现**"，阅读量/CPM/CPE/销售额均为**预估数据**。
> → **适合排序与粗筛，不适合做结算依据，也不适合作为对外承诺的数字。**
> 结算只认平台后台 + 自有 UTM/暗号归因。

### UTM 命名规范（做达人级 ROI 的前提）

```
utm_source   = 平台          xhs / dy / ks / wx
utm_medium   = koc           固定值，区别于 kol / ads
utm_campaign = 项目_月份      newprod_202608
utm_content  = 达人ID_内容ID  koc10231_note0457   ← 必须带达人 ID，否则做不了达人级 ROI
utm_term     = 内容主题标签
```
