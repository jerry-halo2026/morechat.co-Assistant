# KOC 招募六池矩阵 + 话术 + 各平台合规通路

> 整理时点 2026-08-17。平台门槛与规则以后台最新公告为准。
> 转化率与成本区间除标注来源者外，均为【经验值/待校准】，必须用首批实测替换。

---

## 一、六池：KOC 从哪里来

按"真实性 × 成本 × 起量速度"排序，**优先级从上到下**：

| # | 池 | 从哪捞 | 真实性 | 成本 | 起量速度 | 最大的坑 |
|---|---|---|---|---|---|---|
| **1** | **老客池** | CRM / 订单库：复购 ≥2 次 且 有分享行为 且 有公开社交账号 | **最高** | **最低** | 慢 | 多数品牌根本没打通订单与社交账号的对应关系 |
| **2** | **私域社群池** | 企微社群、粉丝群、会员群里活跃发言与晒单的人 | 高 | 低 | 中 | 群里活跃 ≠ 会产内容，要看有没有公开账号 |
| **3** | **内容搜索池** | 站内搜品类词/竞品词，捞真实发过相关内容的真人 | 高 | 中 | 中 | 人力密集；私信有条数限制 |
| **4** | **平台达人池** | 蒲公英招募 / 星图 / 精选联盟 / 合作广场 | 中 | 中 | **快** | 容易招到"接单号"（商单占比高的号） |
| **5** | **员工与导购池** | 内部员工、门店导购的账号化（KOS） | 中高 | 低 | 快 | 归因与提成冲突要先解决，否则店端不配合 |
| **6** | **老带新池** | 现有 KOC 推荐 | 高 | 低 | 慢 | **合规敏感**：奖励只能挂钩被推荐人的真实产出，不能挂钩人数 |

### 各池的落地动作

**① 老客池（最该先做的一池）**
```
筛人 SQL 思路：
  近 180 天订单数 ≥2
  且 有过评价/晒单/分享行为
  且 手机号或微信可触达
  且（有公开社交账号 或 愿意提供）
→ 按 RFM 排序，高价值（R高F高M高）优先，其次「一般价值」（高频低客单：使用频次高＝素材多）
```
**关键补充**：RFM 只解决"从存量里挑谁"，不解决"他会不会产内容"。必须加一个 **C（Content）维度**：
是否有公开社交账号 / 近 90 天是否发过任何 UGC / 历史晒单或评价的字数。

**② 私域社群池**
从企微/社群里筛：近 30 天发言 ≥3 次、晒过单、问过使用方法的人。这些是"深度兴趣"人群，
KOC 候选浓度最高。触达方式：群内公开招募 + 对疑似高潜者一对一私聊。

**③ 内容搜索池（最容易被忽略、质量最好的一池）**
```
搜索词四类：品类词、痛点词、比较词、场景词
筛选：内容是真人第一人称体验 + 近 30 天有更新 + 不是明显的接单号
动作：按平台规则私信邀约（用品牌号，不用个人号）
```
**捞竞品评论区**也属于这一池：在竞品笔记评论区里问问题、吐槽的人，是最精准的候选。

**④ 平台达人池**
| 平台 | 通路 | 硬门槛 |
|---|---|---|
| 小红书 | 蒲公英「招募合作」 | 达人需 ≥1,000 粉 |
| 小红书 | **合作码**（笔记级授权，唯一合规触达 <1,000 粉的通路） | 素人需实名 + ≥18 岁 + **粉丝 <1,000**（涨到 1,000 自动失效） |
| 小红书 | **合作广场**（批量申请素人授权，需报白） | 粉丝 <10,000 + 实名 + ≥18 岁 + 素人身份（非专业号/明星/开店账号）+ 非蒲公英博主 |
| 抖音 | 星图**指派任务 / 投稿任务** | 品牌方直接定人，无统一粉丝门槛 |
| 抖音 | 星图**招募任务（通用规则页）** | 规则页原文写「达人主端粉丝数量应达到 **10000 以上**」 |
| 抖音 | 星图**招募任务-一口价 / 带货达人团** | 一口价产品页写「达人粉丝门槛 **1K–500W**」；带货达人团的 KOC 团写明「粉丝量级 **1K–10W** 为主」 |
| 抖音 | 精选联盟（普通/定向/专属计划） | 达人侧有橱窗与带货权限要求 |
| 微信 | 微信小店优选联盟 / 推客带货 | 推客机构侧需入驻；商家可自注册为机构（自建 KOC 分销的合规路径） |

> ⚠️ **抖音侧最容易搞错的一件事**：招募任务的粉丝门槛**按子类型不同**。
> 通用招募任务规则页写的是 1 万粉以上，但**一口价模式（1K–500W）与带货达人团（1K–10W）
> 对千粉 KOC 是开放的**，后者正是官方给 KOC 批量分销准备的产品。
> **两条官方页面口径不一致**（整理时点 2026-08）——**下单前必须在星图后台确认你走的是哪个子类型**。
> 做 KOC 批量投放时，优先看「招募任务-一口价 / 带货达人团」，其次是指派/投稿任务与素材集市。

**⑤ 员工与导购池（KOS）**
先解决三件事再启动，否则店端一定不配合：
1. **归因载体**：企微活码 / 专属码 / 导购码，一人一码，能追到人；
2. **提成归属**：线上成交算不算门店业绩？跨区成交怎么分？**这件事不定清楚，导购不会发内容**；
3. **合规**：员工号的账号归属（离职怎么办）、发布内容的责任划分。

**⑥ 老带新池（合规敏感）**
唯一安全的设计：**被推荐人产出首篇合格内容或产生首单真实销售后，推荐人获得一次性固定奖励**，
不随层级滚动、不按人数计酬。详见 `koc-compliance-guard`。

## 二、招募漏斗与转化率起始值

**12 环节标准链路**（【经验值/待校准】，本行业没有公开基准）：

| # | 环节 | 建议监控阈值 |
|---|---|---|
| 1 | 招募曝光 → 报名 | 先测基线 |
| 2 | 报名 → **初筛通过率** | 池子健康时 5%–30%；**>60% 说明标准太松**（注意：这是「报名→通过」的比例，与「入池后能否产出」是两个指标） |
| 3 | 初筛通过 → 建联响应 | 站内私信 30%–60%；微信 >80% |
| 4 | 响应 → 接受合作 | 纯佣 20%–40%；有稿费 60%–85% |
| 5 | 接受 → 回收地址 | ≥90%，<80% 说明话术或表单有问题 |
| 6 | 地址 → 实际寄出 | ≥98%（低了是仓配问题） |
| 7 | 寄出 → 签收 | ≥95% |
| 8 | 签收 → 按期发布（**出稿率**） | 见下表 |
| 9 | 发布 → 验收合格（**合格率**） | ≥85% |
| 10 | 合格 → 挂链/带码 | 纯佣场景 ≥95% |
| 11 | 带链 → 出单 | 先测基线 |
| 12 | 出单 → 复投 | ≥25% |

**出稿率按合作形态的差异**（【经验值/待校准】，**必须用首批 100–200 个样品的实测值替换**）：

| 合作形态 | 出稿率 | 合格率 | 有效出稿率 |
|---|---|---|---|
| 纯寄样 · 公开招募 · 无稿费 | 35%–55% | 70%–85% | 25%–47% |
| 纯寄样 · 定向邀约 | 55%–75% | 80%–90% | 44%–68% |
| **寄样 + 小额后置稿费** | **80%–92%** | 85%–95% | **68%–87%** |
| 寄样 + 稿费前置 | 60%–80% | 75%–90% | 45%–72% |
| 平台官方合作单 | 90%–98% | 90%–98% | 81%–96% |

> **两条结论**：① **稿费后置是提升出稿率最强的杠杆**，前置付款反而降低履约；
> ② 有效出稿率对成本是"倒数级"敏感 —— 从 30% 提到 60%，单篇内容成本直接砍半，
> 效果强于任何议价。所以第一优先级是履约机制设计，不是压价。

## 三、招募物料

### 3.1 招募帖（品牌号发布）

**注意**：招募内容本身也要过审。**不得承诺"给钱""返现"**，否则招募帖本身违规。

```
标题：{品牌} 第 N 期体验官招募 · {人数} 名

我们在找这样的人：
· 真的会用 {品类}，并且愿意把用后的真实感受写出来
· 有小红书/抖音账号，最近还在更新（粉丝多少不重要）
· 能在收到产品后 7 天内发出一篇内容

你会得到：
· {产品名}（价值 {X} 元）免费体验，无需返还
· 一对一的内容指导（选题、拍法、标题，我们陪你改）
· 表现好的会进入长期合作，有更多新品优先体验和额外权益

怎么报名：
· 点这里填表 {链接}（1 分钟）｜或私信我们「体验官」

【说明】本期为产品体验合作，内容需按平台规则完成合作报备与标识。
```

### 3.2 私信话术五段式

> 必须用**品牌号**发（不用个人号）。禁止在私信里引导站外交易、承诺保量、或让对方声称自费购买。

| 段 | 作用 | 写法 |
|---|---|---|
| ① 身份 | 消除警惕 | 一句话说清是哪个品牌的官方账号 |
| ② **具体化的赞美** | 证明看过内容 | **点名对方某一篇具体笔记 + 其中一个细节**。这一句决定他回不回你，禁止泛泛夸"内容很棒" |
| ③ 合作形式 | 降低决策成本 | 产品名 + 是寄样置换还是付费 + 走哪个官方通路 |
| ④ 时间与工作量 | 消除不确定 | 档期窗口、内容形式、大概字数或时长 |
| ⑤ **单一行动指令** | 提高回复率 | 只问一个问题（"方便的话回复 1，我把合作单发过来"） |

**禁用表述**：加微信聊 / 留手机号二维码 / 私下合作不走平台 / 保证爆文 / "你就说是自己买的"。

### 3.3 报名表字段（可直接建表）

**必填**：平台 + 账号昵称 + 主页链接（或 UID）、粉丝量、近 30 天更新篇数、常发内容方向、
收货人姓名/电话/地址、是否愿意按平台规则完成报备与标识。

**选填但很有用**：近 3 篇作品链接、平时用什么设备拍、方便出片的场景、是否接受挂链带货、
希望的合作形式（置换/稿费/纯佣）。

**不要收**：身份证号、家庭成员信息、收入等与合作无关的敏感信息（最小必要原则）。
表单页要写明：收集目的、使用范围、保存期限，并取得勾选同意。

## 四、铺量节奏

**小红书官方从未给出 KOC 铺量的数量建议**，行业说法量级差异极大。可给用户的表述方式：

> 铺量数量应由**核心人群规模 ÷ 单篇有效触达**倒推，而不是拍一个数。
> 建议先做 **20–30 篇的最小验证批次**，跑出内容模型与 CPE 基线后，用基线倒推总量。

**反漏斗式招募（推荐做法）：**
```
第 1 批（20–30 人）：只招核心圈层的人（最像你目标用户的那群）
   ↓ 跑出可复制的内容公式（哪个角度、哪种形式、哪类人写得最好）
第 2 批（50–100 人）：复制已验证的组合，扩到次核心人群
   ↓ 内容与投流数据双验证
第 3 批（放量）：破圈到泛人群，同时把跑赢的内容授权后投流放大
```
**不要一上来就铺 1000 人。** 一是内容承接能力跟不上，二是没跑出公式就放量等于放大错误。
