# 合作模式、阶梯佣金与结算条款

> 平台费率与规则以各平台后台最新公告为准（整理时点 2026-08）。中国内容平台的商业化规则变更频率约为季度级。
> 佣金率区间为【行业惯例】谈判锚点，不是标准，更不能写进承诺。

---

## 一、七种合作模式：先选模式，再谈价

| 模式 | 适用场景 | 关键特征 | 品牌风险 | KOC 接受度 |
|---|---|---|---|---|
| **纯 CPS（纯佣）** | 测品、新品、长尾达人 | 无固定费，只给样品 + 佣金 | 低（但样品是沉没成本） | 低（尾部愿意，腰部不愿意） |
| **低固定费 + 阶梯 CPS** | 可信中腰部、有成交目标 | 保底 + 超额高佣 | 中 | **高（最容易谈成）** |
| **固定费 + 佣金** | 高毛利品、可信达人 | 明确结算口径是关键 | 中高 | 高 |
| **CPA** | 高客单、长决策（线索型） | 按线索/咨询结算 | 中 | 中 |
| **内容买断** | **素材投流、多渠道复用** | 按脚本与交付付费，不按 GMV | 低（成本可预期） | 高 |
| **阶梯分成** | 复购品、订阅品 | 长期关系绑定 | 中 | 中 |
| **固定坑位费** | 大促、稀缺档期 | 买的是发布时间与排期 | **高** | 高 |

**固定费的决策规则：** 固定费 ÷ 可贡献毛利率 = 最低回本 GMV。
**只有当这个最低 GMV 落在该达人历史同品类 GMV 的保守区间内，才考虑付固定费。** 否则改纯佣或内容买断。

**KOC 场景的默认选择：** 尾部纯佣 / 小额后置稿费；腰部低固定 + 阶梯；素材价值高的走内容买断。
**注意**：后置稿费（发布验收后付）对出稿率的提升是最强杠杆；前置付款反而降低履约率。

## 二、阶梯佣金设计

### 三条原则

1. **用超额累进，不要全额跳档。** 全额跳档会制造"刷单凑门槛"的动机，也会让差一点点的人直接放弃；
2. **按净销售额分档，不要按 GMV 分档**（GMV 含退款，容易出现"卖得多、退得多、佣金照付"）；
3. **把高佣给增量，不要一开始就整体提高佣金率。**

### 结构模板：底 + 阶梯 + 封顶（【经验值/待校准】）

| 档位 | 触发条件（建议用"内容结果"而非纯 GMV，因为 KOC 单条 GMV 噪声大） | 奖励形式 |
|---|---|---|
| **底** | 按合同交付（发布 + 挂链 ≥72h + 数据回传） | 置换 / 小额固定费（预付 0–20%） |
| **阶梯 1** | 内容进入品牌本月内容池 Top 30%（按互动或收藏分享率） | 达标奖金 + 素材授权费另计 |
| **阶梯 2** | 达到自定爆款线（如点赞 > 1000） | 奖金翻倍 + 进高级 KOC 群 |
| **阶梯 3** | 内容被选入素材银行并产生投流消耗 | 按投流消耗分成 |
| **封顶** | 单条设封顶 | 避免长尾失控 |

用脚本模拟阶梯效果与悬崖：

```bash
python3 ../koc-distribution-engine/scripts/koc_econ.py tier --json '{"mode":"marginal",
  "tiers":[{"from":0,"rate":0.10},{"from":3000,"rate":0.15},{"from":10000,"rate":0.20}]}' --text
```

### 预付比例参考【行业惯例】

| 合作类型 | 预付比例 |
|---|---|
| 置换 / 小额 | 0%–20% |
| 常规固定费（CPT） | 30%–50%（常见分段 30%–30%–40%） |
| 高额独家 | 20%–40% |
| 纯 CPS | 0% |

## 三、结算必须写清的 9 个字段

不写清楚，**同一个"15% 佣金"能算出完全不同的利润**。

| # | 字段 | 推荐口径 |
|---|---|---|
| 1 | **结算基数** | **扣退款后的净销售额**（不要默认 GMV） |
| 2 | 有效订单定义 | 付款成功、未取消、未全额退款、未判定异常；部分退款按实际保留金额计佣 |
| 3 | 退款/拒收处理 | 全额退款佣金全额追回；已支付的在下期账单冲抵 |
| 4 | 优惠券/补贴承担 | 区分平台券/店铺券/达人券；税费与物流默认扣除 |
| 5 | 样品与坑位费计入 | 总成本 = 固定费 + 样品成本 + 预估佣金 + 物流税费 |
| 6 | 结算周期 | 建议退款期结束后结算（跨境 T+30），避免 T+7 结完再追佣 |
| 7 | 归因窗口 | 写死天数；多渠道时以平台最终归因为准 |
| 8 | 异常订单排除 | 同地址大量下单、同设备异常下单、异常优惠叠加、高比例取消或拒收 |
| 9 | 佣金追回/冲抵 | 优先从下期佣金冲抵；无下期则退回 |

## 四、内容对赌 / 按验收付款：8 项验收清单

| # | 验收项 | 具体要求 |
|---|---|---|
| 1 | 合作模式 | CPT / CPS / 置换 |
| 2 | 交付物数量 | 图文/视频条数 |
| 3 | 发布时间与平台 | 具体日期与账号 |
| 4 | 挂链要求 | 链接/券码/UTM 规范；**挂链不少于 72 小时** |
| 5 | 审核修改 | 初稿与修改轮次上限（建议 1 轮）；平台侧有超时自动确认规则，注意别错过窗口 |
| 6 | 数据回传 | 截图或后台报表，24/72 小时内提交 |
| 7 | 付款节点 | 预付/尾款的触发条件 |
| 8 | 异常扣款 | 刷量、删稿处理；**未满约定留存期擅自删除按未完成交付处理** |

### 必须写进合同的三条反向条款

1. **刷量取消全部奖励并追回**（把"平台判定异常"直接写成扣款触发条件，不用自己举证）；
2. **未满留存期删稿按未完成交付处理**；
3. **私自向品牌社群成员推销其他产品，取消资格与全部未结收益。**

另外建议加一条：**达人被平台封禁接单权限的，属达人违约**，否则在途损失全部由品牌承担。

## 五、税务与发放（涉及给个人付钱，必须提前定）

> 这一节只讲运营侧要做的事。具体税目适用与代扣代缴口径，**必须由用户的财务或税务顾问确认**，
> 专家不提供税务筹划意见。

| 场景 | 运营侧要做的事 |
|---|---|
| 给个人发现金/稿费/奖金 | 明确发放主体、是否代扣代缴、要不要发票；把税费口径写进合作协议（税前/税后要写死） |
| 平台内结算的佣金（星图/蒲公英/精选联盟） | 走平台结算，税务由平台规则处理；把"平台服务费由谁承担"写清楚 |
| 实物/礼品激励 | 同样可能涉及个人所得税，礼品价值与发放记录要留档 |
| 大量小额发放 | 优先走平台结算或有资质的服务商；**不要用个人账号大额转账给一堆人** |

**红线：** 不得以"帮忙避税"为由让 KOC 拆分收款、虚开发票，或使用他人身份收款。

## 六、分销层级的法律红线（做团长/推荐机制前必看）

设计"KOC 带 KOC""团长带团员"的分成机制时，三条同时满足才安全：

1. **层级 ≤2 级**（自己 + 直接下级），不设三级及以上的团队计酬；
2. **计酬依据只能是真实商品销售额**，不得以"发展人头数"为计酬或返利依据；
3. **不得收取任何形式的入门费**（买货资格费、押金、加盟费、必须先囤货）。

完整法条依据、判定要件与常见变形，见 `koc-compliance-guard` 技能。
**这三条任何一条不满足，方案都不要出。**
