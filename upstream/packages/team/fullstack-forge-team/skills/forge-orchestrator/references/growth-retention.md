# 增长与留存方法论（growth-retention）

> 适用角色：增长运营师（growth-operator）
> 用途：让产品上线后获得用户、留住用户并持续增长。上游输入：产品定义（目标用户与北极星指标）、平台选型（决定渠道与 ASO 对象）。

---

## 一、增长模型（AARRR）

所有策略挂到模型对应环节，每个环节有明确指标，禁止"泛泛地做推广"：

| 环节 | 含义 | 核心指标 |
|------|------|----------|
| Acquisition 获客 | 用户从哪来 | 新增用户数、各渠道新增占比、获客成本 CAC |
| Activation 激活 | 新用户是否体验到核心价值 | 注册→关键动作转化率（如首单完成率） |
| Retention 留存 | 用户是否回来 | 次日/7日/30日留存率 |
| Revenue 收入 | 是否产生价值变现 | 付费转化率、ARPU、复购率 |
| Referral 推荐 | 用户是否带来用户 | 分享率、邀请 K 因子 |

**模型使用纪律**：
1. 先看留存，再谈获客——留存曲线未走平（没有"啊哈时刻"）之前放大投放等于漏桶注水；
2. 每个环节设置一个"当前瓶颈"，资源优先投向瓶颈环节；
3. 指标口径与产品定义（product-design.md 埋点表）一致，禁止运营口径与埋点口径两套说法。

---

## 二、冷启动获客

### 2.1 种子用户获取（前 100~1000 人）

1. **定义种子用户画像**：越具体越好（"25-35 岁一线城市养猫上班族"，不是"年轻人"）；
2. **去用户所在的地方**：竞品评论区、垂直社群、豆瓣小组/即刻话题、线下场景；
3. **一对一定邀**：初创期人工邀请前 100 个用户，收集真实反馈，比投放有价值；
4. **给足身份感**：创始用户群、命名墙、优先体验新功能——用身份感换包容度。

### 2.2 渠道打法（选择 2~3 个主攻，不撒胡椒面）

| 渠道类型 | 打法 | 适合产品 |
|----------|------|----------|
| 内容平台（小红书/抖音/B站/知乎） | 每周固定内容排期 + 关键词卡位 + 素人/达人置换 | 有内容化空间的产品 |
| 社群/私域 | 目标用户聚集群的价值输出 + 入群钩子 | 高决策成本、需教育的产品 |
| 应用商店首发资源 | 新品自荐、首发专题申请 | App/小程序 |
| 线下场景 | 门店物料、地推、异业合作 | 本地生活类 |
| 搜索（SEO/SEM） | 关键词布局、落地页承接 | 有明确搜索需求的服务 |

每个渠道必须写明：**具体动作 + 频次 + 预算量级 + 预期新增量级**（如"小红书：每周 3 篇笔记 + 2 个达人置换，预算 2000 元/月，预期月新增 500"）。

## 三、ASO 要点（App / 小程序搜索优化）

1. **关键词**：标题权重最高——品牌词 + 核心行为词（如"XX记账-每日收支管理"）；覆盖竞品词与长尾需求词，避开大词硬碰；
2. **截图**：前 2 张决定转化——放核心价值场景，配一句价值文案，不堆功能列表；
3. **描述**：首 3 行是搜索摘要区，自然嵌入核心关键词；
4. **评分**：在"用户完成关键动作的愉悦时刻"触发评分引导（如完成首次记账后），差评引导进客服通道；
5. **小程序搜索**：服务类目准确、页面关键词配置、自定义关键词词包、好评与访问量影响排序；
6. **迭代节奏**：关键词每月复盘一次（曝光/点击/下载转化），换词是小成本高回报的动作。

## 四、留存激活策略（方案重点）

**先回答"用户为什么来第二次"，再谈任何拉新投放。**

### 4.1 新手引导（决定激活率）

1. **缩短首次价值路径**：新用户 ≤3 步触达核心价值（如首单优惠直达，不强制先完善资料）；
2. **登录后置**：先体验后注册，必须登录时给理由（"保存你的预约"）；
3. **空态设计**：无数据页面给示例与一键引导，不做白板；
4. **首单/首次激励**：首次关键动作给即时奖励（优惠券/特权），绑定"啊哈时刻"。

### 4.2 习惯养成

1. **固定触发场景**：把产品挂到一个已有习惯上（早餐后打卡、周五晚上总结）；
2. **打卡/连续机制**：连续签到奖励递增，断签有挽回设计（补签卡）；
3. **定期内容/服务节拍**：周报、每周精选、固定栏目——给用户周期性回来的理由。

### 4.3 推送策略（频率红线）

| 规则 | 标准 |
|------|------|
| 频率上限 | Push/短信每日 ≤1 条，每周 ≤3 条（用户可感知的节奏） |
| 免打扰时段 | 22:00~8:00 不发送（即时性事务除外） |
| 内容分级 | 事务性（订单状态）> 个性化推荐 > 无差别活动轰炸 |
| 退订路径 | 每条触达可关闭/退订，设置入口 ≤2 步 |

### 4.4 会员与积分体系

1. **会员**：先跑通单次付费价值，再设计订阅/等级；权益围绕"省时间/省钱/身份感"三选二；
2. **积分**：行为积分（签到/评价/分享）+ 消费积分双轨；积分必须有清晰价值出口（抵扣/兑换），不可兑换的积分等于空气；
3. **防薅羊毛**：积分风控规则（单日上限、同设备判定）先于裂变活动上线。

## 五、流失召回

### 5.1 流失定义与分层

1. **流失定义**：按业务节奏定义（如电商 30 天未访问、工具 14 天未使用），写进数据口径；
2. **流失分层**（不同层不同策略）：

| 层 | 定义 | 召回重点 |
|----|------|----------|
| 新用户流失 | 注册后 7 天内未完成关键动作 | 降低门槛：发"首单券/新手任务"，引导完成啊哈时刻 |
| 活跃用户衰退 | 频次连续 2 个周期下降 | 找衰退原因：推个性化内容/提醒核心功能 |
| 沉睡用户 | 超流失定义期未活跃 | 大额激励 + 新功能卖点触达 |

### 5.2 召回渠道与话术

- **渠道优先级**：Push（有 App 装机）→ 短信（有手机号）→ 公众号/订阅消息 → 邮件；
- **话术公式**：身份认同 + 具体钩子 + 低门槛行动（"你收藏的 XX 门店本周 8 折，点此预约"——不要"好久不见快回来吧"）；
- **召回实验**：A/B 激励力度（无激励 / 小额券 / 大额券），召回成本 < 用户 LTV 才可持续；
- **召回后承接**：召回落地页直接到钩子内容，不落首页；召回用户 7 日内二次流失率纳入监控。

## 六、数据复盘模板

每周/每月按此模板复盘（口径与埋点表一致）：

```
增长周报 | 第 N 周 | {日期区间}

一、北极星指标：{定义} 本周 {值}（环比 {x}%）｜目标 {y}
二、AARRR 关键数据：
  获客：新增 {n}（渠道1 x% / 渠道2 y% / 自然 z%）｜CAC {成本}
  激活：注册→关键动作 {转化率}（漏斗：曝光 a% → 注册 b% → 激活 c%）
  留存：次日 {x}% / 7日 {y}% / 30日 {z}%
  收入：付费转化 {x}%｜ARPU {y}
  推荐：分享率 {x}%｜邀请 K 因子 {y}
三、留存曲线：新用户 7 日留存曲线是否走平（未走平 = 瓶颈在激活/留存）
四、本周实验结论：{实验名}（假设/结果/决策）
五、下周 Top3 动作：{动作 + 负责人 + 预期指标影响}
```

**漏斗诊断口诀**：曝光→注册低 = 落地页问题；注册→激活低 = 新手引导问题；激活→留存低 = 核心价值问题；先修漏斗再投钱。

## 七、增长实验方法

1. **假设驱动**：每个实验先写假设——"如果 {改动}，则 {指标} 提升 {幅度}，因为 {理由}"；
2. **单变量**：一次只改一个变量，禁止"改版"式多变量混发；
3. **样本与时长**：明确最小样本量与实验周期（小流量产品可用时间段轮换对比）；
4. **结果决策**：显著提升 → 全量；无差异 → 记录并关闭；显著下降 → 回滚并复盘；
5. **实验台账**：所有实验（含失败）入台账，避免重复踩坑，沉淀为团队认知资产。

## 九、用户生命周期运营

按生命周期分层制定运营目标，避免"一套策略打所有人"：

| 阶段 | 定义 | 运营目标 | 关键动作 |
|------|------|----------|----------|
| 新用户 | 注册 ≤7 天 | 完成关键动作（激活） | 新手任务、首单激励、激活率监控 |
| 成长期 | 已激活、使用 <1 个月 | 养成使用习惯 | 引导进阶功能、习惯打卡、个性化推荐 |
| 成熟期 | 稳定活跃用户 | 提升价值（付费/复购/分享） | 会员权益、等级荣誉、邀请激励 |
| 衰退期 | 频次连续下降 | 止跌挽回 | 衰退预警触达、核心功能提醒 |
| 流失期 | 超过流失定义期 | 召回或自然淘汰 | 分层召回（见第五章）、沉默用户清理 |

**纪律**：每层有独立指标与策略；用户从上层滑向下层时必须触发对应动作，而不是等流失定义期过后直接进召回。

## 十、常见增长反模式

1. **烧钱买留存幻觉**：补贴换来的"活跃"在补贴停止后归零——先验证自然留存，再决定是否补贴；
2. **虚荣指标驱动**：只汇报累计注册、下载量，不看活跃与留存——累计数只涨不跌，无法指导决策；
3. **全渠道铺开**：5 个渠道各投 20% 精力，每个都做不透——集中 2~3 个渠道打透再扩展；
4. **裂变先于风控**：裂变活动上线前没有防刷规则——羊毛党一夜掏空预算；
5. **推送轰炸**：用触达频次掩盖内容质量——短期打开率提升，长期关闭率与卸载率上升；
6. **只做活动不沉淀**：活动来的用户没有承接路径（社群/会员/习惯机制），活动结束即流失；
7. **周报没有决策**：罗列数据不给结论与下周动作——复盘的价值在"下一步做什么"，不在数字本身。
