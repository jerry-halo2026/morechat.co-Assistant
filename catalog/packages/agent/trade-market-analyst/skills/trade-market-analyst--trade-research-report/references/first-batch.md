# 首批两项任务：可恢复执行与 Excel

“按产品找客户”与采购商查询下的“进口记录”先用 `plan_report` 的 task 分支，
无需委托方；联系方式六项另见 contacts.md；其他任务按各自 references 的契约执行，不能套用这两项接口。保留原任务标题与归属，
业务对话不展示内部任务编号、步骤编号、工具参数或查询记录原文。
按产品找客户默认展示完整提示词：
请按【产品】寻找【国家】的采购商，规模要求【小型/中型/大型/不限】，目标【25 】家，期间【近一年】。先核实该市场的数据能力，再基于实际采购记录找客户并补充官网、国家、类型、规模、营收、交易次数与最近采购时间。说明排名依据、筛选是否完整及资料缺失；不要用交易次数冒充采购金额。
用户删掉后半段、只给产品与国家时，执行中自动补齐默认条件与完整交付要求，不要求重输。
产品与国家仍须为实际输入；缺必填项先确认，不造信息。
未指定时直接采用不限规模、近一年、25家、聊天摘要+Excel；近一年是截至当天的近12个日历月，
展示实际起止日期。这些默认已采用，不要求补填或再次确认。删减输入例子：请按家具寻找美国的采购商。
规模参考：小型 / 中型 / 大型 / 不限。未选择规模、删除规模要求或保留原选项提示时按“不限”执行；不把选项提示整体作为筛选条件。明确选择或自定义的条件优先。
用户明确给出的规模、数量、完整日期与格式优先；单独给起日或止日仍确认完整期间，日期无效先修正。
采购商进口记录仅给真实采购商时，自动采用截至当天近12个日历月、首批50条、全部可用查询市场、聊天摘要+Excel，展示实际日期而不重复补问默认项。身份与名称范围仍须用户或证据确认，不按注册国缩小市场；单端日期、无效日期和同名歧义仍先处理。
两项任务都须先根据已选任务ID/入口胶囊或明确会话意图识别任务；同名且删减后不明时先澄清，不能一律当海关获客。
泛称占位（产品、采购商名称等）不是真实对象，不传给工具；可选默认/选项未修改或被删除时省略相应参数，让规划器补全。完整日期、数量、格式等明确输入优先。删除输出要求仍交付完整本任务字段、证据、来源、盲区和费用；用户明确仅要聊天或特定展示字段时遵从，但保留必要证据与费用说明。
各任务按目录每项fallback/default_scope和对应 references 的契约执行，不混入本篇两项task接口。
本批仅聊天摘要与 Excel；Word、网页等要求先说明未支持。
所有 blocking 项须确认；改变采用的条件先重规划。
任务规划本身不取付费数据、费用为零。别与旧模块业务入参混传。
若服务端没有 task 支持，保留需求，说明需要部署更新；不补造委托方或模块来绕过。

执行与续做按 SKILL.md 第 3 步：工作目录放计划全文和一份查询记录，每次付费调用记工具、参数、关键数字、服务端实扣和调用编号；同参成功不重跑，已发出未记结果的先告诉用户。参数照计划步骤填，不另编查询；分组只替换 repeat_param，续页只加同组真实响应给的 cursor。本批能力查询的参数名是 `market`。

普通点不必事先告诉用户预计点数，按实扣记账；需要时可按步骤 wallet_ceiling 估算：50/51/500条分别按现有1/2/10点档位，画像基础查询和候选检索各按现有1点。缺失或超出已授权预算时在付费查询前合并做一次费用确认，不自行填20点或视为无限授权。两个钱包分开记录，本批不增加联系人消费；响应实扣为最终依据，不新增价格。
新产品获客计划（acquisition/1）：原产品和完整约束原样使用，不改词或猜HS；能力查询后只选一条明确路线，已有直接进口时不扩大反查。
新采购商明细计划（transaction_facets/1）：先查能力，分别确认 buyer 身份与角色，覆盖以成功且实扣已知的能力查询和计划的完整 coverage_scope 为准，只核角色可用部分，不声称两侧完整。无覆盖停止付费。blocking 待确认项要用户明确回答并记下依据。
每个兼容市场组单独查询并记入查询记录；仅替换计划允许的市场字段，不跨组混排名，未查组显式披露。
所有贸易查询沿用计划的精确起止日期；日期改变须新计划。明细仅在用户要求且响应
有下一页标识时续查，记下用户要求；同组参数只加实际返回的标识，不能自动拉全量。
MCP 报错也记入查询记录，费用未知不凭错误文字猜零。
服务端 billing 是实际费用依据；联系人点独立记录，本批不增加联系方式消费。

获客名单分别核对产品采购证据、注册身份、规模与适用性；货代或同行不能凭注册库命中就称合格客户。
不自动选同名候选第一行；未知身份保留待核实。不限规模时不以规模筛选，未知规模本身不淘汰客户，
也不代表员工人数或营收已核实；明确要求规模时，未知不能当满足。数量不足交部分成果，展示目标、合格、缺口。
用户删除后半段也要先核市场能力，基于实际采购记录找客户；说明排名依据、筛选完整性与资料缺失，不用交易次数冒充采购金额。

营收与最近交易日期已包含在本批展示列中；仅展示已保存的真实值，缺失币种与年份明确标未知。
