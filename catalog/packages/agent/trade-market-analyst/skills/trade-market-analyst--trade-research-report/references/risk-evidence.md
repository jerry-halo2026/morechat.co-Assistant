# 风控背调：先交付证据；骗子判断给分档结论

四项原名称为全面背调、注册信息、扩张期判断、骗子判断。全面背调、注册信息、扩张期判断只交付证据、反证、缺项、核查范围和下一步动作，扩张阶段、概率与总分没有实施。骗子判断（identity_risk_evidence）按用户2026-10-31决定在网页报告和聊天摘要最前面给明确分档结论：大概率是骗子 / 高度可疑 / 有疑点，需核实 / 未发现骗子迹象 / 资料不足，补X即可判断（写明缺哪一项）；只跟一句理由，不写建议、不列依据清单；依据留在 Excel 证据表。结论主要由已查实证据决定，推断和待核实只能上推一档，域名新旧不能单独定为骗子；不出分数或概率，不用“仅供参考”“无法判断”收尾。结论放网页结论横幅，不录成证据字段；Excel 证据表照常交付证据五部分，不含结论。原任务名称、目录顺序与描述留档。适配状态指证据交付能力，不能解释为判断规则已落地。

调用 `plan_report` 的 task.type=risk_evidence；intent=comprehensive_evidence / registration_evidence / expansion_evidence / identity_risk_evidence。subject 必须真实 company、domain，constraints 必须主体 country，不默认中国，不把注册国当贸易市场。已确认会话字段只能填原始实际输入；未确认官网不查任意同名域名。删去可选期间与交付格式恢复当天向前12个日历月、保留日及 chat+docx+xlsx；原始双端顺序先核对、未来夹到当天，单端确认完整范围。注册信息独立用最新可得资料，各登记日期、状态日期和原财年照实保留，历史有效事项不裁剪。无需我方产品。

执行与续做按 SKILL.md 第 3 步写查询记录，两钱包预算分开。先由用户确认主体（名称、国家、实际官网）并记下依据；这是用户确认，不是法律主体已核实，不要填虚构编号。每种格式取真实 get_render_spec，换格式复用已取得的证据，零取数。

默认没有企业、完整画像或资信付费查询。确有需要时规划前显式company_lookup=true（profile_depth默认basic，full须明确）、credit_lookup=true；按已确认预算调用。非全面背调任务只有显式开启资信时才冻结单独资信附节，不能把其原信号当本任务判断等级。关联调用前从本任务成功候选中明确选择实际行（调用编号、行号）与 company_id；名称、官网或主体国家冲突不选择，同名不取首条。商业未命中不能推无登记。真实资信颜色只引用get_company_credit返回的credit_light/light_label、该主体与as_of；未知不补绿或黄，不作欺诈等级。总体来源失败优先于字段清洗，实扣照记，不采用失败事实；未知费用先告诉用户，不自动重试。

公开来源由宿主实际打开，记下主体（公司、国家、官网）、章节（registration / credit / business_change / identity_risk）、无凭证的HTTP(S)链接、带时区的取得时间、精确摘录与字段/值，并区分抓取事实、用户陈述与推断。精确值与主体名称必须在摘录，唯一关联还需国家与实际官网原文。entity_association=matched/unverified/conflict/same_name与association_evidence独立记录。用户材料不能当已核实来源事实。事件日、财年、期间起止、单位、币种、合并范围及可比性须在同一实际摘录内有原值依据。结构化值要指明它在原数据里的实际位置和类型，同次提供的元资料也逐项对应原数据的实际位置；重复键或非有限值不采用，不能随意输入用户统计。

逐项标source_kind=official_register/company_website/rdap/whois/public_event/financial/hiring/investment/user_material，event_date与fiscal_year、period_start/period_end、unit、currency、consolidation、comparability，不能以检查日冒充登记成立日。polarity=evidence/counterevidence/conflict；evidence_status=current/stale/retracted/updated；next_action必有。明确failed/unqueried/unsupported留缺项；检索无发现必须实际打开并记下链接、时间、检索词与检索范围，有限无发现不能说没有负面信息。不新增联网库、虚构WHOIS或登记工具、认证访问，不导入联系人、登录或发消息。

五部分固定交付：主体关联与核验状态；实际值/事件/期间/单位/币种/合并口径；精确摘录、来源与真实检查时间；反证/冲突/撤回/更新；缺项/未查/失败/检索范围/动作。注册存在、当前经营状态与来信授权分别核查。经营证据仅比较真实同主体、同来源、同单位/币种/合并范围、明确可比说明且实际期间起止具有相同财年偏移及日历范围的保存点。全年与半年、来源明示不可比或范围未核实均列缺项，广告不是员工人数、计划不是完成投资、数据覆盖变化不是企业增长。域名创建日、隐私遮蔽与可访问性是事实，域名新旧独立不能作欺诈或安全结论，长期实体新官网与老域名冒名冲突均保留。图表无合格可比序列不生成，不补零或插值。三格式逐格/段落/表格回读失败即不交付。


来源记录关联：结构化捕获必须用实际值路径选取真实记录；同一记录中的企业原名、主体国家、完整官网主机与数值及口径路径一起核验。不得借全页另一企业的数值、币种、年份或更新时间，同域名前缀/后缀不是完整官网匹配。支持的记录身份字段为 company/country/website；其他结构保留原文与未核实状态，不自动改写来源或选第一行。普通文本只有可独立解析的同记录来源字段（企业名称、主体国家、官网、指标、实际值及逐项资料字段）才建立来源关联；自由文本、混合实体或无法定位的关联只作原句引用，保留限定语和缺项。

来源实际更新日必须有对应的实际来源更新时间字段或标签；成立日、事件日、财年、捕获/检查日不能改作更新时间。未提供为未知，未来更新时间保留原值但明确日期异常，不作数据截止。结构化技术键不进入公共表格：完整精确摘录与实际路径留在工作目录；聊天、Word、Excel展示从已核验实际字段确定性提取的“原文精确片段”，逐项关联主体、指标、时间角色、币种单位及来源证据编号。不接受调用方另填显示引文或其他记录片段；普通文本保持原句及限定语。

所选实际来源记录中的未采用补充值和限定原文也要交付，不能只摘数值丢撤回、未审计、不可比或更新条件。实际字符串按原数据值显示；不接受另填显示文字。补充语或嵌套资料的范围未完成核实时，只保留引用、部分取得状态与缺项，并排除可比点；调用方的 current/evidence/same scope 不能解除该限制。另一主体记录的备注不借用，也不承诺理解任意文字或推导评级。来源指标角色未知时公共指标仅为“原文引用值（指标角色未核实）”，调用方原始指标名留在私人证据，不当来源指标；实际已知指标仍用来源角色并保留角色冲突。

比较资格仅接受来源完整可比说明明确为“可比”“same scope”或“相同主体与来源、币种和单体范围”（仅去首尾空白及统一英文大小写）。否定、混合、未知、尚未核实或复杂说明不能靠包含肯定短语准入；原说明和值保留，比较资格另列待核查，不作稳定、零值或阶段结论。未采用的子结构也要一并检查，不忽略深层内容。
