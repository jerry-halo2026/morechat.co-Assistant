## 二、接口拿不到什么（**绝对不能编造**）

| 指标 | 为什么拿不到 | 正确做法 |
|---|---|---|
| **播放量** | `play_count` 在公开接口恒为 `0`，抖音不对外开放 | 让用户到「创作者服务中心 → 作品数据」看，或用巨量星图/蝉妈妈等第三方估算工具 |
| **完播率 / 5秒完播 / 2秒跳出** | 分母是播放量 | 同上，必须由用户提供后台数据 |
| **点赞率 / 分享率 / 收藏率（除以播放量）** | 分母是播放量 | 改用本文第三节的**结构性比率** |
| **推荐流占比 / 流量来源构成** | 仅后台可见 | 让用户提供后台截图 |
| **涨粉数 / 主页访问 / 商品曝光** | 仅后台可见 | 同上 |
| **完整评论内容** | 分享页只返回计数 | 需要评论文本时说明本工具不覆盖 |

> **铁律**：宁可写"该指标接口不返回"，也不要给一个看起来合理的估算值。运营决策建立在假数据上比没有数据更危险。

## 三、结构性比率（不依赖播放量，本工具的核心诊断口径）

黄金数据标准原本以播放量为分母：**点赞率 ~3%、分享率 ~1%、收藏率 ~1%**。
既然分母不可得，就把它换算成**以点赞为基数**的比值，消掉播放量：

| 结构性比率 | 换算依据 | 优秀线 | 达标线 | 业务含义 |
|---|---|---|---|---|
| **分享/点赞** | 1% ÷ 3% ≈ 0.33 | ≥ 33% | ≥ 15% | **传播系数**——内容能否被主动转发出圈 |
| **收藏/点赞** | 1% ÷ 3% ≈ 0.33 | ≥ 33% | ≥ 12% | **价值系数**——是否有"留着以后用"的干货价值 |
| **评论/点赞** | 行业常见健康区间 | ≥ 15% | ≥ 5% | **互动系数**——是否引发讨论与情绪共鸣 |

**读法**：
- 三项全优 → 内容结构健康，若量级仍低，问题在**冷启动与标签**（账号权重、发布时间、初始推荐池），不在内容本身。
- 分享低、收藏高 → 工具型内容，缺社交货币。加"替我说话"的观点或利他理由。
- 分享高、收藏低 → 情绪型内容，缺复用价值。加清单化、步骤化表达。
- 评论低但点赞高 → 观众认同但没话说。缺开放式提问、争议点或可纠错细节。
- 三项全低 → 大概率是泛流量/低质流量，或标题党骗进来的人群不精准，需排查人群标签。

## 四、互动量级判定

| 量级 | 总互动 | 解读 |
|---|---|---|
| S 级 · 平台级爆款 | ≥ 100,000 | 已破圈，重点研究可复制部分 |
| A 级 · 爆款 | ≥ 10,000 | 结构成立，可作模板批量复用 |
| B 级 · 小爆 | ≥ 3,000 | 方向对，需放大投放或优化钩子 |
| C 级 · 合格 | ≥ 500 | 基本盘，靠量取胜 |
| D 级 · 未起量 | < 500 | 需从选题/钩子/标签层面重做 |

> 量级需结合账号粉丝体量看：**点赞/粉丝比 ≥ 1** 说明主要吃推荐流（破圈）；远小于 1 说明推荐流占比不足，先排查内容标签与完播，而不是继续加发布频次。

## 五、与专家方法论的衔接

- 数据诊断完 → 按「**流量 → 人群 → 门店 → 商品 → 账号 → 经营**」顺序继续定位，不跳层。
- 本地生活/团购类视频，额外看：是否挂 POI 锚点（白色内容词 / 绿色交易词）、是否埋搜索钩子（"两头吃"）、评论区是否有到店咨询。
- 单条视频数据只是切片，判断账号健康度需要**至少近 10 条**横向对比，单条爆或单条扑都不足以下结论。

## 六、创作者后台全量数据字段口径（步骤 1.5 专用）

> 以下字段**仅创作者服务中心后台可见**，公开接口无法获取。当用户提供了后台截图/数字时使用本节口径做诊断。

### 6.1 总览基础指标

| 字段 | 口径 | 黄金标准（优秀线） | 合格线 | 危险线 |
|------|------|-------------------|--------|--------|
| **播放量** | 累计播放次数（去重） | — | — | < 200（极低曝光） |
| **完播率** | 完整播放人数 ÷ 播放量 | ≥ 25% | ≥ 15% | < 10% |
| **2s 跳出率** | 播放 < 2s 的人数 ÷ 播放量 | ≤ 35% | ≤ 45% | > 55% |
| **弹幕量** | 弹幕总数 | 因品类而异 | — | 0（互动类内容应有弹幕） |
| **流量激励** | 平台额外扶持播放次数 | > 0 说明被平台青睐 | 0 正常 | — |
| **作品状态** | 正常/审核中/限流/仅自己可见 | 正常 | — | 非正常需先排查违规 |

### 6.2 内容吸引力指标（流量分析 Tab）

| 字段 | 口径 | 黄金标准（优秀线） | 合格线 | 危险线 | 业务含义 |
|------|------|-------------------|--------|--------|---------|
| **完播率** | 完播人数 / 播放量 | ≥ 25% | ≥ 15% | < 10% | 内容整体粘性，最核心指标之一 |
| **平均播放时长** | 总观看时长 / 播放量 | > 视频时长×50% | > 时长×30% | < 5s | 人均看了多久，反映内容密度 |
| **2s 跳出率** | < 2s 划走比例 | ≤ 35% | ≤ 45% | > 55% | 开头 2 秒能否拦住人 |
| **5s 完播率** | 播放超 5s 的比例 | ≥ 45% | ≥ 30% | < 20% | 前 5 秒承接效果 |
| **平均播放占比** | 平均观看时长 / 视频总时长 | ≥ 40% | ≥ 25% | < 15% | 内容全程留人能力 |

**组合解读规则：**

| 2s跳出 | 5s完播 | 完播率 | 平均占比 | 诊断结论 |
|--------|--------|--------|---------|---------|
| 低 | 高 | 高 | 高 | 🟢 优秀：开头好、中后段也好，完整内容健康 |
| 高 | 低 | 低 | 低 | 🔴 致命：开头就失败，后续无从谈起。**优先改前 2 秒** |
| 低 | 高 | 低 | 中 | 🟡 前段强但中后段流失。**检查中段是否有拖沓/无高潮** |
| 低 | 低 | 高 | 高 | ⚠️ 特殊：开头筛掉了泛流量，留下精准人群看完。**需结合品类判断** |

### 6.3 观众参与度指标（流量分析 Tab）

| 字段 | 计算公式 | 黄金标准 | 合格线 | 解读规则 |
|------|---------|---------|--------|---------|
| **点赞率** | 点赞 / 播放 | 2.5%~4% | ≥ 1.5% | < 1% 内容无共鸣或推给了非目标人群 |
| **评论率** | 评论 / 播放 | 1%~2% | ≥ 0.8% | < 0.5% 缺互动引导或话题无争议性 |
| **分享率** | 分享 / 播放 | 0.8%~1.5% | ≥ 0.4% | < 0.2% 缺"替我说话"的社交货币 |
| **收藏率** | 收藏 / 播放 | 0.8%~1.5% | ≥ 0.4% | < 0.2% 缺干货/清单/工具属性 |
| **不感兴趣率** | 不感兴趣数 / 播放 | ≤ 0.5% | ≤ 2% | > 3% 标题党误推或内容冒犯 |

**参与度组合画像：**

| 点赞 | 评论 | 分享 | 收藏 | 画像 | 优化方向 |
|------|------|------|------|------|---------|
| 高 | 高 | 高 | 高 | 🟢 全能爆款 | 复制结构，换选题批量产出 |
| 高 | 低 | 低 | 低 | 👍 点赞机器 | 加互动引导 + 社交货币 + 干货清单 |
| 低 | 高 | 低 | 低 | 💬 争议/讨论型 | 争议引流但缺认可，加共识金句 |
| 低 | 低 | 高 | low | 🔄 传播型 | 有转发理由但缺深度，加实用价值 |
| 低 | 低 | 低 | 高 | 📚 工具/资料型 | 有收藏价值但缺传播力，加情绪钩子 |
| 全低 | 全低 | 全低 | 全低 | 🔴 泛流量/低质 | 排查标签漂移 + 开头钩子 + 选题匹配 |

### 6.4 流量来源构成（流量分析 Tab）

| 来源 | 健康占比范围 | 偏高含义 | 偏低含义 |
|------|------------|---------|---------|
| **推荐页** | ≥ 80% | ✅ 被算法大池接纳 | ⚠️ 未进入推荐池，靠社交/关注撑 |
| **个人主页** | 5%~15% | ⚠️ 吃老粉，破圈能力弱 | 正常，说明新客占比高 |
| **朋友页** | 1%~5% | ✅ 社交裂变生效 | 无社交传播 |
| **同城页** | 1%~5%（本地生活可更高） | ✅ 地域标签生效 | 本地生活类需关注 |
| **消息页** | 0.5%~3% | ✅ 粉丝召回有效 | 粉丝触达弱 |
| **搜索页** | 越高越好 | ✅ SEO 生效 | 未埋搜索词 |

**7 日环比趋势判断：**

| 推荐页趋势 | 个人主页趋势 | 判断 |
|-----------|------------|------|
| ↑ 上升 | ↓ 下降 | ✅ 新客获取加速，破圈中 |
| ↓ 下降 | ↑ 上升 | ⚠️ 在吃老粉，内容对新客吸引力衰减 |
| ↓ 下降 | ↓ 下降 | 🔴 整体流量萎缩，排查违规/标签/热度衰减 |
| ↑ 上升 | ↑ 上升 | ✅ 全面增长，趁热打铁发续集 |

### 6.5 额外流量与搜索

| 字段 | 解读 |
|------|------|
| **平台扶持流量** | 平台活动/热点/新人扶持等额外分发。> 0 说明被平台"翻牌子"，可作为正向信号；但不代表内容自身质量，不可持续依赖 |
| **搜索关键词** | 用户搜什么词进来的。空 = 无搜索流量。有关键词 = SEO 生效，这些词应复用到标题/文案/标签中 |

### 6.6 综合评分权重参考（百分制）

用于步骤 5 综合评估时的打分依据：

| 维度 | 权重 | 子维度及分值分配 |
|------|------|----------------|
| **流量规模** | 15分 | S级(15) / A级(12) / B级(9) / C级(6) / D级(3) |
| **内容吸引力** | 25分 | 完播率(10) + 2s跳出率(8) + 5s完播率(7)，每项按与黄金标准的差距线性扣分 |
| **互动质量** | 20分 | 点赞率(6) + 评论率(5) + 分享率(5) + 收藏率(4) |
| **流量健康度** | 15分 | 推荐流占比(8) + 来源多样性(4) + 不感兴趣率(3) |
| **文案结构** | 15分 | 黄金六秒(5) + 2113544完整度(6) + 钩子类型匹配(4) |
| **传播潜力** | 10分 | 分享率(4) + 搜索关键词覆盖(3) + 平台扶持(3) |
