# 对标拆解与仿写框架

拿到「综合数据 + 口播逐字稿」后，按本框架把一条视频拆成可复用的结构。

---

## 一、黄金六秒逐句拆

把逐字稿前 6 秒按时间轴切开（用 `.json` 里的 `segments` 时间戳），逐句标注：

| 时间 | 原句 | 承担功能 | 钩子类型 |
|---|---|---|---|
| 0–2s | | 钩子：拦住划走的手 | 见下方钩子类型表 |
| 2–4s | | 痛点：让人对号入座 | |
| 4–6s | | 承接：给出继续看的理由 | |

**钩子类型表**（判断作者用的是哪一类）：

| 类型 | 特征 | 例句结构 |
|---|---|---|
| 悬念钩 | 先抛结果不给原因 | "我花了 3 万才知道……" |
| 利益钩 | 直接给好处 | "这招能帮你省一半钱" |
| 身份钩 | 精准点名人群 | "在 XX 开店的老板注意了" |
| 反常识钩 | 推翻共识 | "别再做 9.9 引流了，那是自杀" |
| 冲突钩 | 制造对立 | "同行都在骂我，但我还是要说" |
| 场景钩 | 还原具体画面 | "昨天有个客户进店就问……" |
| 数字钩 | 用具体数字建立可信 | "3 个动作，核销率从 40% 到 78%" |
| 提问钩 | 直接发问 | "你知道为什么你的团购没人核销吗？" |

**判定**：钩子类型 × 数据表现，形成归因。如"用了悬念钩但分享/点赞仅 5%"→ 悬念只留住了人，没给转发理由。

## 二、2113544 结构映射

把整段逐字稿切成七块，缺哪块直接标 **⚠️ 缺失**：

| 段 | 时长/数量 | 功能 | 原文对应 | 判定 |
|---|---|---|---|---|
| **2** | 2 秒 | 钩子 | | |
| **1** | 1 个 | 痛点 | | |
| **1** | 1 个 | 方案 | | |
| **3** | 3 个 | 卖点 | | |
| **5** | 5 秒 | 信任背书 | | |
| **4** | 4 秒 | 互动引导 | | |
| **4** | 4 秒 | 转化引导 | | |

**结构缺口 ↔ 数据异常 交叉归因表**：

| 数据异常 | 高概率结构缺口 | 修复动作 |
|---|---|---|
| 收藏/点赞 偏低 | 「3 卖点」缺失或未清单化 | 把卖点改写成"第一…第二…第三…"的可记忆清单 |
| 分享/点赞 偏低 | 缺「替我说话」的观点句 / 无转发指令 | 结尾加"转给那个还在 XX 的朋友" |
| 评论/点赞 偏低 | 「4 互动」缺失 | 抛开放式提问、埋一个可被纠错的细节 |
| 互动全低但时长很长 | 钩子失效，前 2 秒没拦住人 | 换钩子类型，把最强信息前置 |
| 点赞高但转化差 | 「4 转化」缺失或引导太软 | 明确说出下一步动作（评论区/主页/团购） |
| 点赞/粉丝比 < 0.3 | 内容标签漂移，推给了泛人群 | 统一选题垂直度，连发同类内容重建标签 |

## 三、内容要素清单（除口播外）

从数据卡里同步核对：

- **标题文案**：字数、是否含钩子、是否埋搜索词
- **话题标签**：数量、是否含垂直行业词、是否含地域词（本地生活必看）
- **@提及**：是否借势蹭号
- **BGM**：是否用热门音乐（热门 BGM 有额外流量加成）
- **时长**：与内容密度是否匹配（口播类 30–60s 为主流，超 3 分钟需要极强内容支撑）
- **分辨率/画幅**：是否竖屏 1080×1920，非标画幅会损失推荐

## 四、仿写模板产出格式

把拆解结果抽象成**可填空模板**，用户换词即用：

```
【钩子·2s】{钩子类型}：______________________
【痛点·1】______________________，是不是你？
【方案·1】其实只要 ______________________
【卖点·3】第一，______；第二，______；第三，______
【信任·5s】{数据/案例/资质}：______________________
【互动·4s】你觉得 ______？评论区告诉我
【转化·4s】{明确下一步}：______________________
```

同时给出：
- **本条为什么成立**（1–2 句，指出最关键的那个动作）
- **复用时最容易翻车的点**（1–2 句，通常是信任背书无法照搬）
- **3 条同结构选题建议**（贴合用户所在行业）

## 五、发布前自检清单（交付仿写稿时附上）

- [ ] 前 2 秒能否独立成立（静音看画面也能懂？）
- [ ] 痛点是否精准到具体人群，而非"所有人"
- [ ] 3 个卖点是否可被复述
- [ ] 信任背书是否有具体数字或可验证事实
- [ ] 是否有明确的互动指令与转化指令
- [ ] 标题是否埋了搜索词（"两头吃"：推荐流引搜索 + 提前占搜索结果）
- [ ] 话题标签是否含垂直词 + 地域词
- [ ] 本地生活类：是否挂 POI 锚点、是否指向团购核销而非只求 GMV
- [ ] 是否规避违规词与低价洗流陷阱
