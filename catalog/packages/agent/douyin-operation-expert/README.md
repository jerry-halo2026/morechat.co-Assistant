# 抖音精细化运营专家 (douyin-operation-expert) v1.2.0

抖音短视频、直播与团购本地生活精细化运营操盘手，方法论源自「纸鹤的知识库 · 陈雯直播」与「陈雯大号抖音」一线实战体系（陈雯momo「团购5A人群打法」+「实体抖音3451打法」），并融合**字节官方《生意经 4L人群产品使用手册》《生意经 5A6C人群产品使用手册》**的权威口径（含餐饮综合/酒旅行业计算口径、6C、八大人群、触点归因、人群包圈选、人群流转、诊断QA）与抖音官方合规规范。

## 类型

Agent 型（单个 AI 专家）

## 核心能力

- **总纲 3451 框架（三角四步五流一IP）**：黄金三角盈利（前端流量到店 / 中端品牌声量降本增效 / 后端区域化IP+后端模式收割）、五流打法（内容/商城/线下/截流/投流），统筹全链路。
- **官方生意经 5A/5A6C/4L 人群资产（含行业口径）**：A1 了解/A2 吸引/A3 问询/A4 行动/A5 拥护 五层 + 内圈 6C（支付新客/核销新客/复购/忠诚/沉默/支付唤醒）；掌握**餐饮综合（近15天窗口）与酒旅（近60天窗口）精确计算口径**、互斥倒序判定、次卡多天核销特殊处理；4L（潜在/新客/活跃/沉默）精简诊断；5A6C 开通门槛（餐饮≥40/综合≥35/酒旅≥12 POI）。穿透 2026 年 A3 注水，用"拉资产 → 高 A3 配比 → 洗成真 A3/A4"提升资产质量。
- **八大人群 + 触点归因 + 人群运营实操**：资深中产/新锐白领/精致妈妈/都市蓝领/城镇青年/GenZ/城镇中老年/都市银发 精准定向；解释"触点唯一归因"与"画像不一致=自然流量不受投放定向控制"；用人群包圈选（5A6C+八大人群+地域→本地推/优惠券/消息触达）、人群流转 4 场景（新增/认知加深/种草转化/提升忠诚）、Benchmark 对比、诊断 QA（A1/A2/A3 下降排查）与高频场景（直播大场前中后、货盘价格/场景拉新）给落地动作。
- **M1-M3 流量 + 商城 7 大来源 + 搜索小蓝词**：区分内容/自然交易/付费流，纠正"商城=商品卡"误区，用"埋钩子 → 两头吃"拿精准搜索流，理解 POI 白/绿锚点差异。
- **成交效率与本地生活 ROI 生死线**：以"成交金额/商品曝光指数"评估效率；双 50% 基准下全域 ROI ≥ 10 才不亏，警惕 9.9 元低价洗流陷阱。
- **直播观看模型 / 成交模型打法**：浅层/深层数据判断推流模型，排水+转移焦点聚拢精准人群，确定性原则，直播前 7 天打 A1/A2 冷启，诊断流速/断崖、成交密度 vs 规模。
- **经营分四分四榜一热度**：经营分（部分类目上不封顶 200+，已拆单店/连锁版）/ 服务分 / 违规分 / 信用分 + 人气/收藏/好评/热销四榜 + POI 热度。
- **短视频脚本与黄金数据标准**：黄金六秒 + 2113544 法则，附推荐流占比 > 90%、5 秒完播 > 40% 等验收标尺。
- **养号、本地推、矩阵与职人/达人方向**：7 天养号、本地推优先消耗真 A3/活 A4/A5、商品卡/团购卡为主形态、矩阵分工、职人「马场理论」、达人三方向。

## 安装 / Installation

本包由 **morechat.co-Assistant** 内容仓分发，**通过 morechat.co-Assistant 目录导入**：

1. 在 morechat.co-Assistant 仓中取出 `catalog/packages/<kind>/<id>/`；
2. 该目录即包根目录，内含 `plugin.json`、`agents/`、`skills/`，整体作为包目录导入；
3. 导入后由平台注册 Agent / Squad 与技能，无需额外安装脚本或注册命令；
4. 头像不在仓内分发（`avatars/` 已移除），由产品端生成。
