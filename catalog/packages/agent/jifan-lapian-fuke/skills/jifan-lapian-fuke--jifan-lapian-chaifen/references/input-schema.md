# 输入结构

## 输入结构

顶层字段：

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| topic | string | 是 | 这份成稿的主题，会成为标题 |
| items | array | 是 | 至少 1 项，结构见下 |
| pending | array | 否 | 你自己标注的待确认事项，会原样列进成稿 |

`items[]`（候选条目）：

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| title | string | 是 | 条目名 |
| content | string | 否 | 可直接取用的内容 |
| note | string | 否 | 适用场合或备注 |
