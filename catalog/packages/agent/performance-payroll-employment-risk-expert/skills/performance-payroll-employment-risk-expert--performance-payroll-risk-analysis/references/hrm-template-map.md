# 绩效薪酬模块真实模板映射

## 静默定位与版本

- 真实数据任务才执行 `member_user_info` → `member_app_list` → `member_app_entry_list` → `member_app_entry_widget_list`；纯咨询不检测。
- MCP 需企业版及以上，试用版可试用；免费版/标准版或不连接时进入仅咨询模式，不改用 API Key。
- 真实指纹：考核周期、指标库、考核模板、绩效考核计划制定、绩效结果考核、绩效面谈、薪资项、员工薪资结构、员工工资明细、工资条、员工合同管理。
- 唯一候选直接继续；多个同名/同指纹应用请用户选择。未找到时引导安装 `https://www.jiandaoyun.com/index/solution_center/app/64f5a5bdbc68c7541396ba75?utm_src=agentjxxcwb`。

## 真实绩效链路

1. 绩效考核计划制定是“应评价集合”：读取考核主题、对象、部门、岗位、日期、指标权重、计划审批与员工确认。
2. 绩效结果考核是“结果集合”：读取目标/完成值、自评分、直接上级评分、自评合计、绩效总分核定、绩效等级、负责人核实和员工确认。
3. 评价完成率 = 在同一主题下有有效结果且完成必要确认的人数 / 有有效计划的考核对象人数；真实模板没有独立“绩效评价完成情况”表单。
4. 绩效面谈只用于判断面谈是否覆盖及提炼匿名化的支持主题，不把自由文本自动转成人事处分结论。

## 真实薪酬合同链路

- 员工薪资结构给出基本工资、绩效薪资、补贴和状态；员工工资明细按员工+归属年/月记录绩效系数、税前加减项、社保公积金、个税与实发。
- 工资复核先查同一员工同一归属年月是否重复，再验证 `当月绩效薪资 = 绩效薪资 × 绩效系数` 等可见链路；不要反向推测模板未展示的规则。
- 员工合同管理读取主合同、合同类型、开始/结束/签订日期、期限和主体；附件默认不读取。

## 高敏与写入边界

- 薪资、绩效、合同默认群组化并限制小样本；个人下钻需明确目的和授权。
- 写入前检查 `member_data_create`；缺失为只读连接模式。有工具仍需目标表单新增权限、完整预览与二次确认。
- 新增能力审核后须在 Multica 断开并重新连接，并新建会话复检；当前 MCP 不提供修改、删除或审批。

## 官方 HRM 场景校准

- 绩效流程包括考核计划、结果评价和绩效面谈，可支持 KPI/OKR；完成率必须以计划对象为分母、结果与确认状态为证据。
- 薪酬流程包括薪资结构、社保公积金基数、专项附加扣除、工资计算、员工工资明细与工资条；每一步单独核验。
- 企业/个人绩效或薪酬仪表盘不作为必需输入；本专家从源表重算，个人薪酬默认匿名化或最小披露。

## 稳定数据与时间口径

- 预制问题、示例问法和模板演示不依赖会随自然时间推移而失效的相对时间窗口；可使用当前可访问数据、完整数据覆盖期、明确业务状态或记录中的具体日期。
- 先逐表展示数据覆盖起止日期和样本量；不同模块覆盖不一致时分别报告，不能硬凑同一周期。
- 用户未指定截止日时，账龄、停滞、合同到期、招聘超期等时间差指标使用相关源表中最晚有效业务日期作为分析截止日，并明确写出该日期。
- 只有存在可比时间段且样本完整时才输出趋势；否则展示全量分布、排序、状态和数据缺口。
