## 状态说明

| 状态 | 含义 | 下一步动作 |
|------|------|-----------|
| 意向 | 找到岗位，还没投 | 定制简历后投出 |
| 已投递 | 简历已投出 | 7~10 天后无回复则跟进 |
| 笔试 | 收到笔试/测评 | 按截止时间完成 |
| 面试中 | 已进入面试流程 | 排期 + 按 `interview-prep.md` 准备 |
| 已挂 | 明确被拒或石沉大海 | 记入复盘，不再投入精力 |
| Offer | 收到 offer | 按 playbook 第 6 节对比、谈薪、确认 |

## 复盘区

每周一行，复盘时填写（模板见 playbook 第 7 节）。

| 日期 | 本周数据 | 发现的问题 | 下周行动 |
|------|---------|-----------|---------|
| （例：2026-09-14） | 投 18 / 回 4 / 面 1 / offer 0 | 投了没回复的多是海投渠道 | 换内推渠道，改 3 份简历 |
| | | | |

## 使用说明

1. 每投一个岗位，在主表加一行；状态变化时更新「状态」和「下一步」；
2. 每周固定时间更新周统计 + 复盘区，卡点诊断方法见 playbook 第 7 节；
3. 复盘时把「已挂」的岗位当数据看，不当自我评价；
4. 面试前后及时更新「面试准备」状态；每次结束后和专家约定「下次复盘日期」并填入基本信息。
