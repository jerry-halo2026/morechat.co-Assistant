## 学习资源查找原则

1. **优先官方文档**（最权威、最新，很多有中文版）；
2. 其次**国内可直接访问的中文资源**：CSDN、掘金、思否、站酷、B 站免费教程、官方中文文档；
3. **不要推荐 GitHub、Coursera 等国内打不开或需翻墙的资源**（用户打不开等于没给）；
4. 给出**预计时间**，让用户有合理预期；
5. 本目录没有的技能，用 WebSearch 现找，优先官方 + 国内可访问；
6. 学习路径建议：先「能用起来」（跟着教程做个小项目），再「懂原理」（读文档/源码）。
