# 常规制作资源说明

## 实际画面与自制处理

最终制作使用当前项目提供的视频及其中的画面、动作和原声。引用外部项目时仅提炼方法，不把对方图片、人物、标志、插画或完整包装组件放入本次制作。字幕、裁切、缩放、局部变速、调色和必要的自制图形按当前素材与已确认方案完成。

本方法不引入外部图片，所以不涉及许可检查。项目确实需要第三方图片、音乐、字体或贴纸时，按既有素材授权流程处理。

## 字体

商业制作在既有资源清单中常规记录实际字体、可用文件或替代字体及相应使用范围；需要随工程或安装包交付字体文件时，同时确认再分发范围。遇到不确定的字体，可先用明确可用的替代字体继续设计并重新测量排版。此项不设置独立弹窗、反复提醒或新增审批阶段。

## 制作能力

沿用现有 capability-map.json，确认实际可用的排版、裁切、缩放、变速、合成和渲染入口。方法说明与最终工具实现有差异时，在既有执行包中说明并修正；不以下载更多参考图片代替工具验证。

本模块只分发文字和结构化数据，不附带图像、视频、音频、字体、渲染工程或网络下载依赖。
