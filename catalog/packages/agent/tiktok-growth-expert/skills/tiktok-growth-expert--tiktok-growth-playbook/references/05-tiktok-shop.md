# 05 TikTok Shop 带货实操

## 1. 开店与入驻

- **跨境店（中国主体）**：通过 TikTok Shop 跨境招商入驻，需企业营业执照 + 法人信息 +
  类目资质；保证金按类目/市场收取（不同站点差异大，以招商页面为准）。
- **本土店**：需目标市场本地主体/身份，中国卖家一般用跨境店或与本地服务商合作。
- **达人带货（不开店）**：满足门槛后开通电商权限，挂「联盟选品广场」里的商品赚佣金，
  零库存零售后，是个人创作者首选。
- 入驻状态、类目开放和保证金随时调整，以 TikTok Shop  Seller Center 实时页面为准。

## 2. 选品方法论（七分靠选品）

**好品的 6 个特征**（满足 4 个以上再测）：
1. 可视化卖点：效果能 3 秒演示出来（清洁、收纳、美妆工具、宠物用品）
2. 客单价 $10–$50：冲动消费区间，决策成本低
3. 毛利 ≥ 50%（达人佣金通常 10–20%，店播还要留投流空间）
4. 轻小不易碎：物流成本低、售后少
5. 非强季节/强尺码：SKU 复杂度低
6. 复购或耗材属性：能沉淀长期店铺权重

**选品情报来源**：TikTok Shop 官方热卖榜、Creative Center 趋势、
EchoTik/嘀嗒狗等第三方数据工具、亚马逊 Best Seller 交叉验证、评论区找痛点。

## 3. 达人联盟玩法（卖家视角）

- **开放计划**：设佣金比例（常见 10–20%）挂在选品广场等达人来带，零成本铺量。
- **定向计划**：主动邀约垂类达人，给更高佣金 + 免费样品。
- **建联话术要点**：说明产品卖点 + 佣金 + 已出的销售数据 + 提供素材支持；
  批量触达每天 50–100 个，回复率 5–15% 属正常。
- **达人分层**：1k–10k 粉的纳米达人转化率常常最高且免费/低成本可谈；
  头部达人要坑位费，ROI 难保证，品牌曝光需求再考虑。

## 4. 挂车短视频（达人带货核心动作）

- 结构按 02 分册「带货万能结构」，额外注意：
- **选品广场选品三看**：佣金率 ≥ 15%、店铺评分 ≥ 4.5、30 天销量在爬升。
- **一视频一车**：只挂讲的那个商品，不挂一串。
- **原创实拍**：自己买样/申样实拍，搬运混剪挂车是限流和清退高危区。
- **评论区维护**：置顶购买指引；问尺码/链接的 1 小时内回。

## 5. 店播 vs 达播怎么选

| 维度 | 店播（自己播） | 达播（给达人佣金） |
|---|---|---|
| 成本 | 场地+人力+投流，固定成本高 | 纯佣金，卖一单付一单 |
| 控制 | 话术/价格/节奏全可控 | 不可控，依赖达人能力 |
| 起量速度 | 慢（要养直播间） | 快（借达人现成流量） |
| 适合阶段 | 有稳定货源 + 长期经营 | 冷启动测品 + 快速出单 |

**实操建议**：新店先用达播铺 100–300 单验证产品力与履约，同时搭店播间；
两条线不是二选一，成熟期是「店播做利润 + 达播做规模」。

## 6. 履约与售后红线

- 发货时效：按站点要求（通常 2–3 个工作日内有揽收记录），超时影响店铺分。
- 店铺健康分：差评率、退货率、客服响应时长都影响流量分配；
  差评 24h 内主动联系处理。
- 禁售/限售类目入驻前查清（美妆个护、食品、儿童用品多有额外资质）。
