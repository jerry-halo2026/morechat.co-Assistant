# 07 数据分析与诊断复盘

## 1. 后台入口与看数顺序

- 入口：个人主页 → 右上角菜单 → Creator tools / Business suite → Analytics。
- 看数顺序：先看「流量来源」判断流量结构 → 再看「单条视频数据」找内容问题
  → 最后看「粉丝数据」校准受众。

## 2. 流量来源结构（判断账号健康度的第一眼）

| 来源 | 健康占比 | 解读 |
|---|---|---|
| For You（推荐） | ≥70% | 推荐流量是主引擎，占比越高越健康 |
| Followers（粉丝） | 5–15% | 过高说明新流量进不来（吃老本） |
| Search（搜索） | 3–10% | 占比高 = 内容有长尾价值，可多铺关键词 |
| Profile（主页） | 低 | 单条爆款带看主页属正常 |

**危险信号**：For You <50% 且持续下滑 = 内容被打入低质或标签漂移，回到 03 分册诊断树。

## 3. 单条视频诊断表

每条发布 48h 后填一次：

| 字段 | 记录 | 判断 |
|---|---|---|
| 播放量 | ___ | 相对账号均值是几倍/几折 |
| 3 秒留存 | ___% | <45% → 钩子问题 |
| 完播率 | ___% | <30% → 结构/节奏问题 |
| 平均观看时长 | ___s | 对照视频总长看弃看点 |
| 评论/分享/点赞率 | ___% | 互动弱 → 缺 CTA/争议点 |
| 涨粉 | ___ | 高播放不涨粉 → 缺系列感/人设 |
| 流量来源 | ___ | For You 占比 |

**弃看点分析**：后台留存曲线在哪一秒出现陡坡，那一秒的画面/话术就是问题点，
下一条在对应位置做改进（换画面/加信息点/提前爆点）。

## 5. 直播间数据复盘（与 04 分册配套）

直播后台核心看板：观看人数曲线、进房率、平均停留、互动、商品点击、成交、GPM。
- **观看曲线**：每个峰值/谷底对应当时的话术和动作，标注在曲线上，峰值动作复用、谷底动作删除。
- **转化漏斗**：进房 → 停留 ≥1min → 商品点击 → 下单，逐层找最低转化环节，每周只优化最弱一环。

## 7. 数据解读三原则

1. **看相对值不看绝对值**：和自己过去 10 条比，不和头部账号比。
2. **单点数据不决策**：至少 3–5 条同结构视频的数据趋势才下结论。
3. **每次只改一个变量**：否则无法归因，等于没复盘。
