# 08 避坑指南与合规红线

## 1. 封号/限流高频原因（按踩坑概率排序）

| 原因 | 表现 | 预防 |
|---|---|---|
| 搬运/混剪非原创 | 0 播、判非原创、清退电商权限 | 实拍原创；二创必须有实质性再创作且注意版权 |
| 其他平台水印 | 抖音/快手水印视频 0 播 | 素材去原平台下载前拍原片 |
| 账号环境异常 | 注册即限流、无法开直播 | 一机一号一稳定网络环境；不频繁切换地区 |
| 刷粉刷量 | 清粉、限流、门槛审核不通过 | 不碰，没有任何例外 |
| 硬导流 | 限流、直播警告 | 用 Bio 聚合链接，不口播站外联系方式 |
| 音乐版权 | 视频静音/下架 | 商用号只用 Commercial Music Library |
| 违规内容 | 警告→限流→封号 | 见第 2 节红线清单 |
| 直播违规 | 断播、禁播 1–30 天 | 提前读 LIVE 社区规范；着装/烟酒/未成年人出镜都有细则 |

## 2. 内容红线（绝对不要碰）

- 涉政敏感、仇恨言论、歧视内容
- 裸露/性暗示（含直播着装暴露）、未成年人不当内容
- 血腥暴力、危险挑战（吞物、极限动作无保护）
- 医疗断言（「治愈」「根治」）、减肥产品功效承诺
- 假货、仿牌、侵权 IP（迪士尼/漫威等形象直接商用必死）
- 虚假折扣/虚假功效（电商内容另受广告法约束）
- 赌博、金融荐股、加密货币喊单

## 3. 账号环境规范（跨境用户必看）

- **一机一号**：一台设备稳定登录一个号；多号矩阵用独立设备或合规的多开方案。
- **网络环境稳定**：固定目标市场对应的网络出口，不频繁跳地区
  （今天美国明天东南亚 = 判异常）。本专家不提供任何规避网络限制的技术指导，
  请使用合规的跨境网络服务与运营商方案。
- **资料真实**：生日、地区与后续提现/开店实名信息保持一致，否则卡在审核。
- **操作像真人**：不要新号注册 10 分钟内发视频、批量关注取关。

## 4. 音乐与素材版权

- 个人娱乐可用普通音乐库；**只要挂车/开店/接商单就是商用**，
  必须切换到 Commercial Music Library（CML），否则有被静音/下架/索赔风险。
- 影视/综艺切片、他人视频混剪带货：版权方投诉即下架，账号权重受损；
  明星脸/声音做素材有肖像权风险。
- 字体、贴纸、模板同样注意商用授权（用 TikTok 官方编辑器内的素材最稳）。

## 5. 电商合规

- 禁限售类目入驻前查 Seller Center 类目规则（武器、药品、成人用品、部分食品等）。
- 商品描述与实物一致：夸大宣传 = 退货率飙升 + 店铺扣分。
- 价格合规：先涨后降的假折扣被平台监测到会处罚。
- 目标市场法规：美区 FTC 要求达人推广必须披露（#ad / 付费合作标签）；
  欧盟有 DSA 与消费者权益指令，英国有 ASA 规范，投放市场前各查一遍。

## 6. 申诉与自救

- 误判处理：App 内「报告问题」→ 对应视频/直播提交申诉，48–72h 有结果，
  申诉时说明原创过程（附工程文件/花絮截图成功率高）。
- 被限流自救 SOP：停发 3–7 天 → 清理违规视频 → 恢复后连发 7 条纯原创优质内容
  → 数据仍异常再考虑起新号（老号有权重别轻易放弃）。
- 账号被盗/被封无法登录：通过官网反馈表单 + 注册邮箱申诉，准备实名资料。

## 7. 割韭菜识别（帮用户避坑）

遇到以下话术一律警惕：
- 「无脑搬运日入过千」「内部渠道保过审」「买号直接带货」
- 高价卖「防封技术」「独家流量密码」
- 培训方自己账号数据拿不出来，只晒收益截图
判断标准很简单：真正跑通的人给你看的是后台视频数据，不是收款截图。
