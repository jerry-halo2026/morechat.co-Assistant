# 03 算法与流量机制

## 1. 流量池逐级推荐模型

每条视频发布后进入「赛马」机制，逐级放量：

| 层级 | 曝光量级（经验值） | 晋级看什么 |
|---|---|---|
| 初始池 | 200–500 | 账号权重 + 内容安全审核通过 |
| 一级池 | 1,000–3,000 | 初始池的完播率、互动率达标 |
| 二级池 | 1 万–10 万 | 持续互动 + 分享率 + 复播率 |
| 大流量池 | 10 万+ | 各指标全面优秀 + 人工复审无风险 |

**关键认知**：每一级都看「这批观众的反馈数据」，不是粉丝数。
所以 0 粉新号也能爆——前提是初始池数据达标。

## 2. 核心指标权重与及格线

按对推荐的拉动作用排序（经验权重，非官方公布）：

| 指标 | 计算 | 及格线 | 优秀线 |
|---|---|---|---|
| 完播率 | 看完人数/播放 | ≥30%（15s 内短视频） | ≥50% |
| 3 秒留存 | 3s 留存/播放 | ≥45% | ≥65% |
| 复播率 | 重复观看比例 | ≥5% | ≥15% |
| 评论率 | 评论/播放 | ≥0.5% | ≥1.5% |
| 分享率 | 分享/播放 | ≥0.5% | ≥1% |
| 点赞率 | 点赞/播放 | ≥3% | ≥8% |
| 关注转化 | 新增关注/播放 | ≥0.5% | ≥2% |

**诊断口诀**：播放低看完播，完播低看 3 秒，3 秒够高看选题（是不是池子内人群就不对）。

## 3. 标签系统与账号打标

- **内容标签**：系统从画面（CV 识别）、文案、Hashtag、BGM、评论区关键词综合判定视频主题。
- **兴趣标签**：系统判定「哪类人爱看这条视频」，把视频推给同类人。
- **打标方法**：连续 10–20 条同细分主题 + 同类受众互动（见 01 分册养号节）。
- **打标成功的信号**：推荐流量占比 ≥ 80%、播放稳定在层级内、评论区出现精准受众
  （如宠物号评论都在聊狗）。

## 4. 播放量卡层级诊断树

**现象 A：0 播 / 个位数播放（发布 24h 后）**
1. 审核未过：查「账号状态-违规记录」；搬运/水印/敏感内容直接被掐。→ 换原创重发
2. 账号环境问题：设备/网络异常被判定为虚假账号（见 08 分册）。→ 先解决环境再发
3. 被限流（shadowban）：连续违规后触发，特征是多条连续 0 播。→ 停发 3–7 天 + 申诉 + 之后纯原创

**现象 B：卡在 200–500 播放**
1. 完播率 <20%：钩子不行或前 3 秒拖沓 → 按 02 分册钩子公式重剪
2. 内容标签混乱：今天发猫明天发菜 → 回到单一主题连发 10 条
3. 账号权重低：新号正常现象 → 继续日更，等一条跑出来的视频带权重

**现象 C：卡在 1000–5000**
1. 互动率不足：加 CTA、加争议点、评论区自导讨论
2. 选题受众太窄：换更大的需求切口（「金毛训练」→「狗狗在家搞破坏怎么办」）

**现象 D：有播放不涨粉**
1. 内容没系列感，单条爆但没有关注理由 → 做系列 + 主页三件套
2. 人设缺失 → 固定片尾口播/固定开场白强化记忆点

## 5. 不要做的事（算法侧）

- 发布后 1 小时内反复删除重发（判定低质）
- 用同一 WiFi/设备批量账号互相点赞（关联降权）
- 买粉刷数据（虚假互动清洗期直接限流，且无法通过变现门槛审核）
- 带其他平台水印（抖音/快手/Ins 水印视频直接掐流量）
