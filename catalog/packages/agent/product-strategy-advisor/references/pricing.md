# 定价与变现细部

## 一、设计一个定价方案
走五步，每步都停一下确认：

1. **先看价值，再谈价格**：这个产品给对方带来什么可量化的结果（省多少时间 / 增加多少收入 / 省多少成本）？他的现实替代方案是什么、花多少钱？依据价值估他的承受价。
2. **选定价模型**（用这张表帮他挑最合适）：
   | 模型 | 最适合 | 例子 |
   |---|---|---|
   | 一口价（Flat） | 简单产品、成本可预测 | 月费一款 |
   | 按人（Per-seat） | 协作工具、团队产品 | Slack、Figma |
   | 按用量（Usage） | 基础设施、API | AWS、Twilio |
   | 分层（Tiered） | 有明显人群差异 | 大多数 SaaS：免费/专业/企业 |
   | 免费增值（Freemium） | 有病毒/网络效应 | Spotify、Notion |
   | 免费+按用量 | 平台型 | Vercel、OpenAI API |
   | 按价值（Value-based） | 高影响企业工具 | Salesforce |
3. **竞争对照**：同类/近似怎么定价、覆盖哪段人群，找出"价格锚"，定位自己在高端/中性/廉价哪一档，找价格空档。
4. **估算承受价（WTP）**：问用户"目标用户能接受的心理价位区间"和依据。
   - **不编数字**：承受价是用户/调研才知道的，标"待确认/待你填"。
5. **给建议 + 实验**：给推荐价（说明理由）+ 最小验证（定价页 A/B、预订价、意向表单）。
   - 红线思维：跌破某价说明定价错了/痛点不对，别硬扛。

## 二、设计分层结构（模型选定后）
- **层数**：2–4 层即可，每层差异要清楚，别堆。
- **功能划分**：按**价值单位**分，别按"拍脑门上限量"——你按什么收费就凭什么分（用户数/事件/存储/调用）。
- **锚定定价**：让"最主流的中间那层"显得是明显划算的选择。
- **年度折扣**：通常按月价给 15–20% 的折扣。

## 三、估算价格敏感度
有调研数据时可用 **Van Westendorp 价格敏感度** 四问，看每档人群反应：
- **太便宜**：会担心品质 → 你的质量信号够吗？
- **便宜**：觉得划算 → 这是理想区
- **贵**：开始犹豫 → 守住价值主张
- **太贵**：直接不买 → 超了承受线

没有调研就用竞品价 + 价值估算兜底。

## 四、探索变现路径
用户在做商业化决策时，头脑风暴 **3–5 条赚钱路子**，每条标：
- **做法**：订阅/卖服务/卖数据/BD 分成/专业版…
- **与用户契合度**：跟不跟得上你的价值与人群
- **风险**：最大风险是什么
- **最小实验**：怎么低成本验证可不可行
给出排序倾向（但让用户拍板）；警惕"卖数据"这类敏感路径，提醒信任与合规代价。

## 五、常见坑（主动提醒）
- 定价过低、用低价掩盖价值不清 → 问清"定价低的真实原因"？
- 免费层过猛把付费全吸走 → 免费到底服务什么、不服务什么。
- 不跟进实验、拍脑袋定死 → 定价来自验证，不来自偏好。
