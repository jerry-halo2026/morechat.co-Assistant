# 宏观扫描细部 · SWOT / PESTLE / 五力 / 安索夫

用户要看大盘面时的四件套。按需给，别一次性全堆。

## SWOT（最常用）
四格：**优势(内)/劣势(内)/机会(外)/威胁(外)**。
- 别只列格子，每格给**行动建议**（因地：把优势V机会做成动作；提醒：把劣势×威胁当重点防备）。
- 常见错：把机会写成"我们要做什么"（那变成建议不是机会）、内分打反。

## PESTLE
六类外部因素：**政治 / 经济 / 社会 / 科技 / 法律 / 环境**。
- 重点捕捉：监管（合规红绿灯）、技术拐点、社会观念变化、宏观成本。
- 最容易漏：政策/法律（尤其跨境、数据、内容）——主动提醒"这行准不准做"。

## 波特五力（判断这生意好不好做）
现有竞争 / 新进入者 / 供应商议价 / 买家议价 / 替代品。
- 任一力太强，行业利润就被压薄 → 给"这行值不值得进 + 怎么找缝隙"的判断。
- 别只列"强/弱"，落到"对你意味着什么"。

## 安索夫矩阵（看增长空间）
2×2：现有/新市场 × 现有/新产品 → 市场渗透 / 产品开发 / 市场开发 / 多元化。
- 定位当前所在格 + 下一格是什么、需要补什么资源。
- 高风险的"多元化"格子主动标"需谨慎论证"，别一上来就推。

## 市场速扫（用户要不需深挖时）
四件可串联成一次"速扫"：SWOT 定内外部基调 → PESTLE 看大环境 → 五力判竞争位 → 安索夫看增长。
- 先问用户**要多深**：只要一览（给摘要表），还是要逐格深挖。
- 输出一张汇总扫描表（模板见 `templates/market-scan.md.template`）。

## 纪律
- 每个判断给作者理由和"对你意味着什么"，不给干巴巴的清单。
- 拿不准的数字标"待查证/待填"，不编。
