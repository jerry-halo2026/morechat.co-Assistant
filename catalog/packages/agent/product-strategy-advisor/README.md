# 产品战略顾问

## 安装 / Installation

本包由 **morechat.co-Assistant** 内容仓分发，**通过 morechat.co-Assistant 目录导入**：

1. 在 morechat.co-Assistant 仓中取出 `catalog/packages/<kind>/<id>/`；
2. 该目录即包根目录，内含 `plugin.json`、`agents/`、`skills/`，整体作为包目录导入；
3. 导入后由平台注册 Agent / Squad 与技能，无需额外安装脚本或注册命令；
4. 头像不在仓内分发（`avatars/` 已移除），由产品端生成。

## 运行时适配 / Runtime notes

- 向用户提问：使用 dsh-tool-ask-user（ask_user_question）；运行时无该能力时，改为在任务评论中提问并等待。
- 交付产物：使用 dsh-tool-present 声明交付；在任务评论中作为附件提交。
- 多角色协作：创建平台小队（Squad）并由 leader 通过 @ 派发子任务。
- 工具声明键为 `allowed-tools-dsh`（Task → subagent，AskUserQuestion → ask_user_question）。


帮你把一个产品「往哪走、凭什么赢、怎么赚钱」想清楚。不堆术语，全程大白话，一步步带你走。

## 这个专家是什么

当你手上有一个产品，或一个还在纸上的想法，但你不确定：

- 它到底该往哪个方向走？

- 凭什么别人会选它而不是现有方案？

- 它怎么赚钱、该卖多少钱？

这个专家会带你用一套套成熟的办法把这些一次性理清楚，最后交给你能直接用的草案、画布或定价表。

## 它能帮你做四件事

| 你想要的      | 它怎么帮你                     | 交付什么        |
| --------- | ------------------------- | ----------- |
| **定长期战略** | 带你从愿景到护城河，一格一格填战略画布       | 一份战略草案      |
| **理商业模式** | 用画布把你在为谁解决什么、怎么收费、成本在哪摆清楚 | 一张完整画布      |
| **定价与变现** | 设计定价方案，或列出几条赚钱路子并排出最值得先试的 | 定价方案 / 变现清单 |
| **看大盘面**  | SWOT、外部环境、竞争格局、增长空间       | 一份市场速扫      |

## 怎么使用

新建对话，像聊天一样说清楚你的产品就行，例如：

- 「我要给产品定个长期战略，帮我从愿景到护城河走一遍」

- 「帮我把这个想法的商业模式用精益画布理清楚」

- 「我要给产品定价，帮我设计个方案」

- 「我想看看这个市场值不值得进，帮我扫一下」

你不需要懂任何流程。它每走完一大块，会停下来问你一两句（比如"只能服务一群人，先服务谁？""你明确不做什么？"），其余自己完成，最后把能直接用的东西交给你。

## 它为什么值得用

- **不给空口号**：战略不是漂亮的 PPT，而是一串必须做的取舍——它会逼你想清楚"你明确不做什么"。

- **不骗你**：定价、承受价、市场容量这类只有你或数据才知道的数字，它标"待确认"，绝不编。

- **敢提醒**：你的方向或定价明显有问题时，它直说风险和更优解，但最后尊重你的决定。

## 目录结构

- `agents/` — 该专家怎么工作的说明

- `references/` — 背后用到的各种方法详解

- `templates/` — 交付使用的表格模板

- `examples/` — 一单完整演示

- `avatars/` — 专家头像

## 你在这条"从点子到做好"路的哪一步

把这套专家想成一条生产线的 10 个岗位。按顺序走，每个岗位把前一步接过来、干好自己的活、交给下一站：

| 顺序 | 顾问 | 这一步解决什么 |
|---|---|---|
| 1 | 市场调研 | 看清市场/竞品/用户，决定值不值得进 |
| 2 | 产品战略 | 想清往哪走、凭什么赢、怎么定价 |
| 3 | 产品发现 | 验证想法，找到最该赌的假设 |
| 4 | 落地执行 | 写 PRD、拆故事、排迭代，把想法做成 |
| 5 | AI 交付 | （有 AI 功能时）上线前审计、测试、文档 |
| 6 | 数据分析 | 定指标、取数、读实验、看留存 |
| 7 | 上市 | 推到市场、定目标客户、排上市计划 |
| 8 | 增长营销 | 获客、营销点子、定位文案、命名 |
| 9 | 运营 | 上线后留存、激活、客户成功、运营循环 |
| 10 | 通用工具 | 随手的：NDA、隐私、校对、简历 |

**你现在正在用「2. 产品战略顾问」。**

- 前面的事没做扎实？先往回补一两步再去推进。
- 做完这件，自然把结论交给下一位（例如调研做完，拿结论来找战略定方向）。
