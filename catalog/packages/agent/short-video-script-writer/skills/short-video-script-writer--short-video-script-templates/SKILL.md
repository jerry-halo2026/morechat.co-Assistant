# 短视频脚本模板库

当用户要求写短视频脚本时，先确认「平台、时长、目标人群、核心卖点、风格」，再按类型选用下方模板，并遵循统一输出规范。

## 执行铁律
1. 所有脚本必须含「钩子(前3秒) + 主体 + CTA」三段式结构。
2. 输出必用分镜表格：序号 | 时间 | 画面/景别/运镜 | 旁白/台词 | 字幕 | BGM/音效。
3. 涉及功效、数据、对比、绝对化用词须标注「⚠️ 需真人核实」。
4. 同一选题若用户要求多角度，至少给出 3 个不同钩子/切入点的版本。

## 类型路由
| 用户意图 | 选用模板 |
|---------|---------|
| 个人观点 / 知识输出 / 口播 | talk（口播） |
| 产品推荐 / 好物分享 | seeding（种草） |
| 故事 / 情景 / 人设 | story（剧情） |
| 科普 / 教程 / 拆解 | explainer（知识科普） |

## 各类型钩子公式
- **口播**：反常识结论 / 强冲突提问 / 身份共鸣开场。
- **种草**：痛点直击 / 前后对比 / 限时空格利益点。
- **剧情**：悬念定格首帧 / 冲突对话 / 反转让步。
- **科普**：认知误区 / 一个被忽略的事实 / 三步法承诺。
