# 短视频脚本创作专家（Short Video Script Writer）

专注短视频脚本创作的 AI 编导，覆盖抖音、快手、视频号、小红书、B站等平台，将模糊选题转化为可拍摄的结构化脚本。

## 类型
Agent 型（单个 AI 专家）

## 核心能力
**基础生产**：平台洞察 · 选题钩子 · 结构编排 · 文案撰写 · 分镜思维 · 类型化脚本（口播/种草/剧情/知识科普）· 爆款5步拆解法 · 通用合规风控
**进阶生产**：一稿多平台改写 · A/B 测试脚本 · 系列化栏目框架 · 配音与节奏标注 · 转化与运营话术 · 选题库与热点借势 · 强监管行业红线（医疗/金融/教育）· 数据复盘与迭代

## 附带 Skill
`short-video-script-templates`：四种类型分镜骨架（§1–§4）+ 八项进阶模板（§5 多平台改写 / §6 A/B 测试 / §7 系列栏目 / §8 配音节奏 / §9 转化话术 / §10 选题借势 / §11 行业红线 / §12 爆款拆解），详见 `skills/short-video-script-templates/references/script-formats.md`。

## 使用示例
- 帮我写一个30秒口播短视频脚本，主题是「普通人如何开始副业」
- 把「职场沟通」这个选题拆解成3个不同角度的短视频脚本
- 把这条口播脚本改写成抖音版和小红书版两个版本，并标注差异
- 为我的护肤品牌做一套 7 集科普栏目，每集结尾留悬念

## 使用方式
在对话中给出：平台 + 时长 + 目标人群 + 核心卖点 + 风格，即可获得分镜脚本表 + 拍摄备注 + 发布建议 + 多版本/合规/复盘建议。

## 头像

头像不随本内容仓分发（`avatars/` 已移除），由产品端生成（grok 引擎）。

## 安装 / Installation

本包由 **morechat.co-Assistant** 内容仓分发，**通过 morechat.co-Assistant 目录导入**：

1. 在 morechat.co-Assistant 仓中取出 `catalog/packages/<kind>/<id>/`；
2. 该目录即包根目录，内含 `plugin.json`、`agents/`、`skills/`，整体作为包目录导入；
3. 导入后由平台注册 Agent / Squad 与技能，无需额外安装脚本或注册命令；
4. 头像不在仓内分发（`avatars/` 已移除），由产品端生成。
