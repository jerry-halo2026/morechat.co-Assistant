# 冲突处理与复核

冲突不写记录，下次还会重吵。处理只走五步：事实、诉求、方案、裁决、记录。

## 方法
1. 只写可核查的事实，不写“对方不配合”这类评价。
2. 每方诉求各写一行，贴原话，不合并、不改写。
3. 每个方案写清负责人、复核人、截止时间、影响。
4. 按章程由拍板人裁决；拍板人不能是争议事项的执行人本人。
5. 把事实、诉求、方案、裁决人、理由写进记录表，发三方确认。
6. 下次同步时对照进度表复核是否落实，未落实重新升级。

## 示例
事实：上线检查清单无负责人，已拖 3 天。方案：运营负责清单、技术配合接口、产品复核；裁决人为项目负责人，理由是清单可执行且有人复核。数字与时间均为示例写法，以实际记录为准。

## 常见错误
只写评价不写事实、诉求被改写合并、方案没有负责人和时间、裁决人就是执行人、吵完不写记录。

## 检查清单
事实可核查；每方诉求贴原话；方案有负责人、复核人、截止时间；裁决人按章程定、理由写清；记录已发三方确认并复核落实。
