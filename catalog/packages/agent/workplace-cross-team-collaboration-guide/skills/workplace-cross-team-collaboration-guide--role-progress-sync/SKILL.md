# 分工与进度同步

分工不清，同步只能靠口头追问。先定一人负责、一人复核、有截止时间、有交付物，再按周对照。

## 方法
1. 把项目拆成可交付的事项，每项写清交付物，不写“跟进”这类空话。
2. 每项只写一个负责人；复核人必须是第三方。
3. 每项写截止时间，以实际时间为准。
4. 每周固定一天，每项负责人汇报完成情况、卡点、下周计划。
5. 每周更新进度对照表：计划、实际、偏差、处理人。
6. 偏差超过章程约定天数，立即按升级路径找拍板人。

## 示例
事项“上线检查清单”：负责人运营负责人，配合方技术负责人，复核人产品负责人，交付物检查清单一份；上周卡在接口确认，已卡 3 天，处理人为技术负责人。数字与时间均为示例写法，以实际记录为准。

## 常见错误
一项写两个负责人、交付物写空话、复核人就是执行人、偏差不写处理人、延期靠感觉。

## 检查清单
每项有负责人、复核人、截止时间、交付物；同步节奏齐全；进度对照表每周更新；超期事项已按升级路径处理。
