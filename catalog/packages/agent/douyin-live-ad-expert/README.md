# 抖音投流专家（Douyin Live Ad Expert）

**一句话**：抖音全能投流专家 —— 用数据说清你卡在哪、为何卡、离大盘差多少，再给一套企业和个人都能照做的投流方案。

## 能力介绍

无论是企业投流团队，还是自己开播的个人主播，它用数据回答三件事：

| 你问的 | 大白话 | 它实际做的 |
|---|---|---|
| **流量诊断** | 「我到底卡在哪？」 | 从曝光 → 进入率 → CTR → GPM → 成交结构逐层倒推，定位问题落在人群 / 素材 / 画面 / 机制 / 时段哪一层，而不是笼统说一句「效果不好」 |
| **归因** | 「为什么会卡在这？」 | 用 23 条判断规则卡做归因：同样是不进人，区分是素材衰退还是人群失效；同样是没转化，区分是人货错配还是画面劝退。每个结论都带依据，可追问、可摊开算 |
| **大盘数据对比** | 「我算什么水平？」 | 拿品类大盘、细分赛道水位、三极赛马对标账号（成交高 / 销量高 / 流量高各取 TOP）跟你对表，告诉你处在第几梯队、差的这一截差在哪个数上 |

对完表就开处方：3 套可并行测试的人群组合、通投计划、开播时段、组品搭配，再压缩成一份**三天操作指南**（每天做什么、盯什么指标、到什么阈值做什么调整、什么时候该叫停）。

**没有数据也能用** —— 只说「我做美妆的」就出一份《赛道速判报告》：梯队定位、人群画像、卡点排序、GMV 可改善区间、三天起手式，全程零追问。

## 类型

Agent 型（单个 AI 专家）· 行业分类：05-MarketingGrowth 营销增长

## 人格与工作方式

急诊医生型，不是投流老师。核心行为准则：

1. **先问后答** — 启动前取得品类 / 价格机制 / 日预算 / 流量现状，但一次只问 2-3 项
2. **敢下判断** — 结论单一指向，不许「可能是 A 也可能是 B」
3. **数据不硬撑** — 估算一律标 `[估算]` 并写依据
4. **口径红线** — 只对「进来的人准不准」负责（曝光 / 点击 / CTR / 进入率 / 流量成本），不对 ROI、转化率、停留时长做承诺
5. **GMV 只用锚点公式** — `(腰部偏下月均 GMV + 月均众数 GMV) ÷ 2`
6. **结论必有依据** — 禁「一般来说」「通常情况」

## 两条诊断路径

| 路径 | 触发条件 | 产出 |
|---|---|---|
| **闪电诊断**（`live-ad-flash`） | 用户只给了赛道，或明确不想提供数据、回了「先试」 | 1-2 分钟内出《赛道速判报告》，全程零追问 |
| **标准诊断**（collect → analyze → strategy） | 用户提供了品类 / 价格机制 / 日预算 / 流量现状中的至少两项 | 《关键问题分析与优化方案》+《三天投流操作指南》 |

## 技能构成

| 技能 | 作用 |
|---|---|
| `live-ad-theory` | 判断规则库（23 条规则卡）：现象 → 判因 → 动作。任何判定类问题必须先加载 |
| `live-ad-flash` | 零数据速判：10 赛道基线库 + 五支点推导链 + 速判报告模板 |
| `live-ad-collect` | 7 类输入采集 + 三极赛马选对标账号（成交高 / 销量高 / 流量高） |
| `live-ad-analyze` | 七项分析与归因 + GMV 锚点公式测算 + 爬坡周期 |
| `live-ad-strategy` | 3 套人群画像组合、通投计划、开播时段、组品搭配、三天排期 |

## 理论底座要点

- **对用户理论**：投流绝大部分浪费发生在「把产品推给了根本不需要它的人」
- **算法逻辑**：标签收敛、流量池赛马、**素材衰退 vs 人群失效判别**、推广方式选择、调价节奏
- **画面逻辑**：画面影响进入率与前 3 秒停留，这两项数据后台可读 —— 画面问题可做数据归因
- **决策因子**：价格敏感 / 功效导向 / 颜值认同 / 信任依赖，需与画面、人群三线对齐

## 使用示例

- 我的直播间流速上不去，帮我做个完整诊断
- 帮我测算这个品能跑到多少 GMV，多久能爬起来
- 我只做美妆，没有其他数据，先给我看看大概

## 头像

头像不随本内容仓分发（`avatars/` 已移除），由产品端生成（grok 引擎）。

## 安装 / Installation

本包由 **morechat.co-Assistant** 内容仓分发，**通过 morechat.co-Assistant 目录导入**：

1. 在 morechat.co-Assistant 仓中取出 `catalog/packages/<kind>/<id>/`；
2. 该目录即包根目录，内含 `plugin.json`、`agents/`、`skills/`，整体作为包目录导入；
3. 导入后由平台注册 Agent / Squad 与技能，无需额外安装脚本或注册命令；
4. 头像不在仓内分发（`avatars/` 已移除），由产品端生成。
