# 数据采集（标准诊断第 2 步）

本步的目标不是"把表填满"，而是**建立一份能让下游归因站得住的数据底座**。采不到就明确记录为缺口，不许拿估算充数。

## 7 类输入

### ① 用户信息采集（最高优先级，缺了无法开工）

| 项 | 为什么必须要有 |
|---|---|
| 品类 / 细分品类 | 决定赛道基线与人群结构 |
| 主力价格带与机制 | 决定决策因子与可比对象 |
| 日预算 | 决定可测试的组合数与容错空间 |
| 开播时长与时段 | 决定流量结构采样窗口 |
| 当前状态 | 决定诊断方向：新开播没量 / 有量不转化 / 有转化起不来量 / 老号衰退 |
| 团队配置 | 决定方案能不能被执行（有没有投手、有没有运营） |

**用户自身数据一律不估算**，必须索取。索取时一次只问 2-3 项。

### ② 大盘数据收集

赛道 GMV 量级区间、流量成本水位（ CPC / CPM ）、赛道当前处于上升期还是存量期。

获取路径（按优先级）：巨量算数 → 第三方数据（蝉妈妈 / 飞瓜 / 新抖）→ 用户后台 → 估算降级。

### ③ 细分赛道分析

细分品类的价格带分布、竞品密度、头部集中度。**细分到能找到可直接对标的账号为止** —— "美妆"太粗，"美妆-面部精华-100~300 元"才可用。

### ④ 直播间机制

价格机制（券 / 满减 / 限时 / 阶梯）、组品结构（引流款 / 主推款 / 利润款）、福利发放节奏、话术成交节奏。

机制不在投放职责范围内，但**机制决定了人群该怎么选**：低价引流品和正价主推品吸引的是两拨人，人群包必须与之匹配。

### ⑤ 对手账号数据 —— 三极赛马选样（本步最值钱的动作）

**不要取行业均值**。均值会把不同打法抹平。按三个维度各取 TOP：

| 维度 | 取什么 | 能拆出什么 |
|---|---|---|
| 成交高 | 单位时长成交额 TOP | 转化效率路径 |
| 销量高 | 单量 TOP | 走量 / 低价驱动路径 |
| 流量高 | 场观 / 在线峰值 TOP | 流量获取路径 |

三条路径**互不相同**，各自归因到可迁移的执行要素（人群、素材、机制、时段、组品）。只取均值会得出「大家都差不多」这种没有行动价值的结论。

选样后对每个账号记录：价格带、主推品、开播时段、素材类型、画面风格、在线峰值、成交结构。

### ⑥ 人群数据

自身成交人群画像（性别 / 年龄 / 地域 / 消费层级 / 兴趣行为）、各计划人群包配置与效果、系统探索出来的人群与设定人群的偏差。

获取路径：抖音电商罗盘（自身成交人群）→ 巨量千川后台（计划级人群包效果）→ 第三方（竞品人群结构）。

### ⑦ 开播时间

自身开播时段分布、竞品开播时段、赛道流量高峰时段、时段流量成本差异。

## 数据获取路径（混合模式）

| 类型 | 路径 |
|---|---|
| 能推理判断的 | 专家自行判定，标注 `行业规律` |
| 公开可查的 | 巨量算数 / 抖音电商罗盘 / 巨量千川后台 |
| 需第三方数据的 | 蝉妈妈 / 飞瓜 / 新抖，用户给账号可直接看 |
| 用户自身的 | 必须索取，不估算 |
| 实在拿不到的 | 走估算降级，标注 `[估算]` + 依据（见 `live-ad-theory` 第五节） |

## 输出

用 `templates/collect-checklist.md` 输出数据清单：每类输入列出「已拿到 / 缺口 / 来源 / 可信度」。

**缺口必须显式列出并说明影响**：缺哪一项会让下游哪一步的结论降级。收口时把缺口转成一次性的索取请求，包装成"换取更准的结果"。
