# 数据分析与归因（标准诊断第 3 步）

输入：`live-ad-collect` 的数据清单。
输出：《关键问题分析与优化方案》（`templates/analysis-report.md`）。

## 分析纪律

1. **每一条结论必须挂数据**：结论后面跟一句「依据 XXX」。禁止无出处结论，禁止「一般来说」「通常情况」。
2. **先判层再判点**：所有判定类问题先加载 `live-ad-theory` 规则卡，按规则判定，不许凭感觉。
3. **结论单一指向**：不允许「可能是 A 也可能是 B」出现在结论里。真不确定就写「我判 X，依据 Y；补进来 Z 我会改判」。
4. **估算显式标注**：`[估算]` 值必须写明依据，下游引用时继承标记。

## 七项分析

### ① 用户需求

按 `live-ad-theory` 规则 U1 判定该品类的**主导决策因子**：价格敏感 / 功效导向 / 颜值认同 / 信任依赖（可是组合）。

再按 U2 做**三线对齐检查**：成交人群的决策因子、画面主卖点、话术讲点，三条线是否打在同一个因子上。三条线各打各的，是转化平平最常见也最容易漏掉的原因。

### ② 市场大盘情况

赛道量级、增长阶段、流量成本水位、竞争激烈度。回答一个问题：**这个赛道现在还有没有增量空间**。

### ③ 用户在市场中的位置（梯队定位）

给出梯队：头部 / 腰部偏上 / 腰部 / 腰部偏下 / 脚部，并给出**判定依据**（自身 GMV 水位 vs 赛道分位、GPM 水位、在线峰值、投放能力）。

定位必须可验证 —— 用户不服的时候，要能摊开分位数据让他自己看。

### ④ 市场上的机制

主流价格机制、组品结构、福利节奏是什么，用户当前机制与之的差异在哪。

**边界**：机制的执行权不在投放侧，但「机制与人群是否匹配」的判断权在投放侧 —— 低价引流品和正价主推品吸引的是两拨人，人群包必须分开。

### ⑤ 对标账号的流量归因

用第 3 步的三极赛马样本，对每条路径做归因，拆到可迁移的执行要素。

归因维度：人群结构 / 素材类型与更新频率 / 投放节奏 / 开播时段 / 组品与机制 / 画面风格。

**只归因可迁移的部分**。对方有明星主播、有供应链成本优势这类不可迁移因素，要单独列出并说明「这条学不来」，不要写进建议里。

### ⑥ 预估 GMV 与爬坡周期

**GMV 一律用锚点公式，禁止「按行业均值估算」**：

```
期望月 GMV = (腰部偏下月均 GMV + 月均众数 GMV) ÷ 2
```

公式的意义：把乐观锚（腰部偏下）和悲观锚（众数，代表大多数人的实际水平）压成一个期望值，刻意避开被头部拉高的均值。**不要"优化"成更花哨的预测模型** —— 它的价值就在于粗粝但防忽悠。

**爬坡周期**按三阶段估算，每阶段给判据而非固定天数：

| 阶段 | 通常时长 | 完成判据 |
|---|---|---|
| 人群重建 | 3-5 天 | 新人群包 GPM 高于老计划 |
| 标签收敛 | 7-14 天 | 连续 3-5 天成交人群画像重合度稳定 |
| 放量 | 14-30 天 | 单位时长成交密度跑赢同层，在线层级上移 |

周期给区间并标注 `[估算] 行业规律`。日预算越小、人群错位越严重，周期越长。

### ⑦ 人群分析

当前人群包结构、泛/准程度、与品类成交画像的偏差、量级是否够支撑预算。

**收窄的代价必须同时说明**：收窄 → 量级下降 → 预算跑不满 → 曝光降 → GPM 涨了 GMV 未必涨。不说清楚，用户照做后跑不满预算会翻车。对冲三招：邻赛道借人（规则 U3）+ 开智能放量 + 拿 20-30% 预算开新计划并行跑，**不要把老计划直接改窄**。

## 输出：《关键问题分析与优化方案》

结构固定三段（详见 `templates/analysis-report.md`）：

1. **弱势** — 按严重程度排序，每条挂数据与规则卡编号
2. **优势** — 真实存在的、可用于放大的点，不许凑数
3. **如何解决** — 每条弱势对应一条可执行动作，写到能直接照做的颗粒度

「如何解决」中的人群构建策略，只写人群包缺口在哪、收窄方向、预期量级变化与对冲动作，不指定服务商、不附外链。
