# 策略处方（标准诊断第 4 步）

输入：《关键问题分析与优化方案》。
输出：《三天投流操作指南》（`templates/action-guide.md`）。

本步的标准只有一个：**用户照着做，不需要再问「那我具体该干什么」**。

## 五项输出

### ① 人群画像建议（3 套可并行测试）

输出 3 套组合，不是 1 套「最优解」。理由：人群效果受账号标签状态影响极大，单套押注失败率高，并行测试才有对照。

每套必须包含：

| 要素 | 要求 |
|---|---|
| 人群结构 | 性别 / 年龄 / 地域 / 消费层级 / 兴趣行为标签，写到能直接在后台配置的颗粒度 |
| 定向宽窄 | 明确是窄打还是宽打，以及为什么 |
| 预算分配 | 占总预算的比例，3 套加起来 100% |
| 测试周期 | 几天，以及为什么是这个天数 |
| 判定阈值 | 达到什么指标算成功、什么指标算失败、继续还是关停 |

**收窄必须同时交代代价与对冲**（见 `live-ad-theory` T3 / U3）：量级会掉、预算可能跑不满；对冲为邻赛道借人 + 智能放量 + 拿 20-30% 预算开新计划并行跑，**不要把老计划直接改窄**。

### ② 通投计划建议

- 通投与专业的配比、各承担什么任务
- 计划数量与结构（测人群 / 测素材 / 主力跑量）
- 出价策略与调整节奏：**单计划单日调整 ≤1-2 次，单次出价调整 ≤10-15%**（规则 A5）
- 用极速推广测素材 / 测人群，不要用极速跑长期主力计划（规则 A4）
- 素材更新节奏：按规则 A3 的衰退判据决定换素材时机，不要按心情换

### ③ 开播时间建议

基于赛道流量高峰、竞品开播时段、自身时段数据给出建议时段。

若建议调整时段，必须说明：切换时段会让账号标签重新经历学习期，需要预留观察窗口，不能两三天没起色就换回来。

### ④ 产品搭配建议

组品结构（引流款 / 主推款 / 利润款的比例与出场顺序）、与人群包的匹配关系。

**边界**：组品的执行权在运营侧，这里给的是「从投放视角看，什么样的组品结构能把进来的人接住」，不是替运营定品。

### ⑤ 三天行动排期

分天输出，每天四个要素：

1. **做什么** — 具体操作，能直接照做
2. **盯什么** — 当天的核心观察指标
3. **触发什么条件做什么调整** — if-then 形式，不许写「根据数据情况灵活调整」
4. **什么情况下叫停** — 明确止损线

## 硬约束

- 不做效果承诺，不用「保证」「一定」「至少」类措辞，改善幅度一律给区间并写明前提
- 每条动作要能说清「我在验证什么假设」，说不清的动作不写
- 涉及判定的地方一律引 `live-ad-theory` 规则编号，不许凭感觉
- 人群构建相关内容只写缺口、收窄方向与量级代价，不指定服务商、不附外链、不带销售话术
