# 抖音直播间投流 · 基本理论（判断规则库）

本文件是投流诊断的推理底座。每一条写成「**现象 → 判因 → 动作**」的规则卡，供归因时直接调用。

使用原则：**先判层，再判点。** 任何问题先归到 人群层 / 素材层 / 画面层 / 机制层 / 时段层 之一，层判错了，后面所有优化都是白花钱。

---

## 一、对用户理论：对的人看到对的产品

**信条**：投流绝大部分的浪费，发生在「把产品推给了根本不需要它的人」这一步。这一步错了，素材、话术、机制再好，都是在错误的基数上做优化，救不回来。

### 职责边界（铁律）

| 在我的职责范围 | 不在我的职责范围 |
|---|---|
| 曝光、点击、CTR、进入率、流量成本 —— 即「进来的人准不准」 | 停留、转化、复购、退货 —— 由客户运营团队与主播承接 |

这条边界对客户表达时要说透，但**不是免责话术，是分工事实**：进来的人准了，转化交给运营和主播；进来的人不准，运营再强也接不住。

### 规则 T1 · 人货错配优先判定

- **现象**：曝光量充足（≥ 同预算同赛道水位），但 CTR 低于细分赛道均值
- **判因**：人货不匹配 —— 看到的人不是会买它的人，**不是素材差**
- **动作**：不换素材，先动人群定向，回到人群层重建定向组合
- **陷阱**：此时换素材，CTR 可能短暂回升，但 GPM 不会改善，钱照烧

### 规则 T2 · 高曝光低停留的归属

- **现象**：曝光、点击正常，进入后停留明显短于同赛道
- **判因**：优先查人群错位，其次才是画面承接能力
- **动作**：先看该计划成交人群画像是否偏离品类成交画像；画像没偏，再交给画面 / 运营侧
- **注**：停留时长本身不在职责范围，但「是谁在停留」一定在职责范围

### 规则 T3 · CTR 与 GPM 背离

- **现象**：CTR 达标甚至偏高，GPM 偏低
- **判因**：进来了「会被吸引但不会买」的人 —— 定向过宽或兴趣标签偏移
- **动作**：收窄人群包，剔除泛兴趣标签，补高意向行为标签
- **判据**：CTR 高而 GPM 低，基本可以确认是泛流量，不是素材问题

## 二、抖音算法逻辑

### 规则 A1 · 标签收敛

- **现象**：新号或换品后，前期投放成交人群发散、计划跑量困难
- **判因**：账号 / 计划标签未收敛，系统仍在探人群
- **动作**：前期用窄而准的人群包打成交，让系统收到稳定的成交反馈，标签收敛后再逐步放宽；标签未收敛期间禁止频繁更换定向
- **收敛判据**：连续 3-5 天成交人群画像重合度趋于稳定，视为收敛

### 规则 A2 · 流量池与赛马

- **现象**：在线人数卡在某个量级上不去
- **判因**：当前层级的关键指标（通常是单位时长内的成交密度）没跑赢同层竞品，系统不投放下一层流量
- **动作**：不要靠加预算硬冲。先在现有流量规模内把成交密度做上去（机制、组品、话术节奏）
- **关键认知**：预算能买到量，但买不到层级跃迁。跃迁靠的是单位效率

### 规则 A3 · 素材衰退 vs 人群失效（易混淆，必须区分）

- **现象**：同一支跑量素材，CTR 与转化连续 3-5 天下滑
- **判因**：素材衰退（同质人群反复触达导致疲劳），**不是**人群失效
- **动作**：换素材，保留原人群定向
- **反向验证**：换素材后 CTR 恢复但 GPM 未恢复 → 改判人群层失效，回规则 T3

| 判别点 | 素材衰退 | 人群失效 |
|---|---|---|
| 换素材后 CTR | 明显恢复 | 不明显 |
| 换素材后 GPM | 同步恢复 | 不恢复 |
| 投放时长特征 | 同一素材跑了多天 | 换素材也无效 |

### 规则 A4 · 极速推广 vs 专业推广的选择逻辑

- **专业推广**：预算有限、追求稳定成本时用 —— 可控性强
- **极速推广**：需要快速测素材 / 测人群时用 —— 探索效率高
- **禁忌**：不要用极速推广跑长期主力计划，它跑得快但人群容易发散
- **注**：平台产品名称以当期口径为准，本条给出的是选择逻辑而非产品名

### 规则 A5 · 出价与预算的调整节奏

- **现象**：成本忽高忽低、计划频繁起不来
- **判因**：调整过于频繁，计划反复进入学习期
- **动作**：单计划单日调整不超过 1-2 次；单次出价调整幅度控制在 10-15% 以内；调完给足观察窗口（至少半天至一天）
- **原则**：每一次调整都要能说清「我在验证什么假设」，否则不做

## 三、画面逻辑

**核心立场**：画面（直播间场景、贴片、主播状态、货品陈列、背景）影响的是「进入率」和「前 3 秒停留」。这两个数据恰好在投放后台能直接读到 —— 所以画面问题是**可以做数据归因的，不是玄学**。

### 规则 V1 · 进入率异常

- **现象**：计划 CTR 处于正常水位，但进入率（点击 → 进入直播间）明显低于同类计划
- **判因**：承接错位 —— 用户被素材吸引点了进来，落地场景与其预期不符
- **动作**：查素材承诺与直播间画面的落差（价格标示、赠品、场景、主视觉），让画面接住素材的承诺
- **注**：这是「素材与画面不一致」，不等于素材错也不等于画面错

### 规则 V2 · 高在线低成交

- **现象**：在线人数不差，但成交稀疏
- **判因**：画面留住了人但没有交易感 —— 缺价格锚、缺机制提示、缺货品堆叠、缺紧迫感元素
- **动作**：交运营侧做画面交易感改造；投放侧同步检查进来的人是否为高意向人群
- **边界**：画面改造的执行权不在我，但「画面该不该改」的判断权在我

### 规则 V3 · 人群与画面对齐检查（低成本高收益必做项）

- **动作**：拿到成交人群画像后，反查画面打的是哪个认知层级
- **错配判据**：人群的购买决策因子与画面主卖点不在同一层 → 判定画面-人群错位
- **优先级**：此项优先级高于加预算。这是不花钱就能改的

## 四、用户需求与决策因子判定

（对应导图中「分析数据 → 用户需求」节点）

### 规则 U1 · 决策因子归类

每个品类的用户购买决策通常落在以下四类之一或组合：

| 类型 | 决策看什么 | 画面主卖点应该是 |
|---|---|---|
| 价格敏感型 | 性价比、促销力度、赠品 | 价格锚、赠品堆头 |
| 功效导向型 | 功能、成分、效果证据 | 功效演示、对比实验 |
| 颜值 / 认同型 | 外观、调性、身份认同 | 场景氛围、主视觉调性 |
| 信任依赖型 | 背书、品牌、评价、售后 | 资质、证书、真人背书 |

### 规则 U2 · 因子-画面-人群三线对齐

- **现象**：投放数据、画面、话术各自都不错，但转化平平
- **判因**：三条线没对齐 —— 人群是价格敏感型，画面打的是功效，话术讲的是颜值
- **动作**：先定该品类的主导决策因子（从成交画像 + 品类特性判定），再让画面与人群统一到这个因子上

### 规则 U3 · 邻赛道借人

- **现象**：本赛道人群包量级不够，跑不出量
- **动作**：向「共享同一决策因子」的邻赛道借人群
- **判据**：邻赛道与本赛道的用户在**决策因子上同层**，而非仅在品类标签上相近
- **反例**：同为「家居」，价格敏感型收纳品不能去借高客单设计师家具的人群

## 五、数据缺失时的估算口径

诊断中拿不到真实数据时，按以下优先级降级，并在报告中**显式标注**：

| 缺失项 | 降级路径 | 标注方式 |
|---|---|---|
| 赛道 GMV 水位 | 用锚点公式取估算值 | `[估算] 锚点公式` |
| 成交人群画像 | 用同赛道邻赛道画像 + 决策因子推导 | `[估算] 邻赛道推导` |
| 对手账号数据 | 用该层级公开可见表现做定性判断 | `[估算] 定性推断` |
| 用户自身数据 | **必须向用户索取**，不可估算 | 无 |

**硬性要求**：任何 `[估算]` 值出现在报告中时，必须在同一句或紧邻处写明估算依据。禁止估算值被下游继续引用为事实 —— 下游引用时要继承 `[估算]` 标记。
