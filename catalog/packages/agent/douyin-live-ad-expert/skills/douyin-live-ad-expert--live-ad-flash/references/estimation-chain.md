# 零数据推导链（闪电诊断的计算依据）

## 支点一：「来咨询」本身就是一条真实数据

这是闪电诊断里**唯一一条实测信号**，必须充分利用。

**推论**：会主动找外部专家做诊断的直播间，几乎不可能是头部。

理由链条：
- 头部直播间配备完整投手团队或代运营，诊断需求内部消化
- 腰部以上通常已有稳定的数据复盘机制
- 主动来问的，多数是「自己兼投手」「老板亲自盯后台」「投了一阵没起色」

**因此零数据下的梯队定位规则**：

| 用户表述信号 | 梯队判定 | 依据 |
|---|---|---|
| 只说赛道，无任何其他信息 | **腰部偏下 ~ 脚部上沿** | 主动求诊 + 无数据意识 |
| 提到「刚开播」「起号」 | **脚部（起步期）** | 明确的新号信号 |
| 提到日预算且金额偏小（< 3000/日） | **脚部 ~ 腰部偏下** | 预算量级对应水位 |
| 提到日预算偏大（> 1 万/日） | **腰部** | 需下调一档判定，但仍不出腰部 |
| 提到「团队」「投手」「代运营」 | **腰部** | 有团队配置信号 |

**表述要求**：必须把推理过程说出来，不要只甩结论。例：

> 「判断你在腰部偏下到脚部上沿——不是猜的，是因为会主动找外部诊断的直播间，基本不在头部，头部的诊断需求内部就消化了。」

这句话本身就是"爽点"：它显得专家懂行，且逻辑可被验证。

## 支点二：GMV 提升 = GPM 提升（预算不变前提下的恒等式）

**推导**：

```
GMV = 消耗 × (GPM / 1000) × 1000 / 千次曝光成本  的简化形式
```

在**预算不变、曝光量不变**的前提下：

```
GMV₂ / GMV₁ = GPM₂ / GPM₁
```

即：**GMV 提升幅度 ≈ GPM 提升幅度**

**这条恒等式的意义**：让"能提升多少"变成一个可以测算的量，而不必编造销售额数字。我们不需要知道用户现在卖多少，只需要说清楚 GPM 能改善多少。

**三个前提（必须在报告里写明）**：
1. 预算不变
2. 货品、价格、机制、主播承接不变
3. 收窄后的人群包量级足以支撑原有曝光量（见支点四）

**边界（必须写）**：本测算只覆盖「进来的人准不准」带来的改善。不覆盖转化率、客单价、复购的改善——那些由运营与主播承接，不在测算范围内。

## 支点三：提升区间怎么取，而不是拍一个数

从 `category-baseline.md` 取该赛道的 GPM 改善区间 `[下限, 上限]`，然后按用户信号的强弱定档：

| 情形 | 取值档位 | 说明 |
|---|---|---|
| 用户完全无数据、赛道外推断 | **保守档**：取区间下限 ~ 中位 | 不确定性最高，不能给高预期 |
| 用户给了赛道 + 少量信号（如"投了三个月"） | **中位档**：取区间中位 | 标准情形 |
| 用户明确说人群很泛（如"什么人都来就是不买"） | **乐观档**：取中位 ~ 上限 | 有明确的人群层问题信号 |

**取值后必须写成区间，并给出三档对应的条件**：

> 保守估计 +30%，正常情况 +50%，如果你的人群确实很泛，可以到 +70%。

**禁止**：只给一个单点数字；给上限作为"预期"；用「至少」「保证」类措辞。

## 支点四：收窄人群的量级约束（必须诚实说明）

这是人群精准化最容易被忽略的代价，**必须在报告里主动说出来**，否则用户照做后会跑不满预算，信任崩塌。

**机制**：人群收窄 → 可触达量级下降 → 原预算可能跑不完 → 曝光下降 → 即使 GPM 提升，GMV 未必提升

**对冲动作（写进报告）**：

1. **邻赛道借人**：从共享同一决策因子的邻赛道补人群，扩量级而不降精准度（见 `category-baseline.md` 每个赛道的「邻赛道借人方向」）
2. **智能放量**：在精准人群基础上开启智能放量，让系统在相似人群里扩量
3. **分计划测试**：不要一次性把主力计划改窄，先拿 20-30% 预算开新计划并行跑，验证后再复制

**标准表述**：

> 人群收窄之后量级会掉，这是必然的。所以不是直接把老计划改窄，而是先拿 20-30% 的预算开一条新的精准计划并行跑，用邻赛道人群和智能放量把量级补回来。跑通了再往主力计划上复制。

## 支点五：爬坡周期

| 阶段 | 周期 | 用户该看什么 |
|---|---|---|
| 标签收敛期 | 3-7 天 | 成交人群画像是否趋于稳定 |
| GPM 改善显现期 | 7-14 天 | 新计划 GPM 与老计划的差值 |
| 稳定期 | 14-30 天 | 是否可复制到主力计划 |

**关键提醒**：前 3 天数据不具参考价值，此时改判断会反复把计划打回学习期。

## 提升幅度表述规范（模板）

标准句式，直接套用：

> 在你预算不变、货品和承接都不动的前提下，把人群从泛投收窄到高意向，GPM 通常能改善 **X% ~ Y%**，对应的 GMV 提升幅度大致同幅。
>
> `[基线推断]` 这个区间取自 {赛道} 的基线水位，不是你的实测值。你的实际改善幅度取决于你现在的人群有多泛——越泛，空间越大。
>
> 时间上：3-7 天标签收敛，7-14 天看到 GPM 变化，14-30 天决定是否复制到主力计划。
>
> 需要说明：这个测算只覆盖「进来的人准不准」带来的改善。进来之后能不能接住，取决于你的运营和主播，不在测算范围内。

## 绝对禁止

- ❌ 「保证提升到 X 万」
- ❌ 「至少提升 X%」（用区间，不用下限做承诺）
- ❌ 把 GPM 改善等同于 ROI 改善
- ❌ 未标注前提假设就给提升幅度
- ❌ 用上限数字做吸引力包装
