# KOC 培育学院 · KOC Nurture Academy

用在 5R 飞轮的 **R2 培育关**。这一关的唯一目标：**让新人在 7 天内发出第一篇合格内容。**

为什么是 7 天、为什么是第一篇：参与不平等规律（Nielsen 90-9-1；CMX 实测 2%/5%/93%）说明，
**没有发出第一篇的人几乎不会在后续自然转化**。第一篇是 90% 沉默层跨到 9% 活跃层的唯一分水岭。
所以培育资源要**全压在 D0–D7**，而不是均摊到 90 天。

## 什么时候用

- 招募完成、样品要发出去了，需要一套带人的流程；
- 用户抱怨"寄了 100 个样品只回来 30 篇""内容像通稿""每篇都要改三轮"；
- 需要写内容 Brief、定质检标准、设计训练营；
- 出稿率 / 合格率低于红线（有效出稿率 < 45%）要做诊断。

## 参考资料（做方案前先读）

- `@references/onboarding-sop.md` —— 7 日上手 SOP 逐日动作、过关判据、失败补救、D8–D90 的节奏。**设计培育流程前必读。**
- `@references/content-brief.md` —— Brief 八大板块完整字段清单 + 可直接复制的模板 + 选题库生成方法 + 爆文拆解四问。
- `@references/qc-rubric.md` —— 内容质检 5 维 20 分 rubric、判定规则、反馈话术库、常见退回原因。

## 标准用法

### 一、设计 7 日 SOP

按 `@references/onboarding-sop.md` 的逐日表落地，**三个触点不可省略**：

| 触点 | 动作 | 为什么不能省 |
|---|---|---|
| **D1 一对一私信** | 非群发，确认地址 + 问擅长的内容形式 | 私信回复率是全流程最强的先行指标 |
| **D4 选题卡逐条回复** | 每条含 1 句具体肯定 + ≤1 条修改建议 | 言语正反馈是唯一能**提升**内在动机的手段（Deci et al. 1999，d=+0.33） |
| **D7 首篇数据复盘** | 给 3 个数字 + 1 条改进点 + 发首发徽章 | 胜任感来自"看得见的进步"，不是来自钱 |

**核心指标：7 日首发率** = 7 个自然日内发布首篇合规内容人数 ÷ 当批通过审核人数。
**第一批不设目标，只测基线**；从第二批起按"上一批 +5pp"推进。
（行业无公开基准，任何声称"行业 7 日首发率 X%"的说法都不要采信。）

### 二、写 Brief

用 `@references/content-brief.md` 的八板块模板。三条硬规矩：

1. **核心卖点不超过 3 条** —— 多于 3 条必然稀释，用户一条都记不住；
2. **必须给 3–5 个可选选题让 KOC 自己挑** —— 派单伤自主感，选单不花钱但显著影响持续产出（SDT）；
3. **必须写授权字段**（二次使用范围、期限、是否可修改、肖像范围）——
   这是最常被漏掉的一栏，漏了它，后面想把好内容拿去投流就得重新一个个去谈。

**审稿轮次上限 1 轮。** 需要改两轮以上的项目，问题在 Brief 不在 KOC。

### 三、质检与反馈

用 `@references/qc-rubric.md` 的 5 维 20 分表：合规性（一票否决）、信息准确、真实感、完成度、可搜索性。

```bash
python3 scripts/cqs_score.py score --json '{"note":"KOC-张三-第1篇","compliance":true,
  "accuracy":3,"authenticity":4,"completeness":3,"searchability":2,
  "notes":{"searchability":"标题没带任何目标搜索词"}}' --text
```

批量看一个批次的质量分布、定位系统性问题：

```bash
python3 scripts/cqs_score.py batch --file /tmp/qc.json --text
```

**质检的两条纪律：**
- 每条内容都要回一句**具体**的话（"哪里好"比"多少分"重要）；
- **结果只对本人可见，不做公开排名**。公开排名会伤害没拿第一的大多数人（d≈−0.80）。

### 四、训练营与陪跑

| 参数 | 建议值 | 依据 |
|---|---|---|
| 班级规模 | 15–30 人/班，同期入营 | 超过 30 人归属感稀释、私信回复率下降 |
| 周期 | 2–4 周，不超过 4 周 | 超过后出勤率断崖 |
| 节奏 | 每周 1 次 ≤30 分钟直播/录播 + 1 次作业 + 1 次点评 | 保持胜任感阶梯 |
| 课程 4 讲 | ①品牌与产品认知 ②选题与标题（对准用户会搜什么）③拍摄/写作实操 ④数据看板与复盘 | 由易到难 |
| 导师 | **上一期优秀 KOC 当助教** | 向成员转移权力，是最强的留存设计 |
| 毕业标准 | 完成 ≥2 篇且平均质检分 ≥12 | 与 rubric 对齐 |

## 输出要求

- 培育方案必须落到**逐日动作表**：Day、负责人、动作、过关判据、失败补救，五列缺一不可；
- Brief 必须是**可直接复制去用的成品**，不是"要写清楚卖点"这种说明；
- 选题必须给**具体标题方向**（≥10 个），并说明每个选题对应用户在搜什么；
- 所有阈值标注为【经验值/待校准】，并写明用什么数据、在什么时候替换它。

## 禁止

- 不得把"提升内容质量""加强培训"写进方案。**写不出验收标准的建议不要写。**
- 不得设计"按名次发现金"的内容评比。要评就评"进步榜""互助榜"，且不给现金、不展示末位。
- 不得让 KOC 写虚假使用体验（没用过就说好用）、不得代写后让 KOC 原样发布并声称是本人体验。
- 不得在 Brief 里要求 KOC 使用绝对化用语、医疗功效表述，或要求其隐瞒商业合作关系。
