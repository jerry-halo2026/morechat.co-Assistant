# 平台规则与处罚（小红书 / 抖音 / 微信）

> **整理时点 2026-08-17。平台商业化规则的实际变更频率约为季度级，本文任何条款在使用前都必须回后台复核一次。**
> 标注含义：【官方规则】= 平台官方帮助中心/公告原文；【行业整理】= 多来源交叉但未直读官方页；
> 【经验值/待校准】= 单一来源或推断。

## 一、小红书

### 1.1 报备：什么必须走官方通路

| 情形 | 要求 | 标注 |
|---|---|---|
| 付费商单 | 必须走**蒲公英**报备 | 【官方规则】 |
| **寄样价值 ≥500 元 或 付费置换** | **必须报备** | 【行业整理，需回后台核对当前门槛】 |
| <1,000 粉的素人内容要投流 | 走**合作码**（笔记级授权） | 【官方规则】 |
| 批量申请素人笔记授权 | 走**合作广场**（需报白） | 【行业整理，转述官方产品手册】 |

**三条硬门槛（平台三处规则同时使用 1,000 粉这条线，比任何第三方分层都硬）：**

| 边界 | 数值 | 证据等级 |
|---|---|---|
| 蒲公英报备资格线 | ≥ 1,000 粉 | 【行业惯例】多来源一致，**未直读官方页，本项是本文最大的核验缺口** |
| 合作码资格线 | **< 1,000 粉**（涨到 1,000 粉功能自动关闭） | 【官方规则/服务商转述官方产品说明】 |
| 笔记挂链带货资格线 | ≥ 1,000 粉 | 【行业惯例】多来源一致 |

> **运营含义**：池子里逼近 1,000 粉的合作码账号要**提前标记**，准备切换到蒲公英，否则会在某一天突然全部失效。

### 1.2 未报备的处罚（达人侧与品牌侧是两套，别混着讲）

**达人侧（未报备商业种草）**

| 处罚 | 内容 | 标注 |
|---|---|---|
| 单次 | 扣 4 分信用分 + 笔记下架 + 聚光投放驳回 | ⚠️【行业整理，多来源一致，**未检索到官方原文**，需回后台核对】 |
| 累计 | 扣满 10 分永久关闭带货、蒲公英、投流全部商业化功能 | ⚠️ 同上 |

**品牌侧（品牌违规扣分机制）**

| 累计扣分 | 处置 |
|---|---|
| 6 分 | 全域限流（该品牌相关笔记自然流量受限），维持 **7 天** |
| 8 分 | 全域限流，维持 **28 天** |
| 10 分 | **全域限流 + 品牌封禁**，维持 28 天（品牌词搜索显示违规提示、关联企业号权限受限） |

⚠️ 品牌侧这张表来自 **2022-04** 版规则；2026-01-19 上线的《社区公约 2.0》合并了原《社区公约》与
《商业公约》，**扣分细则是否被修订未能核实**。对客户输出时必须写明"以平台最新规则中心为准"。

**这条是 KOC 铺量最大的隐性成本**：省下的 10% 服务费，换来的是账号商业化能力永久关闭的风险。
**默认设计：100% 走官方通路，零私下置换。**

### 1.3 内容侧规则

| 规则 | 要点 | 生效时点 |
|---|---|---|
| **《社区公约 2.0》** | 三大板块共 25 条倡导；反对虚假营销、虚假人设；重点治理高度模板化的推广笔记、虚构产品功效、**评论区自问自答制造互动假象** | 2026-01-19 |
| **蒲公英低差营销规则** | 禁止吹捧夸张、虚构使用体验、攀比其他品牌、套路营销；点名**横测与排行榜笔记**、海报拼图罗列多品牌但推广品牌排第一（拉踩嫌疑） | 2023-12-22 |
| 医疗及三品一械 | 与医疗专业博主合作的下单管控 | 【行业整理】2025-10-30 起 |

> **要特别注意两个"团队默认动作"已经是明确红线**：
> ① **评论区自问自答**；② **横测/排行榜/多品牌拼图笔记**。这两个是 KOC 铺量最常用的模板。

### 1.4 私信邀约的合规边界

**禁用表述**（会触发站外引导或虚假人设条款）：

- "加微信聊"、留手机号/二维码 → 违反社区商业公约的站外引导条款；
- "我们私下合作，不走平台" → 直接触发未报备违规；
- "保证爆文 / 保 X 万曝光" → 除官方保量产品外无任何保量机制；
- **"你就说是自己买的"** → 《社区公约 2.0》明文反对伪装素人。

## 二、抖音 / 巨量星图

### 2.1 内容规范（可直接抄进 Brief 的"绝不能出现"清单）

【官方规则】巨量星图内容管理规范明确禁止：

- "虚假做作、危言耸听博人眼球、故意夸大、虚假宣传或**营造虚假人设**"；
- "不得涉及对效果做出明示/暗示的**保证性承诺**"；
- "不得以**虚假新闻报道或虚假实验**形式做宣传"；
- 禁止"宣传必中、100% 抽中手机等虚假或夸大的内容"。

### 2.2 达人侧处罚阶梯（排期时必须留缓冲）

【官方规则】巨量星图达人管理规则：
警告提示 → **接单权限封禁 7 天 / 30 天 / 90 天** → 永久关闭合作入口 → **冻结提现（最长 90 天）** → 账户封禁；
另有限制参与活动、冻结在途任务、扣罚未提现费用。履约违规明确点名"**刷单、伪造虚假粉丝、伪造虚假评论、伪造虚假交易**"。

**两条落地动作：**
1. **排期留缓冲**：达人被封 7/30/90 天，在途内容会直接断，档期要有备份人选；
2. **合同里把"达人被平台封禁接单权限"写成达人违约**，否则损失全部由品牌承担。

### 2.3 时效与结算要点（容易踩的坑）

| 项 | 规则 | 标注 |
|---|---|---|
| 招募任务达人门槛（通用规则页） | 「达人主端粉丝数量应达到 **10000 以上**」 | 【官方规则，已逐字复核】 |
| 招募任务-一口价 / 带货达人团 | 一口价产品页写「达人粉丝门槛 **1K–500W**」；带货达人团的 KOC 团「粉丝量级 **1K–10W** 为主」 | 【官方规则，已逐字复核】 |
| **两页口径不一致，落地怎么办** | 招募任务的门槛**按子类型不同**：通用规则页 1 万粉，一口价与带货达人团对千粉 KOC 开放（后者是官方给 KOC 批量分销准备的产品）。**下单前在星图后台确认走的是哪个子类型**；另有指派/投稿任务与素材集市可用 | 【官方页口径冲突，需后台确认】 |
| 视频推送授权时长 | 默认由"不限-3650 天"改为 **30 天**，最长不超过 **365 天**；推送账户 ID 上限 500 个 | 【官方规则】 |
| **由此推出的坑** | 按老习惯以为"一次授权永久可投"的团队，**素材会在第 31 天集体失效** | 【经验值】 |
| 素材集市授权费 | 授权费 = 素材投流消耗 × X%；**单素材封顶 ￥20,000**；28 天计费周期 T+7，第 30 天扣款；**达人拒绝授权后无法再次申请** | 【官方规则】 |
| 一口价素材授权费 | **最低不低于 20 元，最高不高于任务金额的 50%**；授权费部分同样需付 5% 平台服务费；授权长期有效 | 【官方规则】 |
| 千川/本地推的素材时长 | **4s ≤ 时长 ≤ 300s**（巨量营销效果投放可到 60min） | 【官方规则】 |
| **由此推出的动作** | KOC 常见的 5–8 分钟长测评在千川/本地推直接不合规，素材入库时要按 ≤300s 做一次分流 | 【经验值】 |

## 三、微信生态（分销红线最严的一家）

### 3.1 《微信小程序平台运营规范》相关条款【官方规则】

| 条款 | 原文要点 | 处罚 |
|---|---|---|
| **5.9 多级分销** | "不得通过微信小程序实施多级分销行为，发布分销信息诱导用户进行添加、分享或直接参与" | "根据违规程度对该小程序**封禁分享、支付能力直至封号**处理" |
| 5.9.1 | 以电商平台为载体，"通过培养用户粉丝，**分级佣金**的形式进行多级分销" | 同上 |
| 5.9.2 | 以虚拟社区运营，"形成**上下级代理**，诱导组建团队的多级分销行为" | 同上 |
| 5.9.3 | 通过实物销售，"**发展下级代理，多层级抽取销售利润**" | 同上 |
| **5.1.2 滥用分享** | "以分享后**无需互动或无需深度互动**即可获得利益的方式诱导分享" | 阶梯封禁分享能力直至封号 |
| 5.1.3 | "通过**利益诱导分享至朋友圈**"，涵盖现金奖励、虚拟奖品等 | 同上 |
| 5.1.8 | 小程序"**分享量过大且分享转化率过低**"视为过度营销 | 同上 |
| **5.3 网赚** | "诱导转发内容后可获取收益，包括现金、积分、礼品等" | 封禁分享能力或被搜索能力直至封号 |

**微信官方对"多级分销"的定性**：本质是"利用关系链发展人员，形成多级上下线关系，
按照**下线人数或者销售业绩**计算盈利"，与传销行为类似。

### 3.2 一个必须讲清楚的误解

> **微信官方规则文本只写"不得多级分销"，从未成文写出"允许两级"这个数字。**
> "两级以内安全"是行业与法务界的通行解读（源自《禁止传销条例》的层级判定），**不是平台承诺**。

**所以：** 做微信侧分销时，默认按**仅一级、只按本人销售业绩计酬**设计。二级结构必须先过法务，
并且要意识到平台判定有裁量空间——法律上没触线，不等于平台不封。

### 3.3 常见做法的风险分级【经验值/待校准，须过法务】

| 做法 | 风险 | 理由 |
|---|---|---|
| 一级分销：KOC 卖货拿佣金 | 低 | 单层级、只按销售业绩 |
| 二级：KOC 推荐新 KOC，从其**销售额**抽成 | 中 | 未触三级要件，但"分级佣金"字面贴近 5.9.1，平台有裁量空间 |
| 二级：从新 KOC 的**人头**拿奖励 | **高** | 直接命中拉人头 + 5.9 定性 |
| 收 199/399 元"成为分销员/团长" | **高** | 命中入门费要件 |
| "招募 5 人升级团长，享团队业绩提成" | **高** | 命中 5.9.2 诱导组建团队 |
| 用"培训费/大礼包"变相收入门费 | **高** | 实质重于形式 |

### 3.4 合规替代设计

| 想做的事 | 合规做法 |
|---|---|
| 激励老 KOC 带新人 | 改成**商家直接发放的一次性招募奖励**：金额固定、由商家承担、与新人后续销售**无持续挂钩**、不设层级链条 |
| 做等级 | 等级只依据**个人自身**销售业绩/服务分，不依据团队规模 |
| 做团队 | 用"运营小组/学习小组"形态，组长拿的是**商家发的固定管理津贴（岗位性质）**，不是下线业绩抽成 |
| 做团长招商 | 微信生态里"团长"官方对应的是**帮卖带货机构**（机构主体，非自然人）；个人通常需挂靠或注册机构 |

### 3.5 推客分销的归因机制（做私域分销必须知道）

【官方规则】微信小店官方把归因窗口称为「**染色时效**」：

| 场景 | 窗口 |
|---|---|
| 推客分享商品链接，用户点击后从非内容场景购买 | **30 天** |
| 内容场景（短视频/直播/公众号/服务号）分享 | **3 天** |
| **3 天内首次下单** | **延长至 30 天** |

> **这条"3 天 → 30 天"是私域 KOC 分销的核心杠杆**：推客首触后的前 72 小时是唯一的机会窗口。
> 只要 72 小时内撬动任意一笔下单（哪怕 9.9 元引流品），这个用户后续 30 天的复购都算这个推客的。
> **落地动作**：首触话术必须绑一个低价钩子品；KPI 里单独考核"**72 小时内首单转化率**"，不要只看 GMV。

## 四、跨平台通用：处置手段与自检

### 4.1 平台常见处置手段（按严重度）

限流/不推荐 → 笔记或视频下架 → 扣信用分 → 投流权限驳回 → 接单权限封禁（7/30/90 天）→
冻结提现 → 永久关闭商业化功能 → 账号封禁。

**运营上最该记住的是**：处置对象既可能是**达人**，也可能是**品牌方**。品牌违规分会影响后续投放权限，
所以"用达人的号去冒风险"这件事最终会算到品牌头上。

### 4.2 项目启动前的平台侧自检（逐项打勾）

- [ ] 所有付费/置换的合作 **100%** 走官方报备/授权工具，零私下置换
- [ ] 品牌方后台的违规分/信用分当前状态已确认
- [ ] 逼近粉丝门槛（1,000 / 10,000）的账号已标记，准备切换通路
- [ ] 招募内容本身已过审（**招募帖不得承诺"给钱""返现"**）
- [ ] 私信话术里没有站外引流、没有保量承诺、没有"说是自己买的"
- [ ] Brief 里的"绝不能出现"清单已包含平台内容规范的禁止项
- [ ] 素材授权的**到期日**已进台账并设提醒（抖音默认 30 天）
- [ ] 分销结构已过三闸检查（层级/计酬依据/入门费），并已过法务
- [ ] AI 生成成分的标识义务已在 Brief 与合同中写明
