## 一、广告标识：有购物链接的推销内容必须标「广告」

**《互联网广告管理办法》（市场监管总局令第 72 号，2023-05-01 施行）第九条**【已核原文，来源 gov.cn】：

> 互联网广告应当具有可识别性，能够使消费者辨明其为广告。对于竞价排名的商品或者服务，广告发布者应当显著标明"广告"，与自然搜索结果明显区分。**除法律、行政法规禁止发布或者变相发布广告的情形外，通过知识介绍、体验分享、消费测评等形式推销商品或者服务，并附加购物链接等购买方式的，广告发布者应当显著标明"广告"。**

**同办法第十九条（直播）**【已核原文】：

> 商品销售者或者服务提供者通过互联网直播方式推销商品或者服务，构成商业广告的，应当依法承担广告主的责任和义务。直播间运营者接受委托提供广告设计、制作、代理、发布服务的，应当依法承担广告经营者、广告发布者的责任和义务。直播营销人员接受委托提供广告设计、制作、代理、发布服务的，应当依法承担广告经营者、广告发布者的责任和义务。**直播营销人员以自己的名义或者形象对商品、服务作推荐、证明，构成广告代言的，应当依法承担广告代言人的责任和义务。**

### 落到动作

| 内容形态 | 是否附购物链接/购买方式 | 处理 |
|---|---|---|
| 纯体验分享，无链接、无购买引导 | 否 | 不强制标"广告"，但仍受虚假宣传条款约束 |
| 体验分享 + 商品链接 / 团购码 / 小黄车 | **是** | **必须显著标明「广告」** |
| 走平台官方合作工具下单的商单 | 是 | 走平台报备（平台会附合作标识）；**同时**按平台规则在显著位置标注最稳妥 |

**责任在链条上是分配的**：品牌方＝广告主；MCN/代运营＝广告经营者/发布者；
KOC 以自己名义推荐并构成代言的＝广告代言人。**所以 KOC 协议里必须写明合规义务与违约责任**，
否则出事时责任划分不清。

## 二、虚假宣传与用语禁区（《广告法》）

| 条款 | 内容 | 核验状态 |
|---|---|---|
| **第九条第（三）项** | 广告不得使用"国家级""最高级""最佳"等用语 | 【已核原文摘录，维基文库 2021 年版】 |
| **第十七条** | 除医疗、药品、医疗器械广告外，广告中不得涉及疾病治疗功能，并不得使用医疗用语或者易使推销的商品与药品、医疗器械相混淆的用语 | 【依条文表述，需复核条款号】 |
| **第二十八条** | 广告以虚假或者引人误解的内容欺骗、误导消费者的，构成虚假广告；所列情形包括商品性能、功能、产地、用途、质量、销售状况、曾获荣誉等信息与实际情况不符且对购买行为有实质性影响 | 【依条文表述，需复核条款号】<br>注：**"虚假的用户评价"属于《反不正当竞争法》的虚假宣传条款**，不要挂到广告法二十八条名下 |
| **第三十八条** | 广告代言人在广告中对商品、服务作推荐、证明，应当依据事实，**不得为其未使用过的商品或者未接受过的服务作推荐、证明** | 【已核原文摘录】 |
| 第四条 | 广告不得含有虚假或引人误解的内容，不得欺骗、误导消费者 | 【依条文表述】 |

### 对 KOC 运营的三条硬动作

1. **没用过不能写"我用了"。** 这不只是道德问题，是第三十八条的问题。样品必须真的寄到、真的用过。
2. **功效宣称必须由品牌方提供依据**，且在注册/备案范围内。KOC 自己编参数是最高频的违规来源
   —— 解法是给"说明卡"，让 KOC 抄，不让他记。
3. **禁用词表要按品类定制**，通用表 + 品类功效词表两张。放进新人包，做成发布前自检。

## 三、分销 ≠ 传销：三条构成要件（这一节最重要）

**《禁止传销条例》（国务院令第 444 号，2005-11-01 施行）第二条**【已核原文】：

> 组织者或者经营者发展人员，通过对被发展人员以其直接或者间接发展的人员数量或者销售业绩为依据计算和给付报酬，或者要求被发展人员以交纳一定费用为条件取得加入资格等方式牟取非法利益，**扰乱经济秩序，影响社会稳定的行为**。

**第七条**列举的三类传销行为【已核原文】：

| 项 | 原文要点 | 对应到 KOC 机制里的具体设计 |
|---|---|---|
| **（一）拉人头** | 要求被发展人员发展其他人员加入，**对发展的人员以其直接或者间接滚动发展的人员数量为依据计算和给付报酬**，牟取非法利益 | "推荐 1 人入池奖 50 元""拉满 10 人升级"——**这就是拉人头** |
| **（二）入门费** | 要求被发展人员**交纳费用或者以认购商品等方式变相交纳费用**，取得加入或者发展其他人员加入的资格 | 入池保证金、资格费、"先买一箱才能当团长"、等级购买包 |
| **（三）团队计酬** | 要求被发展人员发展其他人员加入，**形成上下线关系，并以下线的销售业绩为依据计算和给付上线报酬** | "团长拿团员销售额的 5%"，且团员还能再带人 |

**第二十四条**的处罚量级【已核原文】：组织策划传销 50 万–200 万元罚款；介绍、诱骗、胁迫他人参加 10 万–50 万元；参加传销的 2000 元以下。

> **刑事层面**：组织、领导传销活动罪见《刑法》第 224 条之一；司法实践中的追诉标准涉及**人数与层级要件**
> （常被引述为"人员在三十人以上且层级在三级以上"）。
> 【须由法务确认】——本文不作为量刑或立案标准的依据引用。

### 行业里那句"三级分销就是传销"该怎么理解

**不准确。** 判定的核心是**第七条的三类行为**（拉人头计酬 / 入门费 / 团队计酬），层级数是重要但非唯一的因素。
**运营上的安全做法（本专家的默认设计原则）：**

1. **层级 ≤2 级**（自己 + 直接下级）；
2. **计酬只能来自真实商品销售**，商品有真实市场价值、价格公允；
3. **零入门费、零强制囤货**；
4. **推荐奖励只挂钩被推荐人的真实内容产出或真实首单销售**，一次性发放，不随层级滚动；
5. 上线前**由法务出书面意见**。

> 用脚本做结构初筛：`python3 scripts/compliance_check.py distribution --json '{...}'`

## 四、刷单、虚假评价、虚假交易

**《反不正当竞争法》**：经营者不得对商品的性能、功能、质量、销售状况、用户评价、曾获荣誉等作虚假或引人误解的商业宣传；
不得通过**组织虚假交易**等方式帮助其他经营者进行虚假或引人误解的商业宣传。
【依条文表述，需复核条款号 —— 该法近年有修订，条款序号可能变动，引用前请核对现行版本】

### 落到动作

**这些一律不做**：刷单、空包、补单撬权重、买好评、控评删差评、组织互赞、评论区自问自答制造互动假象、
批量养号发同质内容。

**合规替代**：
- 想要早期评价 → 真实首批用户运营 + 评价引导话术（不给对价、不干预内容倾向）；
- 想要互动 → 用"暗号归因"（如"戳客服报暗号"）替代刷评，既有互动又能归因；
- 想要权重 → 靠真实内容与投流，不靠虚假交易。

## 五、AI 生成内容的标识义务

**《人工智能生成合成内容标识办法》**（网信办、工信部、公安部、广电总局四部门 2025-03-14 发布，
**2025-09-01 施行**）配套强制性国标同日实施。【已核原文，来源 cac.gov.cn】

- **双重标识**：显式标识（画面/文案上可见的提示）+ 隐式标识（文件元数据中的生成合成属性、服务提供者信息、内容编号）；
- 原文禁止：**"任何组织和个人不得恶意删除、篡改、伪造、隐匿本办法规定的生成合成内容标识，
  不得为他人实施上述恶意行为提供工具或者服务"** —— 后半句意味着**给客户提供"去 AI 标"工具或服务同样违法**。

### 落到 KOC 运营的四条

1. 品牌交给 KOC 的 AI 生成图/视频/口播稿，**发布时的标识义务要写进 Brief 和合同**，否则责任归属不清；
2. **AI 数字人不得冒充真实用户体验**（既触发标识义务，也触发平台"虚假人设"条款）；
3. 素材银行里的 AI 二创素材，推送投流前确认标识随素材走（**剪辑/转码可能丢失元数据**）；
4. 质检 rubric 加一行："本条内容是否含 AIGC 成分？若是，显式标识是否已加？"

## 六、个人信息（招募表单是最容易被忽略的环节）

依据《个人信息保护法》的**告知同意**与**最小必要**原则【依条文表述】：

| 环节 | 运营侧要做的事 |
|---|---|
| 报名表设计 | 只收必要字段（账号 ID、粉丝量、内容方向、收货信息）；**不收身份证号、不收无关信息** |
| 告知 | 表单页写明：收集目的、使用范围、保存期限、由谁处理，并取得勾选同意 |
| 访问控制 | 收货地址/手机号做权限隔离（媒介看自己负责的，财务看结算必需的） |
| 对外提供 | 交给 MCN/代运营/物流之外的第三方前，需另行取得同意 |
| 删除 | 合作结束且无结算争议后，按承诺期限清理敏感字段 |

## 七、结算与税务（只讲运营侧动作）

【须由财税确认】本专家不提供税务筹划意见，也不判断具体税目适用。运营侧必须提前定清楚的是：

| 事项 | 要写进协议的内容 |
|---|---|
| 发放主体 | 谁付钱（品牌 / 服务商 / 平台） |
| 税前税后 | 报价是税前还是税后，**必须写死** |
| 代扣代缴 | 由谁代扣代缴，是否需要 KOC 提供发票 |
| 平台内结算 | 走星图/蒲公英/精选联盟结算的，明确平台服务费由谁承担 |
| 实物激励 | 礼品价值与发放记录留档 |
| 大量小额发放 | 走平台结算或有资质的服务商，**不要用个人账号大额转账给一堆人** |

**红线**：不得以"帮忙避税"为由让 KOC 拆分收款、虚开发票或使用他人身份收款。

## 八、一页速查：五条绝不做

1. **不做未标识的带链推销内容**（《互联网广告管理办法》第九条）；
2. **不做三级及以上的分销、不以人头计酬、不收入门费**（《禁止传销条例》第七条）；
3. **不做刷单、虚假评价、控评、自问自答**（《反不正当竞争法》+ 平台规则）；
4. **不做未用过就代言、不做无依据的功效宣称、不用绝对化用语**（《广告法》第九条、十七条、三十八条）；
5. **不做 AI 内容不标识、更不做去标识**（《AI 生成合成内容标识办法》）。

被要求做以上任何一条时的标准回应：**直说这条我不做**，一句话讲清风险（通常是罚款、下架、
关闭商业化权限），然后给出能达到相似目的的合规做法，接着继续把方案做完。不说教，不反复强调。
