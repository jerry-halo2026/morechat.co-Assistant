# KOC 单位经济模型：公式、基准、归因

> 整理时点 2026-08-17。佣金率与转化率区间除标注来源者外均为【经验值/待校准】，
> **必须用自家首批 100–200 个样品的实测值替换**，否则整个测算不可信。

## 一、指标字典（先把口径锁死，否则报表永远对不上）

### 1.1 成本类

| 指标 | 公式 | 口径陷阱 |
|---|---|---|
| CPM | 总成本 ÷ 曝光量 × 1000 | 曝光量用"阅读/播放量"还是"有效曝光"，差 2–5 倍 |
| **CPE** | 总成本 ÷ 互动量 | **小红书主流口径是赞+藏+评；抖音星图官方口径是赞+评+分享（不含收藏、不含完播）。跨平台不可直接比** |
| CPS 成本 | GMV × (佣金率 + 平台技术服务费率) | 名义"零风险"，但寄样是沉没成本，必须并表 |
| 单篇成本 | (稿费+样品+物流+激励+分摊人力) ÷ **发布篇数** | 分母用"发布篇数"不是"寄样数"，用寄样数会低估 30%–50% |
| **单篇有效内容成本** | 单篇成本 ÷ 内容合格率 | 唯一可跨批次比较的成本 |

**CPE 的三种成本口径（对外报数只能用一种，且在页脚写明）：**
```
CPE_稿费口径   = 稿费 ÷ 互动量               ← 最松；纯寄样时稿费=0，这个指标恒为 0，无意义
CPE_内容口径   = (稿费+样品+物流) ÷ 互动量    ← KOC 场景应该用这个
CPE_全成本口径 = (稿费+样品+物流+投流+人力) ÷ 互动量  ← 汇报给 CFO 用这个
```

> ⚠️ **CPE 是极易被操纵的指标**：达人可以用互赞群、自充互动把 CPE 压到 1 元以下。
> **CPE 必须与互动结构同时看**（评论/点赞比、收藏/点赞比），单看 CPE 会系统性选中刷量号。

### 1.2 履约类（KOC 运营真正的命门）

```
出稿率  = 按期发布篇数 ÷ 已签收样品人数        ← 分母是「签收」，不是「寄出」
合格率  = 通过验收篇数 ÷ 发布篇数
有效出稿率 r_eff = 出稿率 × 合格率            ← 反推寄样量时用这个

出单率的两种口径（必须区分，不可混用）：
  口径A 出单达人率 = 产生 ≥1 笔归因订单的达人数 ÷ 发布达人数   ← 用于「筛人」
  口径B 篇均订单数 = 归因订单总数 ÷ 发布篇数                  ← 用于「算钱」
```
> **90% 的复盘错误来自把口径 A 当口径 B 用。** 反推寄样量必须用口径 B。

### 1.3 池存量类

| 指标 | 公式 |
|---|---|
| 月活率 | 当月产出 ≥1 篇合格内容的 KOC ÷ 池内总数 |
| M3 留存率 | 首月合作且第 3 月仍产出 ÷ 首月合作数 |
| 90 天沉默率 | 连续 90 天无合格产出的 KOC 占比 |
| 复投率 | 二次及以上合作达人数 ÷ 累计合作达人数 |
| 样品浪费率 | 1 − 合格篇数 ÷ 签收数 |
| **内容复用率** | 被二次使用 ≥1 次的内容数 ÷ 产出内容总数 |
| 复用摊薄后单篇成本 | 单篇有效内容成本 ÷ (1 + 复用深度) |

## 二、寄样经济模型（可直接建 Excel）

### 2.1 变量表

| 符号 | 含义 | 取数口径 |
|---|---|---|
| `C_goods` | 单件商品成本 | COGS 含包材，**不是零售价** |
| `C_ship` | 单件寄样物流 | 含仓内拣货操作分摊 |
| `C_sample` | 单件寄样总成本 | `= C_goods + C_ship` |
| `F` / `I` | 单篇稿费 / 单人激励 | 纯佣时 F=0 |
| `r_pub` / `r_qc` | 出稿率 / 合格率 | 见 1.2 |
| `r_eff` | 有效出稿率 | `= r_pub × r_qc` |
| `O` | 篇均归因订单数 | **口径 B** |
| `AOV` / `m` | 客单价 / 毛利率 | 实付口径 / 扣 COGS 与履约后 |
| `c` / `f` | 达人佣金率 / 平台技术服务费率 | — |
| `rr` / `C_ret` | 退货退款率 / 单笔逆向成本 | — |

### 2.2 公式链

```
① 单篇有效内容成本（稿费后置，KOC 主流）
   C_note_eff = C_sample / r_eff + F + I

② 单篇有效内容成本（稿费前置，风险自担）
   C_note_eff = (C_sample + F + I) / r_eff

③ 单笔净毛利
   g = (1 − rr) × AOV × (m − c − f) − rr × C_ret

④ 盈亏平衡的篇均订单数
   O* = C_note_eff / g

⑤ 直接归因 ROI
   ROI_direct = O / O*

⑥ 可承受的最高佣金率（给定单样期望订单数 n_exp = r_eff × O）
   c_max = m − f − [ C_sample/(n_exp × (1−rr)) + rr × C_ret/(1−rr) ] / AOV

⑦ 后置稿费划算的条件
   F < C_sample × (1/r_eff_旧 − 1/r_eff_新)

⑧ 可承受寄样量（预算约束）
   N_max = 寄样预算 / (C_sample + (F + I) × r_eff)
```

### 2.3 三条必须讲给用户的结论

**结论 1：有效出稿率对成本是倒数级敏感，比压价重要得多。**

示例算术（占位假设，`C_sample = 60 元`，F=I=0）：

| 出稿率 | 合格率 | 有效出稿率 | 单篇有效内容成本 | 相对最优档的溢价 |
|---|---|---|---|---|
| 40% | 75% | 30.0% | 200.0 元 | **+155%** |
| 55% | 80% | 44.0% | 136.4 元 | +74% |
| 70% | 85% | 59.5% | 100.8 元 | +29% |
| 85% | 90% | 76.5% | 78.4 元 | 基准 |

→ **把有效出稿率从 30% 提到 76%，等于把内容成本砍掉 60%。** 所以第一优先级是履约机制
（稿费后置、履约承诺函、黑名单跨项目共享），不是议价。

**结论 2：小额后置稿费通常划算** —— 只要它抬升 r_eff 的幅度超过它自身的占比（公式⑦）。
示例：`C_sample=60`，r_eff 从 44% → 76.5% 时，后置稿费低于约 58 元就比不给稿费更省。

**结论 3：反推寄样量必须从"回本"倒推，不能从"预算"倒推。**

| 步 | 动作 |
|---|---|
| 1 | 锁定 AOV、m、c、f、rr、C_ret → 算 `g` |
| 2 | 用历史或首批 100 样测出 r_pub、r_qc、O → 算 `r_eff` |
| 3 | 算 `C_note_eff` |
| 4 | 算 `O* = C_note_eff / g` |
| 5 | 比较 O 与 O*，得 ROI_direct |
| 6 | ROI ≥1 → 寄样量只受现金流与**人力**限制；ROI <1 → **先修 r_eff / 降 c / 提 AOV，不要扩量** |

> **一个必须说出口的事实**：在常见的快消假设下（客单 129、毛利 45%、佣金 20%、平台费 10%、退货 12%），
> 每篇 KOC 内容需要带来 **6 单以上**才能回本。这对尾部 KOC 是很高的门槛。
> **所以纯直接归因看，KOC 铺量在多数快消场景不赚钱** —— 它的价值必须靠
> **增量 + 内容复用 + 搜索承接**三块补齐。这也是为什么 KOC 预算不该挂在单一 CPS ROI 上考核。

### 2.4 纯佣的隐藏成本（不并表会系统性低估 15%–30%）

样品 COGS + 逆向（多数纯佣达人不会退样）、寄样物流 + 仓内操作、平台技术服务费、支付通道费、
退货退款损失 + 逆向物流、**运营人力**（建联/寄样/催稿/结算）、优惠券或专属码的让利。

**若 `c_max` < 类目下限，说明该品类不适合 CPS 型 KOC 铺量**，改"按篇采买内容 + 授权复用"。

## 四、归因与增量（怎么证明 KOC 有效）

### 4.1 归因窗口对照（决定观察期至少多长）

> 🔴 **这是本文档风险最高的一张表。** 复核时发现多条来源已失效或误署名，逐条降级如下。
> **进合同、写考核口径之前，必须自己回各平台后台确认一遍。**

| 链路 | 窗口 | 证据状态 |
|---|---|---|
| 淘宝联盟 | 点击后 24h 内进店 + 其后 15 天内成交 | ⚠️ **【经验值/待校准】** 原署名页回源后是另一份规则，属误署名 → **回阿里妈妈规则中心确认** |
| 淘宝联盟（已确认部分） | 佣金 =（实付 − 运费）× 佣金比例；**按确认收货结算**；退款订单扣除 | 【官方规则】原文直读 |
| 京东联盟 | 同店 15 天 / 其他 24h；订单完成 26 天结算 | ⚠️ **【经验值/待校准】** 原规则页已失效跳转 → **登录京东联盟后台确认** |
| 抖音精选联盟 | 站内闭环，按订单结算基数计佣 | 【官方规则·转述】 |
| 小红书站内"站外店铺行为" | 阅读后 **15 天**（**不要求点击**） | ⚠️ **【经验值/待校准】** 复核时源站 403，未能回源 |
| 小红书 × 电商平台链路 | 多为 15 天，部分产品拉长到 30 天 | ⚠️ 同上，未能回源 |
| 微信小店染色时效 | 非内容场景 30 天；内容场景 3 天（**3 天内首单延长至 30 天**） | 【官方规则】原文直读 |

**三条硬约束：**
1. **KOC 效果复盘的观察期不得短于 30 天**（15 天窗口 + 缓冲）。4 周内下"KOC 没效果"的结论在方法上就是错的；
2. **跨平台数据不可直接相加** —— 口径完全不同，加总就是错的；
3. 小红书站内"阅读后行为"不要求点击，天然比点击归因宽松、数字更大，**对外汇报必须注明口径**。

### 4.2 为什么不能只看最后点击

典型路径：`刷到 KOC 内容 → 若干天后主动搜索品牌词 → 点搜索广告 → 下单`
→ 最后点击把 100% 功劳给了搜索广告，KOC 记 0。

后果：KOC 预算被砍 → 3–8 周后品牌词搜索量下滑 → 搜索广告 CPC 上涨、ROI 反而变差。

**最后点击只能作为"下限参考"，不能作为预算决策依据。**

### 4.3 增量验证四件套（按可信度）

| 方法 | 怎么做 | KOC 场景可行性 |
|---|---|---|
| **人群 Holdout** | 比 EXPOSED vs CONTROL（不是 vs 全体 holdout）；`Lift = (CR_exposed − CR_control)/CR_control`；holdout 比例 5%–10% | ✅ 有投流的 KOC 内容可行；纯自然流量**平台不提供 holdout** |
| **地域灰度** | ≥10 对城市配对、基线期 ≥8 周、处理期 ≥4–6 周 | ⚠️ 内容分发不按地域切，**纯自然流量的 KOC 铺量通常不成立**，别浪费预算 |
| **时间序列断点** | ≥8 周（最好 26 周）基线 + 协变量拟合反事实 | ✅ 可行，但必须控制大促、季节性、价格变动、断货、竞品动作，**实验期冻结其他渠道预算** |
| **专属券码 / 专属链接** | 达人专属码 + UTM（`utm_content` 必须带达人 ID） | ✅ 最易落地，但**系统性低估**（多数被种草的人不会输码）。用一次 holdout 标定校准系数 k |

**汇报口径三档**：
- **下限**：券码/专属链接直接归因订单（"最差也有这么多"）
- **中位**：平台归因（15 天窗口）+ 品牌词搜索增量（日常运营优化用）
- **上限/真值**：增量实验测得的 iROAS（预算决策用，**季度做 1 次**）

> 没有增量实验的年度 KOC 预算争取，一定会输给可直接归因的效果广告。

## 五、五桶预算框架

```
KOC 总预算 = 内容桶 + 投流桶 + 佣金桶 + 激励桶 + 运营桶
  内容桶 = 稿费 + 样品 COGS + 寄样物流
  投流桶 = 优质内容二次加热 + 素材授权费
  佣金桶 = CPS 佣金 + 平台技术服务费（GMV 的函数，属变动成本）
  激励桶 = 现金/实物/等级权益/评选奖金
  运营桶 = 人力 + 工具（达人库/寄样管理/看板）
```

| 原则 | 说明 |
|---|---|
| **佣金桶不预分配** | 佣金是 GMV 的函数，应在 P&L 里作变动成本扣除。把佣金和内容预算放同一个池子会导致"卖得好反而没钱做内容" |
| **投流桶必须留** | KOC 内容不投流 = 单次曝光即死。建议投流桶 ≥ 内容桶的 30%，且**只投跑赢批次 P80 的内容** |
| **激励桶按边际配** | 只用于拉出稿率与复投率，不做普惠发钱 |
| **运营桶是硬约束** | 人均可管理达人数决定池子规模上限 |

**阶段分配（用退出条件，不用固定比例）：**

| 阶段 | 目标 | 预算特征 | 进入下一阶段的门槛 |
|---|---|---|---|
| 测试期 | 找到"人 × 内容角度 × 钩子"的可行组合 | 小额多批次；宁可 30 人 × 1 篇，不要 5 人 × 6 篇 | ≥2 个内容角度的批次 CPE 优于基准，且合格率 ≥85% |
| 放量期 | 复制已验证组合 + 投流放大 | 集中到跑赢的角度，投流桶开到最大 | 增量实验或品牌词搜索量出现可测提升 |
| 长尾期 | 维持搜索承接与口碑基底 | 低成本纯佣 + 内容复用为主 | 月活率与复投率不跌破红线 |

> **"种草:收割"的标准比例**：**未检索到任何权威口径**（流传的 7:3 / 6:4 均无可靠出处）。
> 不要引用这类数字。改用动态规则：
> ```
> 品牌词搜索量环比下滑 且 搜索广告 CPC 上升 → 种草不足，往种草侧转移预算
> 品牌词搜索量上升 但 成交没跟上           → 承接不足，往收割侧（搜索广告、商详、货盘）转移
> ```
> 依据：搜索是"种草→收割"的中间变量，**搜索量变化总是先于成交变化出现**。

## 六、KOC 池健康度：15 项体征与红线

> 全部为【经验值/待校准】。**无任何平台或行业报告公布 KOC 池健康度基准。**
> 积累 3 个月自有数据后，用自家 P25/P50/P75 分位替换下表阈值。

| # | 指标 | 🟢 绿 | 🟡 黄 | 🔴 红线 | 触发动作 |
|---|---|---|---|---|---|
| 1 | 月活率 | ≥35% | 20%–35% | **<20%** | 暂停拉新，先做沉默唤醒；池子已是僵尸池 |
| 2 | 有效出稿率 | ≥65% | 45%–65% | **<45%** | 停止扩大寄样，改稿费后置/加承诺函/收紧准入 |
| 3 | M3 留存率 | ≥30% | 15%–30% | **<15%** | 查激励与结算体验（结算延迟是首要杀手） |
| 4 | 复投率 | ≥25% | 15%–25% | **<15%** | 建分层权益；全量回访找流失原因 |
| 5 | 90 天沉默率 | ≤40% | 40%–60% | **>60%** | 清池，把沉默名单移出分母，避免虚报池子规模 |
| 6 | 池子净增长 | >0 | =0 | **连续 2 月 <0** | 招募渠道枯竭，开新渠道 |
| 7 | 样品浪费率 | ≤25% | 25%–45% | **>45%** | 立即停公开招募寄样，切定向邀约 |
| 8 | 内容合格率 | ≥88% | 75%–88% | **<75%** | **Brief 有问题**，重写 + 加样例 |
| 9 | 爆文率（自定义 P95 口径） | ≥5% | 2%–5% | **<2%** | 内容角度全错，停投流回测试期 |
| 10 | 互动结构异常率 | ≤5% | 5%–15% | **>15%** | 池内刷量号过多，全池数据不可信，重新审核 |
| 11 | CPE 环比漂移 | ≤+10% | +10%~+30% | **>+30%** | 内容疲劳或平台流量政策变化，换角度/形态 |
| 12 | **单人产能负荷** | ≤上限 80% | 80%–100% | **>100%** | **履约率会先崩**。单运营上限按关系强度分档（已有工具）：一次性铺量 200–500 / 复投池 80–150 / 深度陪跑 50–80；**纯手工按 0.6 折算** |
| 13 | **结算及时率** | ≥98% | 90%–98% | **<90%** | **留存率的头号杀手，优先级高于一切内容问题** |
| 14 | 授权率 | ≥70% | 40%–70% | **<40%** | 合作协议缺授权条款，改模板 |
| 15 | 内容复用率 | ≥20% | 10%–20% | **<10%** | 优质内容没被用起来，等于白花钱 |

### 复盘看板必须同时出现的 6 个数

1. 有效出稿率（决定所有成本口径）
2. 单篇有效内容成本（唯一可跨批次比较的成本）
3. CPE_内容口径
4. 篇均归因订单数 O 与临界值 O*（是否回本）
5. **品牌词搜索量环比**（种草的最早信号，防最后点击误判）
6. 池子月活率 + **结算及时率**（池子明天还在不在）

### 自动化触发规则（企微 SCRM + 飞书工作流）

| 触发条件 | 自动动作 |
|---|---|
| 已寄样 且 寄样日+3 天 且 未提交初稿 | 提醒 KOC + 抄送媒介 |
| 已发布 且 发布+72h | 生成"挂链存活核查"任务 |
| 内容进入批次 P95 | 打「爆款」标签 + 触发素材授权申请 + 触发奖金审批 |
| 授权状态=已授权 且 累计消耗>0 | 自动进「素材银行」视图 |
| 合作次数 ≥3 且 爆款数 ≥1 | 自动升级到深度陪跑池 |
| 平台风险标=是 | 进黑名单视图 + 冻结在途排期 |
| **授权到期日 −7 天** | 提醒续签（抖音默认授权仅 30 天） |
