# 平台投放速查手册

> ⚠️ 平台层级名称、版位能力、计费与审核规则会频繁变更。本表用于快速定位思路与杠杆，涉及具体政策、数值与功能开关时，务必以平台当前官方文档和投放后台为准。

## 一、需求澄清清单（出方案前必问）

| # | 问题 | 为什么必须知道 | 缺失时的默认假设（需标注） |
|---|------|----------------|--------------------------|
| 1 | 产品/业务形态 | App、小程序、电商 SKU、表单线索、到店、直播 | 默认「App 激活 + 付费」双目标 |
| 2 | 转化目标与出价方式 | 决定考核口径与智能出价能否跑通 | 默认激活/留资，oCPM 或 CPA |
| 3 | 预算与周期 | 决定测试期规模与平台数量 | 默认日预算 5000 元、测试 7 天 |
| 4 | 目标人群 | 决定定向宽度与素材语言 | 默认一二线城市、25-45 岁、系统智能定向 |
| 5 | 已有素材与历史数据 | 决定是复用迭代还是从零起量 | 默认从零起，按行业基准测算 |
| 6 | 落地页/承接链路 | 决定 CVR 上限与转化事件埋点 | 默认已有可投放落地页且埋点正常 |
| 7 | 行业与资质 | 决定审核风险与禁用表述 | 默认非强监管行业 |

## 二、国内平台速查

### 巨量引擎（抖音 / 今日头条 / 西瓜 / 穿山甲 / 千川）

| 维度 | 要点 |
|------|------|
| 层级 | 广告组 → 计划 → 创意。广告组承载预算与出价方式，计划承载定向，创意承载素材 |
| 核心杠杆 | 素材 > 出价 > 定向。素材是最大的变量，同一计划下多创意赛马 |
| 出价方式 | oCPM / oCPC 为主，按转化目标（激活、付费、留资、ROI）出价 |
| 起量逻辑 | 靠「计划数量 × 素材数量 × 出价竞争力」堆概率，冷启动期多计划并行 |
| 常见坑 | 计划频繁关停重建导致模型反复冷启动；素材高度重复导致互相抢量 |
| 命名建议 | `巨量_业务_转化目标_人群_素材类型_日期`，如 `巨量_电商App_付费_一二线女_口播_0904` |

### 腾讯广告（微信朋友圈 / 公众号 / 小程序 / 视频号 / 搜一搜 / 优量汇）

| 维度 | 要点 |
|------|------|
| 层级 | 推广计划 → 广告 → 创意。计划设预算与投放目标，广告设定向与出价，创意挂素材 |
| 核心杠杆 | 版位选择 + 人群包质量 + 外层素材与落地页一致性 |
| 出价方式 | oCPA / oCPM，支持按注册、付费、加企微等目标优化 |
| 起量逻辑 | 朋友圈版位成本偏高但质量稳，优量汇走量；建议分开建计划，不混投 |
| 常见坑 | 版位全开导致预算被低质流量吃光；外层过度承诺导致 CVR 低 |
| 命名建议 | `腾讯_业务_版位_目标_人群_日期`，如 `腾讯_教育_朋友圈_留资_家长_0904` |

### 快手磁力引擎

| 维度 | 要点 |
|------|------|
| 层级 | 广告组 → 广告计划 → 创意，逻辑与巨量类似 |
| 核心杠杆 | 真实感与信任感。老铁人群对「人设 + 实测 + 让利」反应更好，精修广告片效果常不如原生感内容 |
| 出价方式 | oCPM / oCPC，支持直播间引流、涨粉、表单、付费等 |
| 常见坑 | 直接复用抖音素材，风格不适配导致 CTR 低 |
| 命名建议 | `快手_业务_目标_人群_素材类型_日期` |

### 小红书（聚光 / 蒲公英）

| 维度 | 要点 |
|------|------|
| 打法 | 先种草后收割：蒲公英达人笔记铺量 + 聚光信息流/搜索放大 + 搜索词卡位 |
| 核心杠杆 | 内容真实感、选题与关键词。硬广感越强效果越差 |
| 出价方式 | 按点击/曝光/表单/进店等，搜索广告单独建计划 |
| 常见坑 | 用电商硬广素材直接投，笔记互动率低、成本高 |
| 命名建议 | `小红书_业务_笔记/搜索_场景_关键词组_日期` |

### B站（起飞）/ 知乎（知+）

| 维度 | 要点 |
|------|------|
| 适用 | 高决策成本、需要深度说服的产品（3C、教育、汽车、SaaS、金融） |
| 核心杠杆 | 内容深度与 UP 主/答主的信任背书，投放前先看自然内容表现 |
| 打法 | 先小预算测内容，跑出自然互动后加热，避免冷启动硬砸 |
| 命名建议 | `B站_业务_UP主/自投_内容主题_人群_日期` |

### 百度营销（搜索 + 信息流）

| 维度 | 要点 |
|------|------|
| 适用 | 强意图需求，品牌词防守与竞品词截取 |
| 核心杠杆 | 关键词包结构与匹配方式、否定词、落地页相关性 |
| 常见坑 | 宽匹配 + 无否定词导致预算被无关词消耗；搜索与信息流混在一个计划 |
| 命名建议 | `百度_业务_品牌词/竞品词/通用词_地域_日期` |

### 阿里妈妈（万相台无界）/ 京东京准通

| 维度 | 要点 |
|------|------|
| 适用 | 电商站内收割，归因闭环最好 |
| 核心杠杆 | 人群资产（AIPL/DEEPLINK）分层运营、货品分层、大促节奏 |
| 常见坑 | 只看 ROI 不做人群资产沉淀，活动结束后无法复投 |
| 命名建议 | `阿里妈妈_店铺_货品_场景_人群_日期` |

## 三、海外平台速查

| 平台 | 层级 | 核心杠杆 | 常见坑 |
|------|------|----------|--------|
| Google Ads | Account → Campaign → Ad Group → Ad | 意图词结构、素材资源（RSA）、落地页体验分、转化跟踪 | SKAG 已过时，过度细分关键词导致数据稀疏、智能出价跑不动 |
| Meta Ads | Campaign → Ad Set → Ad | 创意为王、受众与版位交由算法、CAPI 回传质量 | 受众过度细分、频繁改动导致学习期重置、iOS 归因缺失 |
| TikTok for Business | Campaign → Ad Group → Ad | 原生感短视频、前 3 秒钩子、素材更新频率 | 素材更新慢导致快速衰退；直接搬运国内素材不本地化 |
| Apple Search Ads | Campaign → Ad Group → Keyword | 品牌词防守、竞品词、发现型词分组出价 | 与 MMP 归因口径不一致导致重复计算 |

**海外特有注意事项**：归因窗口与口径（SKAN / MMP / GA4）差异大；素材需本地化而非翻译；时区与结算币种影响日报口径。

## 四、审核红线速查（强监管行业尤其注意）

| 类别 | 高频拒审原因 | 规避动作 |
|------|--------------|----------|
| 医疗/医美/保健 | 功效承诺、治愈率、前后对比、患者形象 | 只讲资质与流程，删除绝对化疗效表述，补充资质证明 |
| 金融/保险/借贷 | 收益承诺、保本保息、诱导借贷 | 明示风险提示，删除年化收益数字，补充机构资质 |
| 教育/培训 | 保过、包就业、提分承诺、名师背书 | 强调课程内容与服务，删除结果承诺 |
| 招商加盟 | 收益测算、零风险、回本周期 | 只讲品牌与扶持，删除投资回报承诺 |
| 游戏 | 版号信息缺失、虚假福利、诱导充值 | 补齐版号与适龄提示，删除「送万元」类表述 |
| 通用 | 绝对化用语（最、第一、国家级）、虚假原价、诱导分享、数据无出处 | 用限定词与真实数据替代，标注数据口径与来源 |

> 强监管行业在出素材前先走一遍这张表，比拒审后返工更省时间。
