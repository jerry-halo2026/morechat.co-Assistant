# 专业研报底稿助手

产品版本：`2026.11.5`（隔离修订 `local-01`）
稳定包身份与主 Agent：`long-manuscript-expert`
花名：福帮手 / FBSir ｜ 类型：Agent 型单专家 ｜ 分类：行业顾问（`12-IndustryConsultant`）

把研究问题、网络信息和本地材料转化为内容充分、出处可查、便于继续写作与修订的专业研报底稿。默认使用用户语言；中文输入使用简体中文。

## 这一版能做什么

1. **首份有用底稿**：从明确决定、读者与范围出发，盘点实际可读取材料，区分"实际读取 / 有效证据 / 被成果采用"，形成三条以上承重主张、证据与反证索引、实质正文、可编辑主稿与稳定阅读呈现，并读回。缺失不补零，抽样不当全读。
2. **五类成品形态**：图鉴、白皮书、数据报告、人群专题、方法论。用自然语言选择或由读者用途推荐；形态与行业赛道分离，共用基础层、各自叙事与视觉差异；缺料合法降级，数据限制进入成果。不要求填技术 JSON。
3. **局部修订与接续**：先读当前稿，写前核对选定源码/原件/用户手改完整字节，变化即拒绝；排他新建、碰撞拒绝、写入回执与读回（这些守卫已在小写入器具名验证中证实；不把 Multica 的全部自由文件写入说成崩溃原子性或多文件事务——实际原生任务证据为限定修改、排他创建与当前读回，具体写入后端能力以其实际回执为准）；范围外只标待同步。项目持便携接续卡，意图/证据/组合修订分开，新会话只从项目文件恢复，不依赖云或本地记忆；未知写入按原号只读查询，不换号、不重放。
4. **可选远端策略（默认关闭）**：闭合 `paper.intent.v2` + 精确 `2026.11.5` + 同号只读 receipt 查询。普通研究、五形态与项目文件都不需要服务、登录、连接器或新运行时。

## 使用示例

- 围绕【行业、企业或议题】，结合联网搜索和我的材料，形成有出处、含反证的研究底稿，并给出写作建议。
- 把这批材料整理成图鉴、白皮书、数据报告、人群专题或方法论，并说明哪种形态更适合我的读者。
- 将这些新材料加入已有底稿，只更新受影响章节，保留我的判断和手改，并从项目文件接着写。

## 能力与限制（如实表述）

- 可编辑主稿与稳定阅读呈现是明确支持的交付；两者来自同一稿件版本并读回。需要 PDF 时必须实际生成并渲染检查，Markdown 文件存在不等于 PDF 合格；宿主不显示 SVG/交互图时提供静态替代，SVG 文件存在不等于宿主已显示。
- 图像、音频、视频按宿主实际入口处理；未读取的媒体明确列为未读，转写不冒充原生音画理解，跨端能力保持真实边界。
- 远端策略默认关闭。可选策略与反馈仍默认关闭。**历史（2026.11.0200 时点）**：配套服务 `paper-20261105-0200-r3` 曾由独立服务路部署并公网读回；前置 0200 版本字节的三件客户端源码曾在原时点通过一次受控合成 Python HTTPS 链（resolve / 原号 receipt 查询 / 明确同意 feedback，结果 selected / recorded / accepted），该结果绑定当时字节、保留不改。**当前（2026.11.5）**：新版服务 release `paper-20261105-115-r1` 已由服务路部署；本版固定字节的三件客户端（含 `strategy_client_0200.py`）以精确 `2026.11.5` consumer 完成一次受控合成 Python HTTPS 配对（selected / recorded / accepted）。该证据是新合成 Python 请求，不是 Multica 原生远端用户任务、不是用户采用或业务结果，也不构成服务持续可用性或线上持续通过的保证；默认配置值不自动代表某次实际执行结论。容量满、拒绝或用户未选远端时原生研究照常完成。不启用 v3、foundation preview、feedback v3、私有项目查询、付费供应商或全局稿件存储；不伪装 270/300。

## 安装 / Installation

本包由 **morechat.co-Assistant** 内容仓分发，**通过 morechat.co-Assistant 目录导入**：

1. 在 morechat.co-Assistant 仓中取出 `catalog/packages/<kind>/<id>/`；
2. 该目录即包根目录，内含 `plugin.json`、`agents/`、`skills/`，整体作为包目录导入；
3. 导入后由平台注册 Agent / Squad 与技能，无需额外安装脚本或注册命令；
4. 头像不在仓内分发（`avatars/` 已移除），由产品端生成。
