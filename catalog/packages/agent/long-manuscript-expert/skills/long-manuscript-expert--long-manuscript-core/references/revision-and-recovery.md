# 补料、局部修订与恢复

## 一、先冻结当前基线

补料或改稿前回读当前文件，而不是只凭记忆中的旧稿。记录：

- 当前稿版本或可核对快照；
- 本轮目标和用户最新指令；
- 允许修改的章节、段落或选区；
- 必须逐字保留的作者手改、引语、数字或其他文本；
- 新增或替换材料及其授权范围；
- 可能需要同步更新的目录、引用、图表、摘要和附录。

用户已明确范围时直接执行，不重复索要同一确认。范围含糊且会改变结果时，采用最小可逆范围并只问一个关键问题。

## 二、补料影响映射

逐项判断新材料对现有主张和产物的作用：

| 影响 | 含义与动作 |
| --- | --- |
| 新增 | 增加原材料没有的新事实或案例，定位可使用的章节 |
| 支持 | 增强已有主张，但不自动消除原有限制 |
| 修正 | 改变事实、数字、时期或身份，更新相关主张及派生物 |
| 冲突 | 与现有材料在同一对象和口径下不一致，回源核对并并列限制 |
| 重复 | 保留副本和来源关系，不增加独立证据数量 |
| 无关 | 对当前研究问题无可识别用途，说明未采用范围 |
| 未知 | 依赖关系或内容不足，保留待核，不能宣称无影响 |

先列受影响的主张、章节、图表、摘要、写作建议和来源附录，再修改。来源变化使相关主张需复核；主张变化使依赖它的图表、摘要与建议需同步检查。每项实际变化另标“新材料导致”或“复核发现原稿已有错误”，分别保留触发证据和原始定位。无关章节及仍有效的复核结果不重做。

## 三、有界修订

1. 只修改授权范围及用户可见说明中列出的必要联动项。
2. 保留旧稿、历史出处、作者判断和旧版本；修订稿另存或使用宿主明确支持的版本机制，不覆盖原件。
3. 作者手改优先保留。若新证据与手改冲突，指出具体句子和影响，不整章自动重生。
4. 输出实际改后正文，而非只有改稿建议；附简洁差异说明，包含原文锚点、修改原因和证据。
5. 未找到关联时保留未知并说明需要什么映射，不能把“没有自动识别到关联”写成“无影响”。
6. 修改后检查范围外文字和保护文本。机械一致只证明范围未变，不证明事实、语义或质量正确。
7. 排版或后续编辑改变交付正文后，重新执行相关范围、回读和一致性检查，旧回执不能绑定新稿。
8. 每项变化标明原因类别：“新材料导致的变化”或“复核发现原稿已有的错误”。后者注明原稿位置、原始证据和修正依据，不伪装成新料影响。
9. 修改范围是写入边界，不是拒绝核查的借口。授权章节内仍需核对必要的原始字段、对象关系、反证和上下文；“只更新第二章”不等于第二章其他小节一律不能核查。范围外只做必要依赖识别，发现影响时列入修订说明，不擅改。
10. 摘要、目录、引用、图表、附录和其他格式存在已知未同步项时，逐项标为待同步或受限；不得宣称全稿一致。只有实际完成授权联动并回读核对后，才能声明相应范围一致。
11. 自检同时执行范围或字节保护与语义回源：至少抽查授权章节内关键关系到原始材料，检查原有限定和反证是否仍保留，不能只做新旧文件比较。

## 四、项目恢复点

长任务或中断前保留最小可行动状态：

- 原研究问题、读者、用途和当前范围；
- 当前稿位置或可复制文本、当前版本和停点；
- 已读取来源、采用证据、来源变化和关键口径；
- 已完成章节或批次、未完成范围、失败和未知项；
- 用户已确认决定、模型暂定建议和仍未知事项，三者分开；
- 唯一下一步及一条可继续执行的自然语言指令。

“继续”表示恢复原任务未完成部分，不表示同意新的购买、发布、外发或额外提议。恢复时先核对当前文件与来源，复用仍有效结果；上下文缺失时从用户提供的项目文件或续接说明恢复，不假装存在隐藏持久化。

模型或工具条件变化后，只刷新受影响的能力判断。已核实来源、已完成计算和未变化材料不因换模型自动失效，也不默认全量重跑。

## 五、有界批次与失败收束

- 大目录、搜索结果、长媒体和多格式生成按问题或语义单元分批；每批保留范围与恢复点。
- 独立研究分支少量起步，原则上首批不超过三个工作单元，服从宿主和预算限制。
- 区分运行、失败、超时和状态未知。先检查原操作是否已产出或仍在运行，避免重复副作用。
- 同一可恢复失败默认最多一次有理由的重试；输入格式明确不支持、权限拒绝等确定性错误不在同一路径盲试。
- 慢调用不得阻塞已经可以完成的可靠正文；单个失败项隔离后继续其他工作。
- 自我修订只处理具体高影响缺陷，设定收束条件，保留当前可用稿。
- 用户停止时不启动新批次；若已在运行的调用无法取消，准确说明，不能假称已全部停止。

## 六、成本与续改

先判断路线是否能完成合格任务，再比较实际积分、耗时、外部费用和人工返工。展示倍率不是实耗，费用不可见时保持未知，不填零。复用有效 OCR、ASR、来源核验和统计结果；补料只处理变化；简单任务采用直接步骤。不得为节省调用而省略承重证据或必要交付检查。
