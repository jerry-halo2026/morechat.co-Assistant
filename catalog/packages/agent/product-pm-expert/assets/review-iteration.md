# 评审迭代闭环自动化（Review-Iteration Loop）

> 配套资产：演练自动化回归的评审迭代扩展（v1.13.0）。与 agent.md「能力 8：演练标准」评审迭代闭环自动化小节、SKILL.md「## 评审迭代闭环自动化」章节保持一致（单一事实源），改其一必同步其余。
> 用途：新演练 PRD 出稿后，自动模拟一轮评审（按 `assets/review-corpus.md` 语料库与 `assets/review-roles.md` 角色库命中），验证每条命中评审反馈在 PRD 中有对应章节落点，形成「出稿 → 评审 → 修订 → 回归验证」的闭环。
> 回归联动：`_deep_test/_verify_iteration.py` 对演练 PRD 执行评审迭代闭环验证，纳入一键回归。

## 一、闭环四步（评审迭代闭环）

1. **出稿**：按场景模板产出 15 段完整 PRD（含评审自查）
2. **模拟评审**：按语料库类别（资金/状态/范围/依赖/合规/场景专项等）与角色库视角（研发/测试/资金）命中评审反馈；资金类必查「资金底线三件套」，强监管类必查合规专项
3. **修订落点**：每条命中评审反馈须在 PRD 有对应章节落点（业务规则/验收标准/专项检查/风险应对），不静默忽略
4. **回归断言**：`_verify_iteration.py` 按「命中 → 落点」映射表断言修订已落地，纳入一键回归；新增场景出稿后跑一次回归即自动覆盖

## 二、命中 → 落点映射表（评审反馈 → PRD 章节）

| 评审命中（语料库/角色库条目） | 必查落点（PRD 章节） | 示例措辞 |
|------------------------------|----------------------|----------|
| 资金类（幂等/对账/资损） | 七、功能需求 + 十二、异常处理 + 十五、评审自查 | 放款幂等键/对账轧差/资损监控 |
| 验收不可测 | 功能需求验收标准 + 十五、评审自查 | Given/When/Then 可测 |
| 依赖排期不明 | 十三、依赖清单 | 三档分级 + 最晚就绪时限 |
| 方案选型未论证 | 五、方案对比与选型说明 | 三案对比 + 演进路径 |
| 合规红线（强监管） | 十五、评审自查 + 风险 | 资质/存管/征信授权/适当性 |
| 存量迁移风险 | 十二、异常处理 + 十三、上线验证 | 预演/校验/回滚/公告 |
| 计量口径不明 | 指标口径四要素 + 数据埋点 | 2xx 计费/排除项 |
| 文案缺失无兜底 | 业务规则 | fallback 链 |

## 三、闭环验收标准

- 每条命中评审反馈都有 PRD 章节落点，且回归断言覆盖（断言字符串与产物实际措辞精确匹配，不放宽断言凑数）
- 资金类演练必含资金底线三件套（幂等 + 对账 + 资损），缺一即 FAIL
- 强监管类（金融）演练必含合规专项（征信授权/适当性/审计留痕），缺一即 FAIL
- 修订后跑一键回归全绿方可发布；FAIL 时修产物措辞或落点，不放宽断言
