## 场景 7：开放平台 / API 产品

### 适用判断

用户要做的产品是「以 API 为核心交付物」：开放平台、开发者服务、数据/能力输出、B 端集成接口。

### 15 段 PRD 各段要点

| 段 | 该场景要点 |
|----|------------|
| 二、目标 | 开发者接入数、API 调用量、成功率（P95/P99）、活跃开发者、计量收入 |
| 三、术语 | AppKey/Secret、签名、Token、QPS、配额、沙箱、版本 |
| 四、范围 | 接口清单（本期提供哪些 API）、控制台、文档站、计费 |
| 五、方案对比 | 自建网关 vs 云网关 vs 直连；REST vs GraphQL |
| 七、功能需求 | 开发者注册/密钥管理、接口调试、文档、配额与限流、计量计费、用量报表、告警 |
| 八、非功能 | 接口 P95/P99 延迟、可用性 SLA（99.9%）、限流阈值、幂等、审计 |
| 九、流程 | 调用鉴权 → 限流校验 → 业务处理 → 计量记录 → 响应（统一错误码） |
| 十、数据 | 调用日志（含 AppKey/接口/耗时/状态码）、计量流水、配额快照 |
| 十一、权限 | 开发者（本人密钥/配额）、平台运营（全量）、计费（对账） |
| 十二、异常 | 密钥失效、签名错误、超限流、接口错误码、幂等冲突 |
| 十三、上线 | 依赖（网关/计量/文档站）、灰度（白名单开发者）、版本兼容策略 |
| 十四、风险 | 密钥泄露、超配额滥用、接口不兼容升级、计费争议 |

### 专项检查清单（8 项）

- [ ] 接口契约：入参/出参/错误码统一（业务错误码 + HTTP 状态码分层）
- [ ] 认证鉴权：AppKey/Secret + 签名防重放，或 OAuth Token；密钥可轮换可吊销
- [ ] 限流与配额：按 AppKey/接口分级限流（QPS/日配额），超限返回明确错误码与 Retry-After
- [ ] 幂等与重试：写操作幂等键；客户端重试指引（指数退避）写入文档
- [ ] 计量计费：调用量/计费字段口径一致（成功/失败是否计费注明）；日对账 + 资损监控（资金类必查）
- [ ] 版本兼容：不兼容变更走版本升级（v1/v2），旧版本弃用期与迁移指引明确
- [ ] 沙箱与文档：沙箱环境与测试数据、接口文档（示例/错误码/限流说明）
- [ ] 安全：密钥不落日志、调用审计、敏感字段脱敏

## 场景 8：数据合规产品

### 适用判断

产品涉及个人信息处理、数据跨境、用户权利响应、隐私合规建设（隐私政策/同意管理/数据治理），或强监管领域的数据流程。

### 15 段 PRD 各段要点

| 段 | 该场景要点 |
|----|------------|
| 二、目标 | 合规违规事件 0、用户权利响应时效（删除/导出时限）、同意覆盖率、审计完整率 |
| 三、术语 | PII、敏感个人信息、同意、脱敏、加密、留存期、数据主体 |
| 四、范围 | 处理的数据类型清单、覆盖的产品链路、不含（如第三方数据采购） |
| 五、方案对比 | 自建合规平台 vs 采购合规工具 vs 流程制度先行 |
| 七、功能需求 | 数据分类分级、同意管理（告知/撤回）、脱敏与加密、用户权利（删除/导出/更正）、留存期自动清理、合规审计 |
| 八、非功能 | 删除/导出时限（如 30 天内）、加密强度、审计日志保留期 |
| 九、流程 | 采集告知 → 同意 → 使用（脱敏加密）→ 权利响应 → 到期删除 |
| 十、数据 | 数据资产清单（分类分级）、同意记录、权利请求工单、审计日志 |
| 十一、权限 | 数据管理员（分级授权）、合规官（审计）、用户（本人权利） |
| 十二、异常 | 同意撤回后使用中断、删除失败需人工介入、导出数据量超限 |
| 十三、上线 | 合规评审前置、灰度（先试点链路）、法务确认 |
| 十四、风险 | 过度采集、未授权使用、跨境违规、删除不彻底 |

### 专项检查清单（8 项）

- [ ] 数据分类分级：数据资产清单 + 分级（公开/内部/敏感/PII）+ 分级处理规则
- [ ] PII 处理：脱敏（不可逆/可逆区分）、加密存储、最小化采集（只采必要字段）
- [ ] 告知同意：采集前告知（目的/范围/期限）、同意留痕、撤回路径与生效时限
- [ ] 用户权利：删除/导出/更正流程明确（响应时限、验证身份、工单留痕）
- [ ] 留存期：各类数据留存期明确（如停用后 X 天删除），到期自动清理
- [ ] 跨境合规：数据出境场景标注合规依据（评估/标准合同/认证）
- [ ] 审计：处理活动日志、权限变更审计、合规报告可导出
- [ ] 未成年人：未成年数据特殊保护（单独同意/监护人同意）

## 场景 9：国际化产品（多语言/多区域）

### 适用判断

产品面向多个语言/区域市场：多语言界面、多币种、多时区、多法规，或海外发布。

### 15 段 PRD 各段要点

| 段 | 该场景要点 |
|----|------------|
| 二、目标 | 首批区域数、语言覆盖、区域转化率、本地化支付成功率、法规合规 0 事故 |
| 三、术语 | i18n、locale、时区、币种、GDPR、本地化 |
| 四、范围 | 首批语言/区域清单、本地化深度（界面/支付/客服/内容） |
| 五、方案对比 | 自建翻译流程 vs 翻译平台 vs 机器翻译+人工校对 |
| 七、功能需求 | 语言切换、文案管理（占位符/复数/时长）、货币与时区本地化、区域配置、本地化支付与客服 |
| 八、非功能 | 文案长度适配（溢出防护）、时区一致性、货币精度（分/Decimal）、加载性能 |
| 九、流程 | 区域选择 → 本地化内容 → 本地化支付/客服 → 区域运营 |
| 十、数据 | locale 资源、区域配置、货币汇率口径、区域埋点 |
| 十一、权限 | 区域运营（本区域配置）、翻译管理（文案）、全局管理员 |
| 十二、异常 | 文案缺失回退（fallback）、货币汇率过期、时区错位、区域支付不可用 |
| 十三、上线 | 区域灰度（首批 1-2 区域 → 扩展）、法规确认前置 |
| 十四、风险 | 文案溢出/截断、时区日期错位、货币精度、区域法规不符 |

### 专项检查清单（8 项）

- [ ] i18n 资源规范：占位符（{0}/{name}）、复数规则、时长/日期格式（ICU MessageFormat 或等价）
- [ ] 文案管理：缺失文案 fallback 链（当前语言 → 英语 → 原文）、翻译评审与版本管理
- [ ] 区域配置：时区/货币/日期/数字格式按 locale 配置，禁止硬编码
- [ ] 货币精度：金额以最小货币单位（分/欧分）存储，汇率口径与生效时间明确
- [ ] 本地化支付：区域支付方式适配（本地钱包/卡组）、失败提示本地化
- [ ] 法规适配：GDPR/个保法/区域法规（如儿童数据 COPPA）标注合规要求
- [ ] 区域发布：区域灰度与回滚、区域数据隔离与权限
- [ ] 本地化客服：客服语言覆盖、时区值班、SLA 按区域配置

## 场景 10：企业服务（B 端客户服务 / 工单 / 续约）

### 适用判断

面向企业客户的服务履约：工单与 SLA、客户成功、续约与增购、服务台与知识库、服务度量。

### 15 段 PRD 各段要点

| 段 | 该场景要点 |
|----|------------|
| 二、目标 | 工单 SLA 达标率、首响时长、客户续约率、NPS/CSAT、服务成本 |
| 三、术语 | 工单、SLA、首响/解决时长、客户成功、续约窗口、知识库 |
| 四、范围 | 工单渠道（IM/邮件/电话）、SLA 分级、续约流程、服务台 |
| 五、方案对比 | 自建工单系统 vs 采购 ITSM vs 混合（工单自建+知识库外采） |
| 七、功能需求 | 工单创建/流转/升级、SLA 计时与告警、客户分群与续约提醒、知识库、满意度回访 |
| 八、非功能 | 工单处理 P95 时长、SLA 计时精度（分钟级）、审计 |
| 九、流程 | 客户提单 → SLA 计时 → 分派/流转 → 处理/升级 → 解决回访 |
| 十、数据 | 工单、SLA 事件、服务时长、客户信息（脱敏）、续约记录 |
| 十一、权限 | 客服（本组工单）、组长（升级/仲裁）、客户成功（续约）、运营（看板） |
| 十二、异常 | SLA 超时、工单误派、客户信息变更、续约窗口错过 |
| 十三、上线 | 依赖（IM 接入/客服人力）、灰度（先试点客户群） |
| 十四、风险 | SLA 超时赔付、客服人效、客户数据合规、续约流失 |

### 专项检查清单（8 项）

- [ ] 工单 SLA：分级（P1/P2/P3）与计时规则（首响/解决时长）明确，超时自动升级与告警
- [ ] 客户分群与续约：续约窗口（到期前 N 天）与提醒、续约漏斗口径、流失预警
- [ ] 服务度量口径：SLA 达标率/首响时长/CSAT 定义与排除项（如客户等待中不计时）
- [ ] 升级路径：工单升级链路（客服→组长→高级）与升级时限
- [ ] 知识库：解决方案沉淀与检索、权限分级（内部/客户可见）
- [ ] 权限分级：客服/组长/客户成功/运营权限矩阵与数据隔离
- [ ] 审计：工单操作留痕、SLA 变更留痕、客服质检
- [ ] 客服承接：值班排班、机器人分流、投诉升级通道、脱敏

### 10.4 多租户深化子模板（v1.19.16，企业服务多端/多租户深化）

- 租户三隔离：数据隔离（租户 ID 全链路透传 + 跨租户访问拦截）、存储隔离、资源隔离策略；共享库 + 租户 ID vs 独立库的选型与迁移成本
- 租户级 SLA 计量：SLA 达标率分母按租户合同 SLA 范围；首响/解决时长按租户分级；超时自动升级与赔付口径按租户合同
- 租户开通与迁移：租户开通流程（审批/配额初始化）；存量租户数据迁移方案（预演/校验/回滚/公告）
- 租户级审计：工单/SLA 变更/操作留痕按租户维度可查询可导出，留存 ≥180 天
- 租户套餐配额：租户级配额/降级/超限告警；跨租户资源争抢监控（容量与并发隔离）

## 场景 11：硬件 IoT（设备接入 / 固件 OTA / 遥测）

### 适用判断

硬件设备 + 云端联动：设备接入与认证、物模型、固件升级（OTA）、遥测数据采集、断连与离线处理。

### 15 段 PRD 各段要点

| 段 | 该场景要点 |
|----|------------|
| 二、目标 | 设备激活数、在线率、OTA 成功率、遥测数据完整率、固件版本分布 |
| 三、术语 | 设备、物模型、OTA、遥测、网关、证书、离线缓存 |
| 四、范围 | 接入协议（MQTT/HTTP）、物模型定义、OTA 升级、遥测存储、存量设备迁移 |
| 五、方案对比 | 自建 IoT 平台 vs 云 IoT（阿里云/腾讯云） vs 混合 |
| 七、功能需求 | 设备注册/认证、物模型、OTA（灰度/回滚/失败恢复）、遥测上报与告警、设备管理 |
| 八、非功能 | 设备并发接入容量、消息吞吐、OTA 批次容量、时区口径 |
| 九、流程 | 设备注册 → 认证 → 上报 → 云端处理 → 指令下发 → OTA 升级 |
| 十、数据 | 设备档案、物模型数据、遥测时序、OTA 任务、固件版本 |
| 十一、权限 | 设备厂商（本厂设备）、运营（全量）、售后（设备维度） |
| 十二、异常 | 设备断连、OTA 失败回滚、证书过期、遥测缺失、数据乱序 |
| 十三、上线 | 依赖（设备端 SDK/云端平台）、灰度（指定设备组 OTA） |
| 十四、风险 | OTA 变砖、设备安全（证书泄露）、容量不足、存量迁移中断 |

### 专项检查清单（8 项）

- [ ] 设备接入：协议与认证（证书/密钥）明确，设备唯一标识与激活流程
- [ ] 物模型标准：属性/事件/服务的物模型定义统一，版本管理
- [ ] OTA：分批次灰度、失败回滚、断点续传、设备变砖保护（双分区/恢复模式）
- [ ] 离线与断连：离线缓存与补传策略、断连重连退避、指令下发失败处理
- [ ] 数据采集口径：遥测频率、时区与时间戳口径、数据乱序处理
- [ ] 设备安全：证书/密钥安全存储与轮换、固件签名校验、最小权限
- [ ] 容量：设备数/并发消息量/遥测存储容量预估与扩展
- [ ] 存量迁移：旧设备迁移方案（预演/校验/回滚/公告）

### 11.4 多端深化子模板（v1.19.16，硬件 IoT 多端/多形态深化）

- 设备形态矩阵：网关/子设备/直连设备分类与能力差异；型号-固件版本兼容矩阵（升级前兼容性校验）
- 多端 OTA 分批：按型号/区域/固件版本分批灰度，批次间互不阻塞；失败回滚与断点续传；批次进度与暂停/恢复
- 多端遥测口径：统一时间戳与时区；端侧去重与乱序处理；离线补报窗口与丢弃策略
- 多区域驻留：数据驻留区域配置；跨境传输合规（审批/脱敏/留存）；区域间迁移
- 多端认证与权限：设备级证书/密钥、双向认证、最小权限；证书吊销与固件防降级

## 场景 12：金融（理财 / 借贷 / 风控 / 额度）

### 适用判断

金融产品：理财购买/赎回、借贷申请/放款/还款、额度与征信、风控联动、强监管合规。

### 15 段 PRD 各段要点

| 段 | 该场景要点 |
|----|------------|
| 二、目标 | 开户数、交易量、坏账/逾期率、额度使用率、合规违规 0 |
| 三、术语 | 年化、额度、征信、风控、存管、清结算、适当性 |
| 四、范围 | 开户/绑卡、理财申赎、借贷授信/放款/还款、风控联动、合规留痕 |
| 五、方案对比 | 自建清结算 vs 银行存管 vs 第三方支付+分账 |
| 七、功能需求 | 开户 KYC、授信额度、放款（幂等）、还款计划、理财申赎、风控拦截、适当性提示 |

### 12.4 多端/多租户深化子模板（v1.19.16，金融多端/多机构/多租户深化）

- 渠道一致性：多端统一账户体系；渠道标识全链路透传；各端额度/利率/还款计划一致
- 机构资金方隔离：多机构资金方（银行/信托/担保）数据与资金隔离；机构级对账与结算批次（T+1、差异挂起 ≤24h）
- 多端幂等：业务单号 + 渠道唯一约束；重复请求不重复放款/扣款；跨端重试与结果查询一致
- 多端安全：端侧证书/双向认证；风险设备识别与联动风控；会话与密钥管理
- 机构级审计：机构/渠道维度审计留痕（放款/还款/冲正/担保）≥180 天；监管报送口径一致

## 场景 26：AI 功能与智能体（v1.19.24 新增）

**AI 六模块专项（能力 9）**：任务定义 / 输入输出契约 / 质量阈值与验收样本 / 异常降级与人工接管 / 行为约束三层 / 反馈与版本闭环，缺一不可；涉及优先级给 RICE 评分卡（能力 10）。

**15 段要点**：文档信息（模型/提示/知识版本关联）→ 背景与目标（业务成本 vs AI 价值，含评测基线与成功阈值）→ 名词术语（幻觉/置信度/降级/接管）→ 需求范围（含/不含：明确不做的确定性兜底）→ 方案对比与选型（自研 vs API vs 微调，成本/质量/延迟权衡 + 演进路径）→ 用户角色（人类用户 + 人工接管者）→ 功能需求（任务定义 + 输入输出契约 + 行为约束三层）→ 非功能（延迟 P95/并发/成本上限）→ 业务流程（输入→推理→输出→人工确认/接管→反馈闭环）→ 数据与埋点（评测集/字段级反馈/版本号）→ 权限与安全（输入过滤/输出校验/PII 脱敏/注入防护）→ 异常处理（幻觉/低置信/拒答/工具失败/多源冲突 + 用户可见与恢复）→ 上线计划（灰度/影子模式/人工监控 + 回滚）→ 风险与遗留（质量漂移/偏见/成本超预算）→ 附录（验收样本集/评测计划/原型思路）

**专项检查清单（6 项）**：
- [ ] 任务定义落点：AI 负责到哪一步、哪些必须人工确认，边界可执行
- [ ] 输入输出契约：来源/字段/缺失处理；输出结构/必填/禁止/证据形式
- [ ] 质量验收阈值：评测集量化目标（如事实准确率 ≥85%）+ 不可接受条件
- [ ] 异常降级与人工接管：每类失败有策略，接管携带上下文
- [ ] 行为约束三层（Always/Ask first/Never），Never 不因输入变化而越过
- [ ] 反馈与版本闭环：字段级反馈 + 模型/提示/知识/规则版本关联
