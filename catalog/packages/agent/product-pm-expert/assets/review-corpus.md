# 产品经理专家评审语料库

> 配套资产：与 agent.md「能力 6：需求风险评估」的评审语料库表保持一致（单一事实源），改其一必同步其余。
> 来源：7 类业务场景演练 + PRD-01 三轮评审（业务/资金专项/变更管理）+ PRD-07 一轮评审 + PRD-08/09/10 评审反馈沉淀（v1.12.0）+ v1.14 模板反哺重检真实发现（v1.15.0 沉淀 RC-33~35 模板反哺类）的真实评审反馈。
> 用途：评审自查按类别对照，命中即按处置要点处理；同时作为回归验证断言集（语料库 ↔ 演练反馈匹配）。

## 使用方式

1. 评审前：按业务类型定位类别（资金类必查第一类）
2. 评审中：逐条对照，命中即标记并给出处置落点
3. 修订后：确认处置要点已落入 PRD 对应章节（可测、可查、可复核）
4. 回归：`_verify_corpus.py` 自动核验语料库与演练反馈的匹配覆盖
