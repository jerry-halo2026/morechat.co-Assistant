# AI 内容创作专家团

AI 驱动的多模态内容生产专业团队，提供从创意策划到成品交付的端到端解决方案。

## 类型

Team 型（6人团队）

## 功能

专注于利用 AI 技术进行多模态内容生产，覆盖以下核心能力：

- **创意策划**：品牌定位分析、情绪板/视觉方向探索、广告创意方向、场景构思、镜头设计、Logo概念
- **文案创作**：公众号/知乎/博客长文、小红书/社媒短文案、视频脚本、营销文案
- **视频生成**：文生视频/图生视频，4 个视频生成模型（HY-Video-1.5、YT-Video-2.0、YT-Video-HumanActor、YT-Video-FX）
- **图文创作**：7 种场景创作策略、20 变体矩阵批量生成、系统化图片构建
- **发布级精修**：精确层+生成层分离、确定性合成、多平台尺寸适配
- **智能编辑**：Track 结构视频编辑（5种元素 + 11种滤镜），支持裁剪/拼接/转场/字幕/去水印等
- **视频翻译**：AI 声纹克隆 + 唇型同步 + 字幕翻译，支持中英日韩西等多语言
- **素材分析**：多模态视频理解，精彩片段自动提取
- **多媒体合成**：视频/图片/音频智能合成

## 使用示例

- 帮我确定新产品的品牌视觉方向，做一个情绪板
- 帮我想几个社媒广告创意方向
- 帮我写一篇公众号长文，主题：独立开发者如何 0→1 做 SaaS
- 帮我用 AI 生成一段 15 秒的产品宣传短视频
- 为我的新品上市生成一组小红书风格的种草图文

- 把这段中文视频翻译成英文版本，保留原声特征
- 帮我从这段 1 小时的直播回放中提取精彩片段

## 安装 / Installation

本包由 **morechat.co-Assistant** 内容仓分发，**通过 morechat.co-Assistant 目录导入**：

1. 在 morechat.co-Assistant 仓中取出 `catalog/packages/<kind>/<id>/`；
2. 该目录即包根目录，内含 `plugin.json`、`agents/`、`skills/`，整体作为包目录导入；
3. 导入后由平台注册 Agent / Squad 与技能，无需额外安装脚本或注册命令；
4. 头像不在仓内分发（`avatars/` 已移除），由产品端生成。
