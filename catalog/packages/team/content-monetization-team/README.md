# 内容变现商业化专家团

专注于帮助内容创作者和品牌方实现内容价值最大化的 AI 专家团队。

## 类型

Team 型（5人团队）

## 功能

覆盖内容商业化的完整闭环：
- **CPS 带货分佣**：商品选品、佣金结构设计、转化漏斗优化
- **CPE/CPM 效果广告**：互动任务设计、曝光策略、出价优化、效果评估
- **交易市场运营**：商家-创作者匹配、定价策略、供需平衡、质量保证
- **收益分析**：数据分析、结算对账、积分体系运营、财务模型
- **推广任务管理**：全生命周期管理（创建→匹配→创作→审核→发布→追踪→结算）

## 技能

| 技能名 | 说明 |
|--------|------|
| content-monetization-ops | 内容变现商业化技能包，含CPS/CPE/CPM模式指南、积分体系、交易撮合和推广任务管理 |

| 角色 | 名称 | 职责 |
|------|------|------|
| 主理人 | 芬利(Finley) | 商业变现策略设计、收益模型选型、团队调度、ROI评估 |

| 交易撮合专家 | 麦奇(Match) | 内容交易市场运营、商家-创作者匹配、供需平衡、定价策略 |
| 收益分析师 | 普罗(Profit) | 收益数据分析、结算对账、积分体系运营、财务模型 |

## 使用示例

- "帮我设计一套适合我账号的内容变现方案"
- "分析哪种结算模式（CPS/CPE/CPM）最适合我当前的粉丝体量"
- "帮我评估这个品牌推广任务的收益是否合理"

## 适用场景

- 创作者想要开始内容变现，不知道从何入手
- 品牌方想要投放推广，需要合理预算分配
- MCN 机构需要规模化商业化运营方案
- 已有变现收入，希望优化收益结构
- 需要设计积分/信用体系
- 需要运营内容交易市场

## 头像

头像不随本内容仓分发（`avatars/` 已移除），由产品端生成（grok 引擎）。

## 安装 / Installation

本包由 **morechat.co-Assistant** 内容仓分发，**通过 morechat.co-Assistant 目录导入**：

1. 在 morechat.co-Assistant 仓中取出 `catalog/packages/<kind>/<id>/`；
2. 该目录即包根目录，内含 `plugin.json`、`agents/`、`skills/`，整体作为包目录导入；
3. 导入后由平台注册 Agent / Squad 与技能，无需额外安装脚本或注册命令；
4. 头像不在仓内分发（`avatars/` 已移除），由产品端生成。
